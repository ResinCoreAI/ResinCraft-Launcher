# ResinCraft Launcher: 機能一覧

**Puirkle** が作った、モダンで使いやすい Minecraft ランチャーです。Windows、macOS、Linux に対応しています。テレメトリーはなく、ResinCraft アカウントも必要ありません。

> NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.

**(新機能)** と書かれた項目は、最新バージョンで追加された新機能です。

## プレイ

- **インスタンス:** バージョンや Modパックごとに分かれたインストールです。それぞれに Mod、ワールド、Java、メモリ、JVM 引数を個別に設定できます。
- **どの Minecraft バージョンでも:** すべてのリリースとスナップショットに対応。昔のクラシックアルファまでさかのぼれます。
- **Mod ローダー:** Fabric、Quilt、Forge（Minecraft 1.2.5 まで対応）、NeoForge、LiteLoader に対応し、ローダーのバージョンも選べます。OptiFine や jar Mod も使えます。
- **バージョンとローダーの変更:** インスタンスの Minecraft バージョンや Mod ローダーを、Prism と同じように**設定**タブから切り替えられます。インスタンスページのバージョン表示をクリックしても開きます。
- **プレイ:** ワンクリックで起動。別のアカウントでプレイしたり、同じインスタンスを 2 つのアカウントで同時に起動したりもできます。
- **クイック参加:** 最近遊んだサーバーやシングルプレイのワールドが並び、ワンクリックですぐに入れます。
- **ワールド:** ワールドを直接プレイ、名前の変更、バックアップ、zip からのインポートができます。
- **クラッシュ修復:** Minecraft がクラッシュすると、ResinCraft がクラッシュレポートとログを読み取ります。何が起きたかをわかりやすい言葉で伝え、ワンクリックで直せるようにします。直せる内容: 足りない Mod のインストール、クラッシュした Mod のオフ、正しい Java の選択、ゲームへのメモリの追加。
- **再インストール (新機能):** インスタンスのゲームファイルをもう一度ダウンロードしたり、Modパックのファイルをパック本来の状態に戻したりできます。インスタンスのメニューか**設定 → 修復**から行えます。ワールドはそのままです。
- **調整済みの Java フラグ:** ゲームは ResinCraft の G1GC フラグで起動するので、フレームがよりなめらかになります（設定 → Java、またはインスタンスごと）。
- **Java:** インストール済みの Java を見つけて、Minecraft のバージョンごとに合ったものを選びます。合うものがなければ Eclipse Temurin をダウンロードします。
- **メモリ表示:** ランチャー、各ゲーム、各サーバーがどれだけメモリを使っているかを表示します（ホームにも表示可能）。
- **Discord Rich Presence:** パック名、バージョン、プレイ時間、シングルプレイかサーバーかを表示します。フレンド向けのボタン: **View modpack**（Modパックを見る）と **Get ResinCraft**（ResinCraft を入手）。

## インスタンス

- **整理:** グループ分け、自由な並び順（ドラッグで並べ替え）、アイコン、バナー、カラー。
- **タブ:** コンテンツ、ワールド、サーバー、スクリーンショット、メモ、ファイル（ファイルマネージャーとエディター内蔵）、ログ、設定。
- **別のインスタンスからコピー:** ワールド、Mod とその設定（config フォルダー）、シェーダーパック、リソースパック、ゲーム設定をコピーできます。
- **複製、エクスポート**（Modrinth `.mrpack` または CurseForge `.zip`）、そして**自分だけの Modパックに**。
- **コマンドと環境変数:** 起動前やゲーム終了後に実行するコマンドと、環境変数を設定できます。
- **すぐに切り替え:** Mod のオン・オフは一瞬で切り替わります。ファイル名の変更はバックグラウンドで行われます。
- **すぐに削除・作成 (新機能):** 削除したインスタンスはすぐに消え、バックグラウンドでごみ箱に移されます。インストール中の Modパックはすぐにライブラリに表示され、カードに進捗が出ます。

## コンテンツと「探す」

- **配信サイト:** Modrinth、CurseForge、FTB、ATLauncher、Technic、GitHub リリースの Mod、Modパック、リソースパック、シェーダー。インスタンスのバージョンとローダーに合うものだけを表示します。
- **Modパックのページ:** 説明、ギャラリー、バージョン、変更履歴、そして**パックに入っている Mod** を確認できます。
- **スマートなインストール:** 好きなバージョンを選べて、まとめて複数インストールでき、必要な前提 Mod は自動で追加されます。2 つのサイトから同じ Mod を入れてしまっても検出します。
- **アップデート:** アップデートの確認と適用（1 つずつ、またはすべて）。Modパックのアップデートやバージョン切り替えにも対応。
- **手動ダウンロード:** 作者がランチャーからのダウンロードを許可していない CurseForge のファイルは、ダウンロードフォルダーやほかの**監視フォルダー**から自動で取り込みます（設定 → ダウンロード）。
- **リスト:** Mod、リソースパック、シェーダーをリストとして書き出し、そのリストを別のインスタンスにインストールできます。

## サーバーのホスト

- **サーバーの種類:** Vanilla、Paper、Purpur、Folia、Spigot、Leaf、Fabric、Quilt、Forge、NeoForge、Arclight（Mod とプラグインを同時に使用）、Bedrock Dedicated Server。
- **Modパックやインスタンスから:** Modrinth、CurseForge（公式サーバーパックがあればそれを使用）、FTB から、または自分のインスタンスからサーバーを作れます。
- **公式サーバーパックがない場合 (新機能):** ResinCraft がパック自身の Mod リストからサーバーを組み立て、作成時にその旨を伝えます。サーバーには **Built by ResinCraft**（ResinCraft が作成）のバッジが付きます。
- **自分でダウンロードするファイル (新機能):** 作者が自分の Web サイトからのダウンロードしか許可していないファイルは、サーバーの **Console**（コンソール）タブに一覧表示されます。起動のたびに、ResinCraft がダウンロードフォルダーと同じパックのインスタンスからそれらを探し、所定の場所に置きます。
- **パックの大きさに合わせたメモリ (新機能):** 新しく作る Mod 入りサーバーには、Mod が 80 個以上なら 6 GB、150 個以上なら 8 GB を割り当てます（最大で PC の RAM の半分まで）。
- **クライアント専用 Mod は、クラッシュしたときだけオフ:** サーバーが問題なく起動する限り、クライアント用の Mod もサーバーに残します。Mod がゲームクライアントの機能を呼び出したせいで起動がクラッシュした場合は、その Mod をオフ（`.jar.disabled`）にして、サーバーが自動で再起動します。ほかの Mod が必要としている Mod はオンのままです。
- **管理:** コンソール、プロパティエディター、アップデート対応のプラグイン・Mod マネージャー、ホワイトリスト、OP とBAN、サーバーアイコン、バックアップ。
- **再起動とその他メニュー:** Stop（停止）の隣に「再起動」ボタン。アドレスのコピー、フォルダーを開く、バックアップ、設定、削除をまとめたメニューもあります。
- **オンラインのプレイヤー:** サーバーにいるプレイヤーを、数秒ごとにリアルタイムで確認します。
- **Java フラグ:** ResinCraft が調整したフラグか、Modパック独自のもの（`user_jvm_args.txt`、起動スクリプト）を使えます。
- **Anti-xray（X-ray 対策） (新機能):** Paper、Purpur、Folia、Leaf のサーバーでは、X-ray Mod やテクスチャーパックから鉱石を隠せます（Settings → Anti-xray）。
- **再インストール (新機能):** サーバーのソフトウェアをもう一度インストールしたり、Modパックのファイルを元に戻したりできます。ワールドと設定はそのままです。
- **すぐに削除・作成 (新機能):** 削除したサーバーはすぐに消えます。作成中のサーバーはすぐに一覧に表示され、進捗も確認できます。
- **リモート操作 (新機能):** ResinCraft が開いているかシステムトレイにある間、`console.rscraft.resincore.tech` の Web コンソールを使って、どのブラウザーやスマホからでもサーバーを操作できます。サインインには同じ Minecraft アカウントを使います（設定 → リモート操作）。サーバーの起動、停止、確認、作成はできますが、ファイルやほかの設定には一切アクセスできません。
- **フレンドと共有:**
  - ResinCraft Relay（`<name>.rscraft.resincore.tech`）
  - playit.gg
  - bore
  - ルーター（UPnP）
  - 自分のドメイン（Cloudflare DNS の自動設定つき）
- **統合版のプレイヤーも参加可能:** Java 版サーバーに統合版から参加できます（Geyser + Floodgate）。
- **Whitelist requests（ホワイトリスト申請）:** プレイヤーが参加を申請し、**Players** タブで承認または拒否します。
  - **Web page（Web ページ）:** `https://rscraft.resincore.tech/join/<name>`（ResinCraft Relay 使用時）。
  - **自分の Discord ボット:** プレイヤーが `/whitelist` と入力します。
  - **返事:** 承認するとホワイトリストに追加され、ボットがダイレクトメッセージで本人に知らせます。
  - **保護:** BAN されたプレイヤーの申請は自動で断られます。**Reject and block**（拒否してブロック）を使うと、その人は二度と申請できなくなります。

## 統合版（Windows）

- Minecraft for Windows と Minecraft Preview のインストール、起動、アンインストール（アンインストール前にワールドをバックアップします）。

## アカウント

- **Microsoft サインイン:** トークンは暗号化して保存されます。シングルプレイや LAN 用の**オフラインプロフィール**も使えます。
- **スキン、マント、名前の変更。**

## 他のランチャーからの移行

- Prism Launcher、MultiMC、Modrinth App、CurseForge アプリ、ATLauncher、GDLauncher、公式 Minecraft Launcher から、Mod、ワールド、パック、設定ごとインスタンスを取り込めます。サーバーも取り込めます。

## アプリ

- **Windows、macOS**（Apple Silicon と Intel）、**Linux**（x64 と ARM64: AppImage、`.deb`、`.tar.gz`）。
- **Windows 用インストーラー:** `.exe`、管理されたインストール向けの `.msi`、そして **ResinCraft Setup (新機能)**。ResinCraft Setup は常に最新バージョンをインストールする小さなインストーラーで、リンクはずっと変わりません。
- **アップデート:** 自動で確認します。
  - タイトルバーに**アップデート**ボタン。
  - ゲームやサーバーが動いているときは**閉じてアップデート**。
  - バックグラウンドで**サイレントアップデート**。
- **システムトレイで動かし続ける:** ウィンドウを閉じても、サーバー、Discord ボット、リモート操作、ダウンロードは動き続けます。
- **ResinCraft の再インストール (新機能):** 設定 → アップデート から、アプリを上書きでもう一度インストールして修復できます。インスタンス、アカウント、設定はそのままです。
- **テーマ (新機能):** ダーク、ライト、黒曜石、深層岩、サクラ、ネザー、ジ・エンド、ハロウィン、クリスマス、またはシステム。
  - ハロウィンは 10 月 16 日〜31 日、クリスマスは 12 月 10 日〜25 日に自動でオンになります。別のテーマを選べば、そのテーマのままです。イベントテーマをオフにすることもできます。
  - **カスタムCSS:** どのテーマにも上から自分の CSS を適用できます。現在の色から始められます。
  - さらに、隠しサプライズも。コナミコマンドを試してみてください。
- **16 の言語:** English, Deutsch, Español, Français, Bahasa Indonesia, Italiano, 日本語, 한국어, Polski, Português (Brasil), Русский, ไทย, Türkçe, Tiếng Việt, 简体中文, 繁體中文.
- **ストレージ管理**（データを別のドライブに移動）、設定の**バックアップと復元**。
