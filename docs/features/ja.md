# ResinCraft Launcher: 機能一覧

**Puirkle** が作った、モダンで使いやすい Minecraft ランチャーです。Windows、macOS、Linux に対応しています。テレメトリーはなく、ResinCraft アカウントも必要ありません。

> NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.

かっこ内のバージョンは、その機能が追加されたバージョンです。最新は 1.4.0 と 1.4.1 です。

## プレイ

- **インスタンス (0.1.0):** バージョンや Modパックごとに分かれたインストールです。それぞれに Mod、ワールド、Java、メモリ、JVM 引数を個別に設定できます。
- **どの Minecraft バージョンでも (0.1.0):** すべてのリリースとスナップショットに対応。昔のクラシックアルファまでさかのぼれます。
- **Mod ローダー (0.1.0):** Fabric、Quilt、Forge、NeoForge に対応し、ローダーのバージョンも選べます。1.7.10〜1.12.2 向けのクラシック Forge（1.1.2）、Minecraft 1.2.5 までさかのぼる Forge と LiteLoader（1.2.0）。OptiFine（1.0.1）や jar Mod（1.2.0）も使えます。
- **バージョンとローダーの変更 (1.2.7):** インスタンスの Minecraft バージョンや Mod ローダーを、Prism と同じように**設定**タブから切り替えられます。インスタンスページのバージョン表示をクリックしても開きます。
- **プレイ (0.1.0):** ワンクリックで起動。別のアカウントでプレイしたり、同じインスタンスを 2 つのアカウントで同時に起動したりもできます（1.0.5）。
- **クイック参加 (1.1.0):** 最近遊んだサーバーやシングルプレイのワールド（1.2.3）が並び、ワンクリックですぐに入れます。
- **ワールド (0.1.0):** ワールドの名前の変更、バックアップ、zip からのインポートができます。ワールドを直接プレイすることもできます（1.2.0）。
- **ワールドの自動バックアップ (1.4.0):** ゲームやサーバーが動いている間、そのワールドを 30 分ごとにバックアップし、ワールドごとに新しい 3 つを残します（設定 → 自動バックアップ）。
- **バックアップから復元 (1.4.0):** 自分で作ったものでも自動のものでも、どのバックアップからでもワールドを戻せます。コピーとして戻すこともできます。置き換えられたワールドはごみ箱に移されます。
- **クラッシュ修復 (1.2.7):** Minecraft がクラッシュすると、ResinCraft がクラッシュレポートとログを読み取ります。何が起きたかをわかりやすい言葉で伝え、ワンクリックで直せるようにします。直せる内容: 足りない Mod のインストール、クラッシュした Mod のオフ、正しい Java の選択、ゲームへのメモリの追加。
- **再インストール (1.3.0):** インスタンスのゲームファイルをもう一度ダウンロードしたり、Modパックのファイルをパック本来の状態に戻したりできます。インスタンスのメニューか**設定 → 修復**から行えます。ワールドはそのままです。
- **調整済みの Java フラグ (1.2.7):** ゲームは ResinCraft の G1GC フラグで起動するので、フレームがよりなめらかになります（設定 → Java、またはインスタンスごと）。
- **Java (0.1.0):** インストール済みの Java を見つけて、Minecraft のバージョンごとに合ったものを選びます。合うものがなければ Eclipse Temurin をダウンロードします。
- **メモリ表示 (1.2.1):** ランチャー、各ゲーム、各サーバーがどれだけメモリを使っているかを表示します（ホームにも表示可能）。
- **Discord Rich Presence (1.2.3):** パック名、バージョン、プレイ時間、シングルプレイかサーバーかを表示します。フレンド向けのボタン（1.2.6）: **View modpack**（Modパックを見る）と **Get ResinCraft**（ResinCraft を入手）。

## インスタンス

- **整理:** グループ分け（0.2.0）、自由な並び順（0.3.1、ドラッグで並べ替え）、アイコンとバナー（0.3.0）、カラー（0.1.0）。
- **タブ (0.1.0):** コンテンツ、ワールド、サーバー、スクリーンショット、メモ、ファイル（ファイルマネージャーとエディター内蔵、0.2.0）、ログ、設定。
- **別のインスタンスからコピー (1.2.5):** ワールド、シェーダーパック、リソースパック、ゲーム設定をコピーできます。Mod とその設定（config フォルダー）は 1.2.6 から。
- **複製 (0.1.0)、エクスポート**（Modrinth `.mrpack` または CurseForge `.zip`、1.0.5）、そして**自分だけの Modパックに (1.1.0)**。
- **複数選択 (1.1.0):** たくさんのインスタンスをまとめて移動、削除、複製、更新できます。
- **コマンドと環境 (1.2.0):** 起動前やゲーム終了後に実行するコマンドと、環境変数を設定できます。
- **すぐに切り替え (1.2.7):** Mod のオン・オフは一瞬で切り替わります。ファイル名の変更はバックグラウンドで行われます。
- **すぐに削除・作成 (1.3.0):** 削除したインスタンスはすぐに消え、バックグラウンドでごみ箱に移されます。インストール中の Modパックはすぐにライブラリに表示され、カードに進捗が出ます。

## コンテンツと「探す」

- **配信サイト (0.1.0):** Modrinth、CurseForge、FTB、ATLauncher、Technic、GitHub リリース（0.3.1）の Mod、Modパック、リソースパック、シェーダー。インスタンスのバージョンとローダーに合うものだけを表示します。
- **Modパックのページ (1.2.0):** 説明、ギャラリー、バージョン、変更履歴、そして**パックに入っている Mod (1.2.5)** を確認できます。
- **スマートなインストール (0.3.0):** 好きなバージョンを選べて、まとめて複数インストールでき、必要な前提 Mod は自動で追加されます。2 つのサイトから同じ Mod を入れてしまっても検出します。
- **アップデート (0.1.0):** アップデートの確認と適用（1 つずつ、またはすべて）。Modパックのアップデートやバージョン切り替え（1.1.0）にも対応。**すべて更新** は最大 4 つずつ同時にダウンロードします（1.4.1）。
- **手動ダウンロード (1.0.1):** 作者がランチャーからのダウンロードを許可していない CurseForge のファイルは、ダウンロードフォルダーやほかの**監視フォルダー**（1.0.5、設定 → ダウンロード）から自動で取り込みます。
- **リスト (0.4.0):** Mod、リソースパック、シェーダーをリストとして書き出し、そのリストを別のインスタンスにインストールできます。
- **サーバーを探す (1.4.0):** 探す → **サーバー** に、ResinCraft でホストされているサーバーと、プレイヤーが追加したサーバーが並びます。検索や、カテゴリー、地域、言語、Modパック、統合版やオフラインプロフィールへの対応で絞り込めます。いいねや通報もできます。
- **サーバーごとのページ (1.4.1):** 説明と MOTD の全文、すべての詳細情報、クライアントパック、リンク、ホワイトリスト申請の欄があります。
- **ワンクリックで参加 (1.4.0):** **参加** を押すと、合うインスタンスを選ぶか、どれを使うか尋ねます。**インストールして参加** は、サーバーとまったく同じ Mod でインスタンスを作って参加します。
- **ホワイトリストへの登録を申請 (1.4.0):** **参加をリクエスト** で、Minecraft アカウントで署名した申請を送ります。表示は **Waiting for the host**（ホストの返事待ち）、**On the whitelist**（ホワイトリスト登録済み）、**Ask again**（もう一度申請）のいずれかになり、ホストが返事をすると ResinCraft が知らせてくれます（タスクバーも点滅します、1.4.1）。

## サーバーのホスト

- **サーバーの種類 (0.1.0):** Vanilla、Paper、Purpur、Folia、Spigot、Fabric、Quilt、Forge、NeoForge。Leaf、Arclight（Mod とプラグインを同時に使用）、Bedrock Dedicated Server は 0.3.1 から。
- **Modパックやインスタンスから (0.1.0):** Modrinth、CurseForge（公式サーバーパックがあればそれを使用）、FTB から、または自分のインスタンスからサーバーを作れます。
- **公式サーバーパックがない場合 (1.2.11):** ResinCraft がパック自身の Mod リストからサーバーを組み立て、作成時にその旨を伝えます。サーバーには **Built by ResinCraft**（ResinCraft が作成）のバッジが付きます。
- **自分でダウンロードするファイル (1.2.9):** 作者が自分の Web サイトからのダウンロードしか許可していないファイルは、サーバーの **Console**（コンソール）タブに一覧表示されます。起動のたびに、ResinCraft がダウンロードフォルダーと同じパックのインスタンスからそれらを探し、所定の場所に置きます。
- **パックの大きさに合わせたメモリ (1.2.9):** 新しく作る Mod 入りサーバーには、Mod が 80 個以上なら 6 GB、150 個以上なら 8 GB を割り当てます（最大で PC の RAM の半分まで）。
- **クライアント専用 Mod は、クラッシュしたときだけオフ (1.2.8):** サーバーが問題なく起動する限り、クライアント用の Mod もサーバーに残します。Mod がゲームクライアントの機能を呼び出したせいで起動がクラッシュした場合は、その Mod をオフ（`.jar.disabled`）にして、サーバーが自動で再起動します。ほかの Mod が必要としている Mod はオンのままです。
- **管理 (0.1.0):** コンソール、プロパティエディター、アップデート対応のプラグイン・Mod マネージャー（0.3.0）、ホワイトリスト、OP とBAN、サーバーアイコン（1.2.5）、バックアップ。
- **より速いアップデート (1.4.1):** **すべて更新** は、プラグインや Mod を最大 4 つずつ同時にダウンロードしてまとめて入れます。サーバーの実行中なら、次の再起動まで待たせておきます。
- **サーバーを掲載 (1.4.0):** 設定 → **サーバーリスト** で、説明、タグ、地域、言語を付けて 探す → サーバー に掲載します。ほかの場所で動かしているサーバーは **サーバーを登録** で追加できます。
- **クライアントパック (1.4.0):** プレイヤーが参加するのに必要なものを公開します。1.4.1 からは、サーバーの Modパック（配信元のサイトからインストール）、ほかの Mod は 1 つずつ Modrinth か CurseForge から、そして自分のファイルを PC から直接。リソースパックやシェーダーもいっしょに送れます。プラグインサーバーやバニラサーバーにも対応。
- **再起動とその他メニュー (1.2.7):** Stop（停止）の隣に「再起動」ボタン。アドレスのコピー、フォルダーを開く、バックアップ、設定、削除をまとめたメニューもあります。
- **オンラインのプレイヤー (1.2.7):** サーバーにいるプレイヤーを、数秒ごとにリアルタイムで確認します。
- **Java フラグ (0.2.0):** ResinCraft が調整したフラグか、Modパック独自のもの（`user_jvm_args.txt`、起動スクリプト、1.2.7）を使えます。
- **Anti-xray（X-ray 対策） (1.3.0):** Paper、Purpur、Folia、Leaf のサーバーでは、X-ray Mod やテクスチャーパックから鉱石を隠せます（Settings → Anti-xray）。
- **Anti-cheat（チート対策） (1.4.0):** スイッチ 1 つで、プラグインサーバーに Grim アンチチートをインストールします。
- **ワールドを再生成 (1.4.0):** 新しいワールドでサーバーをやり直せます。古いワールドはごみ箱に移されます。
- **再インストール (1.3.0):** サーバーのソフトウェアをもう一度インストールしたり、Modパックのファイルを元に戻したりできます。ワールドと設定はそのままです。
- **すぐに削除・作成 (1.3.0):** 削除したサーバーはすぐに消えます。作成中のサーバーはすぐに一覧に表示され、進捗も確認できます。
- **リモート操作 (1.3.0):** ResinCraft が開いているかシステムトレイにある間、`console.rscraft.resincore.tech` の Web コンソールを使って、どのブラウザーやスマホからでもサーバーを操作できます。サインインには同じ Minecraft アカウントを使います（設定 → リモート操作）。サーバー管理でできることはすべてできます。ファイルマネージャー、Java 設定、任意のリンクからのプラグインには、2 つ目のスイッチ **フル操作を許可** が必要です。Servers ページには **Web コンソール** ボタンもあります（1.3.1）。
- **ほかの PC (1.4.1):** Servers タブの PC メニューから、リモート操作をオンにしたほかの PC のサーバーを開けます。起動、停止、プレイヤー・プラグイン・設定の管理、そちらでのサーバーの作成やインポートができます。
- **フレンドに手伝ってもらう (1.4.1):** 設定 → リモート操作 → **People who can use your servers**（サーバーを使える人）で、Minecraft アカウントに **Viewer**（閲覧者）、**Operator**（オペレーター）、**Manager**（マネージャー）の権限を、すべてのサーバーか選んだサーバーに対して与えます。ファイル、Java 設定、サーバーの作成と削除は自分だけのものです。
- **フレンドと共有:**
  - ResinCraft Relay（`<name>.rscraft.resincore.tech`、0.3.0）
  - playit.gg（0.2.0）
  - bore（0.2.0）
  - ルーター（UPnP、0.2.0）
  - 自分のドメイン（Cloudflare DNS の自動設定つき、0.2.0）。TXT レコードで検証します（**検証待ち**、**検証済み**、1.3.1）
  - 新しいサーバーでは **Automatic**（自動、1.3.2）: まずルーター、次に ResinCraft Relay、その次に playit.gg
- **統合版のプレイヤーも参加可能 (0.3.1):** Java 版サーバーに統合版から参加できます（Geyser + Floodgate）。
- **Whitelist requests（ホワイトリスト申請） (1.2.7):** プレイヤーが参加を申請し、**Players** タブで承認または拒否します。
  - **Web page（Web ページ）:** サーバー自身のアドレスか、検証済みの自分のドメインで（1.3.2、ResinCraft Relay 使用時）。
  - **自分の Discord ボット:** プレイヤーが `/whitelist` と入力します。
  - **サーバーリスト (1.4.0):** ResinCraft を使っているプレイヤーは 探す → サーバー から申請します。
  - **返事:** 承認するとホワイトリストに追加され、ボットがダイレクトメッセージで本人に知らせます。
  - **保護:** BAN されたプレイヤーの申請は自動で断られます。**Reject and block**（拒否してブロック）を使うと、その人は二度と申請できなくなります。**Blocked**（ブロック中）の一覧があり、プレイヤーごとに **Unblock**（ブロック解除）できます（1.4.1）。

## アカウント

- **Microsoft サインイン (0.1.0):** トークンは暗号化して保存されます。シングルプレイや LAN 用の**オフラインプロフィール (0.1.0)** も使えます。Java Edition を持っていない Microsoft アカウント向けの **Bedrock プロフィール (1.0.0)** もあります。
- **スキン、マント、名前の変更 (0.1.0)。** スキンライブラリ、プレイヤー名からのスキン取得とオンライン検索（1.0.3）、3D スキンビューアー（1.1.0）。

## 他のランチャーからの移行

- **インポート (1.0.5):** Prism Launcher、MultiMC、Modrinth App、CurseForge アプリ、ATLauncher、GDLauncher、公式 Minecraft Launcher から、Mod、ワールド、パック、設定ごとインスタンスを取り込めます。サーバーも取り込めます。
- **別の PC へ移行 (1.1.1):** 設定 → 別の PC へ移行 で、すべてを 1 つの `.resincraft` ファイルに保存します。新しい PC でそのファイルを開いてください。

## アプリ

- **Windows (0.1.0)、macOS**（Apple Silicon と Intel）、**Linux**（x64 と ARM64: AppImage、`.deb`、1.2.0。`.tar.gz`、1.2.4）。
- **Windows 用インストーラー:** `.exe`（0.1.0）、管理されたインストール向けの `.msi`（1.2.10）、そして **ResinCraft Setup (1.3.0)**。ResinCraft Setup は常に最新バージョンをインストールする小さなインストーラーで、リンクはずっと変わりません。
- **アップデート (0.3.0):** 自動で確認します。
  - タイトルバーに**アップデート**ボタン（1.2.7）。
  - ゲームやサーバーが動いているときは**閉じてアップデート**（1.2.7）。
  - バックグラウンドで**サイレントアップデート**（1.2.7）。
- **システムトレイで動かし続ける (1.2.7):** ウィンドウを閉じても、サーバー、Discord ボット、リモート操作、ダウンロードは動き続けます。
- **ResinCraft の再インストール (1.3.0):** 設定 → アップデート から、アプリを上書きでもう一度インストールして修復できます。インスタンス、アカウント、設定はそのままです。
- **テーマ:** ダーク、ライト、システム（0.1.0）。黒曜石、深層岩、サクラ、ネザー、ジ・エンド（1.3.0）。
  - **テーマを作成 (1.3.0):** 自分だけのテーマを作れます。**詳細調整** でどの色でも変えられ（カラーピッカー）、アプリの各部分に CSS も使えます（1.3.2）。
  - **テーマの共有 (1.3.2):** 画像と CSS 入りの `.rctheme` ファイルを **エクスポート** できます。**テーマをインポート** するか、ファイルをダブルクリックして取り込めます（1.4.0）。
  - **カスタムCSS (1.3.0):** どのテーマにも上から自分の CSS を適用できます。現在の色から始められ、色やアプリの各部分、すぐ使える例をまとめたガイドも内蔵しています。
  - さらに、隠しサプライズも（1.3.0）。コナミコマンドを試してみてください。
- **16 の言語 (0.1.0):** English, Deutsch, Español, Français, Bahasa Indonesia, Italiano, 日本語, 한국어, Polski, Português (Brasil), Русский, ไทย, Türkçe, Tiếng Việt, 简体中文, 繁體中文.
- **ストレージ管理 (1.1.0):** インスタンスを別のドライブに置けます。そこへ **インスタンスを移動** するか、**移動せずに使う** を選べます（1.4.1）。
- 設定の **設定をリセット** と **ResinCraft をアンインストール (1.4.0)**。
