# ResinCraft Launcher: 기능

**Puirkle**이 만든 현대적이고 친근한 Minecraft 런처예요. Windows, macOS, Linux에서 쓸 수 있어요. 텔레메트리도 없고 ResinCraft 계정도 필요 없어요.

> NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.

**(1.2.7)** 표시가 있는 항목은 1.2.7 버전에서 새로 추가된 기능이에요.

## 플레이

- **인스턴스:** 버전이나 모드팩마다 따로 설치되고, 각각 모드, 월드, Java, 메모리, JVM 인수를 따로 가져요.
- **모든 Minecraft 버전:** 모든 정식 버전과 스냅숏, 옛날 클래식 알파까지 지원해요.
- **모드 로더:** Fabric, Quilt, Forge(Minecraft 1.2.5까지), NeoForge, LiteLoader를 지원하고 로더 버전도 고를 수 있어요. OptiFine과 jar 모드도 돼요.
- **버전과 로더 변경 (1.2.7):** Prism처럼 **설정** 탭에서 인스턴스의 Minecraft 버전이나 모드 로더를 바꿀 수 있어요. 인스턴스 페이지의 버전 표시를 눌러도 열려요.
- **플레이:** 클릭 한 번이면 시작돼요. 다른 계정으로 플레이하거나, 같은 인스턴스를 두 계정으로 동시에 실행할 수도 있어요.
- **빠른 참가:** 최근에 들어간 서버와 싱글플레이 월드가 모여 있어서, 클릭 한 번으로 바로 들어갈 수 있어요.
- **월드:** 월드를 바로 플레이하고, 이름을 바꾸고, 백업하고, zip에서 가져올 수 있어요.
- **충돌 해결 (1.2.7):** Minecraft가 충돌하면 ResinCraft가 충돌 보고서와 로그를 읽어요. 무엇이 잘못됐는지 쉬운 말로 알려 주고, 클릭 한 번으로 고칠 수 있게 해 줘요. 고칠 수 있는 것: 빠진 모드 설치, 충돌한 모드 끄기, 알맞은 Java 고르기, 게임에 메모리 더 주기.
- **Java:** 설치된 Java를 찾아서 Minecraft 버전마다 알맞은 것을 고르고, 맞는 게 없으면 Eclipse Temurin을 내려받아요.
- **메모리 표시:** 런처, 각 게임, 각 서버가 메모리를 얼마나 쓰는지 보여 줘요(홈에도 표시 가능).
- **Discord Rich Presence:** 팩 이름, 버전, 플레이 시간, 싱글플레이인지 서버인지 보여 줘요. 친구용 버튼: **View modpack**(모드팩 보기)과 **Get ResinCraft**(ResinCraft 받기).

## 인스턴스

- **정리:** 그룹, 원하는 순서(끌어서 정렬), 아이콘, 배너, 색상.
- **탭:** 콘텐츠, 세계, 서버, 스크린샷, 메모, 파일(파일 관리자와 편집기 내장), 로그, 설정.
- **다른 인스턴스에서 복사:** 월드, 모드와 모드 설정(config 폴더), 셰이더 팩, 리소스 팩, 게임 설정.
- **복제, 내보내기**(Modrinth `.mrpack` 또는 CurseForge `.zip`), 그리고 **나만의 모드팩 만들기**.
- **명령어와 환경 변수:** 실행 전과 게임 종료 후에 실행할 명령어, 그리고 환경 변수.
- **즉시 전환 (1.2.7):** 모드를 켜고 끄는 게 바로 반영돼요. 파일 이름 변경은 백그라운드에서 처리돼요.

## 콘텐츠와 둘러보기

- **사이트:** Modrinth, CurseForge, FTB, ATLauncher, Technic, GitHub 릴리스의 모드, 모드팩, 리소스 팩, 셰이더를 인스턴스의 버전과 로더에 맞게 걸러서 보여 줘요.
- **모드팩 페이지:** 설명, 갤러리, 버전, 변경 사항, 그리고 **팩에 들어 있는 모드**까지 볼 수 있어요.
- **똑똑한 설치:** 원하는 버전을 고르고, 여러 개를 한 번에 설치하고, 필요한 선행 모드는 자동으로 추가돼요. 같은 모드를 두 사이트에서 받는 것도 잡아내요.
- **업데이트:** 업데이트 확인과 적용(하나씩 또는 전부), 모드팩 업데이트와 버전 전환.
- **수동 다운로드:** 제작자가 런처 다운로드를 막아 둔 CurseForge 파일은 다운로드 폴더나 다른 **감시 폴더**에서 알아서 가져와요(설정 → 다운로드).
- **목록:** 모드, 리소스 팩, 셰이더를 목록으로 내보내고, 그 목록을 다른 인스턴스에 설치할 수 있어요.

## 서버 호스팅

- **서버 종류:** Vanilla, Paper, Purpur, Folia, Spigot, Leaf, Fabric, Quilt, Forge, NeoForge, Arclight(모드와 플러그인을 함께), Bedrock Dedicated Server.
- **모드팩이나 인스턴스로:** Modrinth, CurseForge(공식 서버 팩이 있으면 그걸 사용), FTB의 모드팩이나 내 인스턴스로 서버를 만들 수 있어요.
- **클라이언트 전용 모드는 꺼 둠:** 게임 클라이언트에서만 돌아가는 모드를 찾아서, 서버가 시작될 때마다 자동으로 꺼요. 다른 모드가 필요로 하는 모드는 켜 둬요. 그래도 서버가 충돌하면 그 모드를 끄고 서버가 알아서 다시 시작돼요.
- **관리:** 콘솔, 속성 편집기, 업데이트를 지원하는 플러그인·모드 관리자, 화이트리스트, OP와 차단, 서버 아이콘, 백업.
- **다시 시작과 더 보기 메뉴 (1.2.7):** Stop(중지) 옆에 '다시 시작' 버튼이 있고, 주소 복사, 폴더 열기, 백업, 설정, 삭제가 담긴 메뉴가 있어요.
- **지금 접속 중:** 서버에 있는 플레이어를 몇 초마다 실시간으로 확인해요 **(1.2.7)**.
- **Java 플래그 (1.2.7):** ResinCraft가 다듬은 플래그나 모드팩 자체 플래그(`user_jvm_args.txt`, 시작 스크립트)를 쓸 수 있어요.
- **친구와 공유:**
  - ResinCraft Relay(`<name>.rscraft.resincore.tech`)
  - playit.gg
  - bore
  - 공유기(UPnP)
  - 내 도메인(Cloudflare DNS 자동 설정 포함)
- **베드락 플레이어도 참가 가능:** Java 서버에 베드락 에디션으로 들어올 수 있어요(Geyser + Floodgate).
- **Whitelist requests(화이트리스트 신청) (1.2.7):** 플레이어가 참가를 신청하면 **Players** 탭에서 수락하거나 거절해요.
  - **Web page(웹 페이지):** `https://rscraft.resincore.tech/join/<name>`(ResinCraft Relay 사용 시).
  - **내 Discord 봇:** 플레이어가 `/whitelist`를 입력해요.
  - **답변:** 수락하면 화이트리스트에 추가되고, 봇이 DM으로 알려 줘요.
  - **보호:** 차단(밴)된 플레이어는 거절돼요. **Reject and block**(거절하고 차단)을 쓰면 그 사람은 다시 신청할 수 없어요.

## 베드락 에디션 (Windows)

- Minecraft for Windows와 Minecraft Preview를 설치, 실행, 제거할 수 있어요(제거 전에 월드를 먼저 백업해요).

## 계정

- **Microsoft 로그인:** 토큰은 암호화해서 보관해요. 싱글플레이와 LAN용 **오프라인 프로필**도 있어요.
- **스킨, 망토, 이름 변경.**

## 다른 런처에서 옮기기

- Prism Launcher, MultiMC, Modrinth App, CurseForge 앱, ATLauncher, GDLauncher, 공식 Minecraft Launcher에서 모드, 월드, 팩, 설정까지 인스턴스를 그대로 가져올 수 있어요. 서버도 가져올 수 있어요.

## 앱

- **Windows, macOS**(Apple Silicon과 Intel), **Linux**(x64와 ARM64: AppImage, `.deb`, `.tar.gz`).
- **업데이트:** 자동으로 확인해요.
  - **(1.2.7)** 제목 표시줄에 **업데이트** 버튼.
  - **(1.2.7)** 게임이나 서버가 실행 중일 때는 **닫고 업데이트**.
  - **(1.2.7)** 백그라운드에서 **조용히 업데이트**.
- **시스템 트레이에서 계속 실행 (1.2.7):** 창을 닫아도 서버, Discord 봇, 다운로드가 계속 돌아가요.
- **16개 언어:** English, Deutsch, Español, Français, Bahasa Indonesia, Italiano, 日本語, 한국어, Polski, Português (Brasil), Русский, ไทย, Türkçe, Tiếng Việt, 简体中文, 繁體中文.
- **저장소 관리**(데이터를 다른 드라이브로 옮기기), 설정 **백업과 복원**, **라이트와 다크** 테마.
