# ResinCraft Launcher: 기능

**Puirkle**이 만든 현대적이고 친근한 Minecraft 런처예요. Windows, macOS, Linux에서 쓸 수 있어요. 텔레메트리도 없고 ResinCraft 계정도 필요 없어요.

> NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.

괄호 안의 버전은 각 기능이 추가된 버전이에요. 가장 최신은 1.4.0과 1.4.1이에요.

## 플레이

- **인스턴스 (0.1.0):** 버전이나 모드팩마다 따로 설치되고, 각각 모드, 월드, Java, 메모리, JVM 인수를 따로 가져요.
- **모든 Minecraft 버전 (0.1.0):** 모든 정식 버전과 스냅숏, 옛날 클래식 알파까지 지원해요.
- **모드 로더 (0.1.0):** Fabric, Quilt, Forge, NeoForge를 지원하고 로더 버전도 고를 수 있어요. 1.7.10~1.12.2용 클래식 Forge(1.1.2), Minecraft 1.2.5까지 가는 Forge와 LiteLoader(1.2.0). OptiFine(1.0.1)과 jar 모드(1.2.0)도 돼요.
- **버전과 로더 변경 (1.2.7):** Prism처럼 **설정** 탭에서 인스턴스의 Minecraft 버전이나 모드 로더를 바꿀 수 있어요. 인스턴스 페이지의 버전 표시를 눌러도 열려요.
- **플레이 (0.1.0):** 클릭 한 번이면 시작돼요. 다른 계정으로 플레이하거나, 같은 인스턴스를 두 계정으로 동시에 실행할 수도 있어요(1.0.5).
- **빠른 참가 (1.1.0):** 최근에 들어간 서버와 싱글플레이 월드(1.2.3)가 모여 있어서, 클릭 한 번으로 바로 들어갈 수 있어요.
- **월드 (0.1.0):** 월드 이름을 바꾸고, 백업하고, zip에서 가져올 수 있어요. 월드를 바로 플레이할 수도 있어요(1.2.0).
- **자동 월드 백업 (1.4.0):** 게임이나 서버가 실행되는 동안 그 월드를 30분마다 백업하고, 월드마다 최신 3개를 남겨요(설정 → 자동 백업).
- **백업에서 복원 (1.4.0):** 직접 만든 백업이든 자동 백업이든 어떤 백업에서도 월드를 되돌리거나, 사본으로 되살릴 수 있어요. 대체되는 월드는 휴지통으로 가요.
- **충돌 해결 (1.2.7):** Minecraft가 충돌하면 ResinCraft가 충돌 보고서와 로그를 읽어요. 무엇이 잘못됐는지 쉬운 말로 알려 주고, 클릭 한 번으로 고칠 수 있게 해 줘요. 고칠 수 있는 것: 빠진 모드 설치, 충돌한 모드 끄기, 알맞은 Java 고르기, 게임에 메모리 더 주기.
- **다시 설치 (1.3.0):** 인스턴스의 게임 파일을 다시 내려받거나, 모드팩 파일을 팩 원래 상태로 되돌려요. 인스턴스 메뉴나 **설정 → 복구**에서 할 수 있어요. 월드는 그대로예요.
- **다듬은 Java 플래그 (1.2.7):** 게임이 ResinCraft의 G1GC 플래그로 시작돼서 프레임이 더 부드러워요(설정 → Java 또는 인스턴스별).
- **Java (0.1.0):** 설치된 Java를 찾아서 Minecraft 버전마다 알맞은 것을 고르고, 맞는 게 없으면 Eclipse Temurin을 내려받아요.
- **메모리 표시 (1.2.1):** 런처, 각 게임, 각 서버가 메모리를 얼마나 쓰는지 보여 줘요(홈에도 표시 가능).
- **Discord Rich Presence (1.2.3):** 팩 이름, 버전, 플레이 시간, 싱글플레이인지 서버인지 보여 줘요. 친구용 버튼(1.2.6): **View modpack**(모드팩 보기)과 **Get ResinCraft**(ResinCraft 받기).

## 인스턴스

- **정리:** 그룹(0.2.0), 원하는 순서(0.3.1, 끌어서 정렬), 아이콘과 배너(0.3.0), 색상(0.1.0).
- **탭 (0.1.0):** 콘텐츠, 세계, 서버, 스크린샷, 메모, 파일(파일 관리자와 편집기 내장, 0.2.0), 로그, 설정.
- **다른 인스턴스에서 복사 (1.2.5):** 월드, 셰이더 팩, 리소스 팩, 게임 설정. 모드와 모드 설정(config 폴더)은 1.2.6부터.
- **복제(0.1.0), 내보내기**(Modrinth `.mrpack` 또는 CurseForge `.zip`, 1.0.5), 그리고 **나만의 모드팩 만들기(1.1.0)**.
- **여러 개 선택 (1.1.0):** 인스턴스 여러 개를 한 번에 옮기고, 삭제하고, 복제하고, 업데이트할 수 있어요.
- **명령어와 환경 (1.2.0):** 실행 전과 게임 종료 후에 실행할 명령어, 그리고 환경 변수.
- **즉시 전환 (1.2.7):** 모드를 켜고 끄는 게 바로 반영돼요. 파일 이름 변경은 백그라운드에서 처리돼요.
- **즉시 삭제와 생성 (1.3.0):** 삭제한 인스턴스는 바로 사라지고 백그라운드에서 휴지통으로 옮겨져요. 설치 중인 모드팩은 라이브러리에 바로 나타나고, 카드에 진행 상황이 표시돼요.

## 콘텐츠와 둘러보기

- **사이트 (0.1.0):** Modrinth, CurseForge, FTB, ATLauncher, Technic, GitHub 릴리스(0.3.1)의 모드, 모드팩, 리소스 팩, 셰이더를 인스턴스의 버전과 로더에 맞게 걸러서 보여 줘요.
- **모드팩 페이지 (1.2.0):** 설명, 갤러리, 버전, 변경 사항, 그리고 **팩에 들어 있는 모드(1.2.5)** 목록까지 볼 수 있어요.
- **똑똑한 설치 (0.3.0):** 원하는 버전을 고르고, 여러 개를 한 번에 설치하고, 필요한 선행 모드는 자동으로 추가돼요. 같은 모드를 두 사이트에서 받는 것도 잡아내요.
- **업데이트 (0.1.0):** 업데이트 확인과 적용(하나씩 또는 전부), 모드팩 업데이트와 버전 전환(1.1.0). **모두 업데이트**는 한 번에 최대 네 개씩 내려받아요(1.4.1).
- **수동 다운로드 (1.0.1):** 제작자가 런처 다운로드를 막아 둔 CurseForge 파일은 다운로드 폴더나 다른 **감시 폴더**(1.0.5, 설정 → 다운로드)에서 알아서 가져와요.
- **목록 (0.4.0):** 모드, 리소스 팩, 셰이더를 목록으로 내보내고, 그 목록을 다른 인스턴스에 설치할 수 있어요.
- **서버 찾기 (1.4.0):** 둘러보기 → **서버**에 ResinCraft로 호스팅되는 서버와 플레이어가 추가한 서버가 나와요. 검색하거나 카테고리, 지역, 언어, 모드팩, 베드락이나 오프라인 프로필 지원 여부로 거를 수 있고, 좋아요와 신고도 할 수 있어요.
- **서버마다 페이지 (1.4.1):** 전체 설명과 MOTD, 모든 세부 정보, 클라이언트 팩, 링크, 화이트리스트 신청란이 있어요.
- **클릭 한 번으로 참가 (1.4.0):** **참가**를 누르면 맞는 인스턴스를 고르거나 어떤 걸 쓸지 물어봐요. **설치하고 참가**는 서버와 똑같은 모드로 인스턴스를 만들고 들어가요.
- **화이트리스트 신청 (1.4.0):** **참가 요청**을 누르면 내 Minecraft 계정으로 서명한 신청을 보내요. 버튼에 **Waiting for the host**(호스트 응답 대기 중), **On the whitelist**(화이트리스트에 있음), **Ask again**(다시 요청)이 표시되고, 호스트가 답하면 ResinCraft가 알려 줘요(작업 표시줄도 깜빡여요, 1.4.1).

## 서버 호스팅

- **서버 종류 (0.1.0):** Vanilla, Paper, Purpur, Folia, Spigot, Fabric, Quilt, Forge, NeoForge. Leaf, Arclight(모드와 플러그인을 함께), Bedrock Dedicated Server는 0.3.1부터.
- **모드팩이나 인스턴스로 (0.1.0):** Modrinth, CurseForge(공식 서버 팩이 있으면 그걸 사용), FTB의 모드팩이나 내 인스턴스로 서버를 만들 수 있어요.
- **공식 서버 팩이 없나요? (1.2.11):** ResinCraft가 팩 자체의 모드 목록으로 서버를 만들고, 서버를 만들 때 그렇게 알려 주며, **Built by ResinCraft**(ResinCraft가 만듦) 배지를 보여 줘요.
- **직접 내려받을 파일 (1.2.9):** 제작자가 자기 웹사이트에서만 내려받을 수 있게 한 파일은 서버의 **Console**(콘솔) 탭에 목록으로 나와요. 시작할 때마다 ResinCraft가 다운로드 폴더와 같은 팩의 인스턴스에서 그 파일들을 찾아 제자리에 넣어요.
- **팩 크기에 맞춘 메모리 (1.2.9):** 새로 만드는 모드 서버는 모드가 80개 이상이면 6GB, 150개 이상이면 8GB를 받아요(최대 PC RAM의 절반까지).
- **클라이언트 전용 모드는 충돌할 때만 꺼요 (1.2.8):** 서버가 문제없이 시작되는 한 클라이언트 모드도 서버에 그대로 둬요. 어떤 모드가 게임 클라이언트를 찾다가 시작 중에 충돌하면, 그 모드를 끄고(`.jar.disabled`) 서버가 알아서 다시 시작돼요. 다른 모드가 필요로 하는 모드는 켜 둬요.
- **관리 (0.1.0):** 콘솔, 속성 편집기, 업데이트를 지원하는 플러그인·모드 관리자(0.3.0), 화이트리스트, OP와 차단, 서버 아이콘(1.2.5), 백업.
- **더 빠른 업데이트 (1.4.1):** **모두 업데이트**는 플러그인이나 모드를 한 번에 최대 네 개씩 내려받아 함께 넣고, 서버가 실행 중이면 다음 재시작 때 들어가도록 대기열에 넣어요.
- **서버 등록하기 (1.4.0):** 설정 → **서버 목록**에서 설명, 태그, 지역, 언어와 함께 둘러보기 → 서버에 올려요. 다른 곳에서 운영하는 서버는 **서버 등록**으로 추가할 수 있어요.
- **클라이언트 팩 (1.4.0):** 플레이어가 들어오는 데 필요한 것을 공개해요. 1.4.1부터: 서버의 모드팩(원래 사이트에서 설치), 그 밖의 모드는 각각 Modrinth나 CurseForge에서, 내 파일은 PC에서 바로. 리소스 팩과 셰이더도 함께 보낼 수 있고, 플러그인 서버와 바닐라 서버도 돼요.
- **다시 시작과 더 보기 메뉴 (1.2.7):** Stop(중지) 옆에 '다시 시작' 버튼이 있고, 주소 복사, 폴더 열기, 백업, 설정, 삭제가 담긴 메뉴가 있어요.
- **지금 접속 중 (1.2.7):** 서버에 있는 플레이어를 몇 초마다 실시간으로 확인해요.
- **Java 플래그 (0.2.0):** ResinCraft가 다듬은 플래그나 모드팩 자체 플래그(`user_jvm_args.txt`, 시작 스크립트, 1.2.7)를 쓸 수 있어요.
- **Anti-xray(엑스레이 방지) (1.3.0):** Paper, Purpur, Folia, Leaf 서버에서 엑스레이 모드와 텍스처 팩으로부터 광석을 숨길 수 있어요(Settings → Anti-xray).
- **Anti-cheat(치트 방지) (1.4.0):** 스위치 하나로 플러그인 서버에 Grim 안티치트를 설치해요.
- **월드 재생성 (1.4.0):** 새 월드로 서버를 다시 시작해요. 예전 월드는 휴지통으로 가요.
- **다시 설치 (1.3.0):** 서버 소프트웨어를 다시 설치하거나 모드팩 파일을 되돌려요. 월드와 설정은 그대로예요.
- **즉시 삭제와 생성 (1.3.0):** 삭제한 서버는 바로 사라지고, 만드는 중인 서버는 목록에 바로 나타나 진행 상황을 보여 줘요.
- **원격 제어 (1.3.0):** ResinCraft가 열려 있거나 시스템 트레이에 있는 동안, `console.rscraft.resincore.tech`의 웹 콘솔에 같은 Minecraft 계정으로 로그인해서 어떤 브라우저나 휴대폰으로도 서버를 다룰 수 있어요(설정 → 원격 제어). 서버 관리에서 할 수 있는 건 모두 할 수 있어요. 파일 관리자, Java 설정, 아무 링크에서 받는 플러그인은 두 번째 스위치인 **전체 제어 허용**을 켜야 쓸 수 있어요. Servers 페이지에 **웹 콘솔** 버튼도 있어요(1.3.1).
- **내 다른 PC (1.4.1):** Servers 탭의 PC 메뉴에서 원격 제어를 켠 다른 PC의 서버를 열어요. 시작, 중지, 플레이어·플러그인·설정 관리를 하고, 그 PC에서 서버를 만들거나 가져올 수도 있어요.
- **친구에게 도움 받기 (1.4.1):** 설정 → 원격 제어 → **People who can use your servers**(내 서버를 쓸 수 있는 사람)에서 Minecraft 계정에 **Viewer**(보기), **Operator**(운영자), **Manager**(관리자) 권한을 내 모든 서버나 고른 서버에 줘요. 파일, Java 설정, 서버 만들기와 삭제는 나만 할 수 있어요.
- **친구와 공유:**
  - ResinCraft Relay(`<name>.rscraft.resincore.tech`, 0.3.0)
  - playit.gg(0.2.0)
  - bore(0.2.0)
  - 공유기(UPnP, 0.2.0)
  - 내 도메인(Cloudflare DNS 자동 설정 포함, 0.2.0), TXT 레코드로 인증(**인증 대기 중**, **인증됨**, 1.3.1)
  - 새 서버는 **Automatic**(자동, 1.3.2): 먼저 공유기, 그다음 ResinCraft Relay, 그다음 playit.gg
- **베드락 플레이어도 참가 가능 (0.3.1):** Java 서버에 베드락 에디션으로 들어올 수 있어요(Geyser + Floodgate).
- **Whitelist requests(화이트리스트 신청) (1.2.7):** 플레이어가 참가를 신청하면 **Players** 탭에서 수락하거나 거절해요.
  - **Web page(웹 페이지):** 서버 자체 주소나 인증된 내 도메인에서(1.3.2, ResinCraft Relay 사용 시).
  - **내 Discord 봇:** 플레이어가 `/whitelist`를 입력해요.
  - **서버 목록 (1.4.0):** ResinCraft를 쓰는 플레이어는 둘러보기 → 서버에서 신청해요.
  - **답변:** 수락하면 화이트리스트에 추가되고, 봇이 DM으로 알려 줘요.
  - **보호:** 차단(밴)된 플레이어는 거절돼요. **Reject and block**(거절하고 차단)을 쓰면 그 사람은 다시 신청할 수 없어요. **Blocked**(차단됨) 목록이 있고 플레이어마다 **Unblock**(차단 해제)할 수 있어요(1.4.1).

## 베드락 에디션 (Windows)
