# ResinCraft Launcher：功能

由 **Puirkle** 打造的現代、好上手的 Minecraft 啟動器，支援 Windows、macOS 和 Linux。沒有遙測，也不需要 ResinCraft 帳戶。

> NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.

括號裡的版本號是每項功能首次推出的版本。最新的是 1.4.0 和 1.4.1。

## 遊玩

- **實例（0.1.0）：** 每個版本或模組包各自獨立安裝，各有自己的模組、世界、Java、記憶體和 JVM 參數。
- **任何 Minecraft 版本（0.1.0）：** 所有正式版和快照，一路到早期的經典 Alpha 版。
- **模組載入器（0.1.0）：** Fabric、Quilt、Forge 和 NeoForge，可選擇載入器版本。適用於 1.7.10 到 1.12.2 的經典 Forge（1.1.2），最早到 Minecraft 1.2.5 的 Forge 和 LiteLoader（1.2.0）。也支援 OptiFine（1.0.1）和 jar 模組（1.2.0）。
- **變更版本和載入器（1.2.7）：** 和 Prism 一樣，在實例的**設定**分頁中切換 Minecraft 版本或模組載入器。點擊實例頁面上的版本標籤也能開啟。
- **遊玩（0.1.0）：** 一鍵開玩。可以改用其他帳戶遊玩，也能用兩個帳戶同時執行同一個實例（1.0.5）。
- **快速加入（1.1.0）：** 列出你最近玩過的伺服器和單人世界（1.2.3），一鍵直接進入。
- **世界（0.1.0）：** 重新命名、備份，或從 zip 匯入世界。直接進入世界遊玩（1.2.0）。
- **世界自動備份（1.4.0）：** 遊戲或伺服器執行時，它的世界每 30 分鐘備份一次，每個世界保留最新的 3 份（設定 → 自動備份）。
- **還原備份（1.4.0）：** 從任何備份還原世界，你自己的備份或自動備份都可以，也可以還原成一個副本。被取代的世界會移到資源回收筒。
- **當機修正（1.2.7）：** Minecraft 當機時，ResinCraft 會讀取當機報告和記錄，用簡單的話告訴你出了什麼問題，並提供一鍵修正。可以修正：安裝缺少的模組、關閉造成當機的模組、選擇合適的 Java、給遊戲更多記憶體。
- **重新安裝（1.3.0）：** 重新下載實例的遊戲檔案，或把模組包自己的檔案恢復成模組包原本的樣子。可以從實例的選單或**設定 → 修復**操作。世界會保留。
- **調校過的 Java 參數（1.2.7）：** 遊戲使用 ResinCraft 的 G1GC 參數啟動，畫面更流暢（設定 → Java，或依實例個別設定）。
- **Java（0.1.0）：** 自動找到已安裝的 Java，依 Minecraft 版本挑選合適的；都不合適時會下載 Eclipse Temurin。
- **記憶體顯示（1.2.1）：** 顯示啟動器、每個遊戲和每個伺服器用了多少記憶體（可選擇在首頁顯示）。
- **Discord Rich Presence（1.2.3）：** 顯示模組包名稱、版本、遊玩時間，以及在玩單人還是伺服器。給好友的按鈕（1.2.6）：**View modpack**（查看模組包）和 **Get ResinCraft**（取得 ResinCraft）。

## 實例

- **整理：** 群組（0.2.0）、自訂順序（0.3.1，拖曳排列）、圖示和橫幅（0.3.0），以及顏色（0.1.0）。
- **分頁（0.1.0）：** 內容、世界、伺服器、螢幕截圖、筆記、檔案（內建檔案管理器和編輯器，0.2.0）、日誌和設定。
- **從其他實例複製（1.2.5）：** 世界、光影包、資源包和遊戲設定；模組及其設定（config 資料夾）從 1.2.6 起支援。
- **建立副本（0.1.0）、匯出**（Modrinth `.mrpack` 或 CurseForge `.zip`，1.0.5），以及**做成你自己的模組包（1.1.0）**。
- **多選（1.1.0）：** 一次移動、刪除、複製或更新多個實例。
- **指令與環境變數（1.2.0）：** 設定啟動前和遊戲關閉後要執行的指令，以及環境變數。
- **即時開關（1.2.7）：** 開啟或關閉模組立即生效，重新命名在背景完成。
- **即時刪除和建立（1.3.0）：** 刪除的實例會立刻消失，並在背景移到資源回收筒。正在安裝的模組包會馬上出現在遊戲庫中，卡片上會顯示安裝進度。

## 內容與探索

- **來源網站（0.1.0）：** 來自 Modrinth、CurseForge、FTB、ATLauncher、Technic 和 GitHub Releases（0.3.1）的模組、模組包、資源包和光影，依實例的版本和載入器篩選。
- **模組包頁面（1.2.0）：** 包含簡介、圖庫、版本、更新記錄，以及**模組包裡包含的模組（1.2.5）**。
- **聰明安裝（0.3.0）：** 任選版本、一次安裝多個、自動加入必要的前置模組，還能發現從兩個網站裝了同一個模組的情況。
- **更新（0.1.0）：** 檢查並套用更新（單個或全部），支援模組包更新和版本切換（1.1.0）。**全部更新**最多同時下載四個（1.4.1）。
- **手動下載（1.0.1）：** 作者禁止啟動器下載的 CurseForge 檔案，會從你的下載資料夾或其他**監視資料夾**（1.0.5，設定 → 下載）中自動取得。
- **清單（0.4.0）：** 把模組、資源包或光影匯出成清單，再把清單安裝到另一個實例。
- **尋找伺服器（1.4.0）：** 探索 → **伺服器**列出用 ResinCraft 架設的伺服器和玩家加入的伺服器。可以搜尋，並依分類、地區、語言、模組包、是否支援基岩版或離線帳戶篩選；還能按讚和檢舉。
- **每個伺服器都有自己的頁面（1.4.1）：** 完整簡介和 MOTD、所有詳細資訊、用戶端模組包、連結，以及白名單申請框。
- **一鍵加入（1.4.0）：** **加入**會挑選合適的實例，或問你。**安裝並加入**會建立一個剛好包含伺服器模組的實例，然後加入。
- **申請加入白名單（1.4.0）：** **申請加入**會送出一個用你的 Minecraft 帳戶簽署的申請。按鈕會顯示 **Waiting for the host**（等待服主）、**On the whitelist**（已在白名單中）或 **Ask again**（再次申請），服主回覆時 ResinCraft 會通知你（並讓工作列閃爍）（1.4.1）。

## 架設伺服器

- **伺服器類型（0.1.0）：** Vanilla、Paper、Purpur、Folia、Spigot、Fabric、Quilt、Forge 和 NeoForge；Leaf、Arclight（模組和插件同時使用）以及 Bedrock Dedicated Server 從 0.3.1 起支援。
- **從模組包或實例建立（0.1.0）：** 用 Modrinth、CurseForge（有官方伺服器包時使用它）或 FTB 的模組包建立伺服器，也可以從你的某個實例建立。
- **沒有官方伺服器包？（1.2.11）：** ResinCraft 會依模組包自己的模組清單架設伺服器，建立時會告訴你，並顯示 **Built by ResinCraft**（由 ResinCraft 架設）標記。
- **需要自己下載的檔案（1.2.9）：** 作者只允許從自己網站下載的檔案，會列在伺服器的 **Console**（主控台）分頁中。每次啟動前，ResinCraft 會在你的下載資料夾和同一模組包的實例中尋找它們，並放到正確的位置。
- **依模組包大小分配記憶體（1.2.9）：** 新建立的模組伺服器在有 80 個模組時分配 6 GB，150 個時分配 8 GB（最多為電腦記憶體的一半）。
- **僅限用戶端的模組只在造成當機時才關閉（1.2.8）：** 只要伺服器能正常啟動，用戶端模組就會留在伺服器上。如果某次啟動因為某個模組呼叫了遊戲用戶端而當機，就會關閉那個模組（`.jar.disabled`）並自動重新啟動伺服器。其他模組需要的模組會保持開啟。
- **管理（0.1.0）：** 主控台、屬性編輯器、支援更新的插件和模組管理（0.3.0）、白名單、管理員和封鎖、伺服器圖示（1.2.5）、備份。
- **更快的更新（1.4.1）：** **全部更新**最多同時下載四個插件或模組，並一起裝上；伺服器執行時則排隊等到下次重新啟動。
- **把伺服器加入列表（1.4.0）：** Settings → **伺服器列表**會把它放進「探索 → 伺服器」，附上簡介、標籤、地區和語言。在別處執行的伺服器可以用**提交伺服器**加入。
- **用戶端模組包（1.4.0）：** 發布玩家加入時需要的內容。從 1.4.1 起：伺服器的模組包（從它自己的網站安裝）、來自 Modrinth 或 CurseForge 的其他每個模組，以及直接從你電腦傳送的自己的檔案；資源包和光影也能一起傳送；插件伺服器和原版伺服器也支援。
- **重新啟動和更多選單（1.2.7）：** Stop（停止）旁邊有「重新啟動」；選單中有複製位址、開啟資料夾、備份、設定和刪除。
- **目前線上（1.2.7）：** 每隔幾秒即時查看伺服器上的玩家。
- **Java 參數（0.2.0）：** 使用 ResinCraft 調校好的參數，或模組包自帶的參數（`user_jvm_args.txt`、啟動腳本，1.2.7）。
- **Anti-xray（防礦物透視）（1.3.0）：** Paper、Purpur、Folia 和 Leaf 伺服器可以對 X 光模組和材質包隱藏礦石（伺服器的 Settings → Anti-xray）。
- **Anti-cheat（反作弊）（1.4.0）：** 一個開關就能在插件伺服器上安裝 Grim 反作弊。
- **重新產生世界（1.4.0）：** 用一個新世界讓伺服器重新開始；舊世界會移到資源回收筒。
- **重新安裝（1.3.0）：** 重新安裝伺服器軟體，或恢復它的模組包檔案。世界和設定會保留。
- **即時刪除和建立（1.3.0）：** 刪除的伺服器會立刻消失；正在建立的伺服器會馬上出現在清單中，並顯示進度。
- **遠端控制（1.3.0）：** 只要 ResinCraft 開著或在系統匣中執行，就能在任何瀏覽器或手機上透過 `console.rscraft.resincore.tech` 網頁主控台管理伺服器，用同一個 Minecraft 帳戶登入（設定 → 遠端控制）。伺服器管理能做的，它都能做。檔案管理器、Java 設定和來自任何連結的插件需要再開啟第二個開關：**允許完全控制**。Servers 頁面上有一個**網頁主控台**按鈕（1.3.1）。
- **你的其他電腦（1.4.1）：** Servers 分頁的電腦選單可以開啟你其他已開啟遠端控制的電腦上的伺服器：啟動、停止，管理玩家、插件和設定，還能在那裡建立或匯入伺服器。
- **讓好友幫忙（1.4.1）：** 設定 → 遠端控制 → **People who can use your servers**（可以使用你伺服器的人）：給某個 Minecraft 帳戶 **Viewer**（檢視者）、**Operator**（操作員）或 **Manager**（管理者）權限，適用於你的所有伺服器或你選的那些。檔案、Java 設定，以及建立或刪除伺服器，仍然只有你能做。
- **與好友分享：**
  - ResinCraft Relay（`<name>.rscraft.resincore.tech`，0.3.0）
  - playit.gg（0.2.0）
  - bore（0.2.0）
  - 你的路由器（UPnP，0.2.0）
  - 你自己的網域，支援 Cloudflare DNS 自動設定（0.2.0），用 TXT 記錄驗證（**等待驗證**、**已驗證**，1.3.1）
  - 新伺服器預設 **Automatic**（自動，1.3.2）：先用你的路由器，接著是 ResinCraft Relay，再來是 playit.gg
- **基岩版玩家也能加入（0.3.1）** Java 版伺服器（Geyser + Floodgate）。
- **Whitelist requests（白名單申請）（1.2.7）：** 玩家申請加入，你在 **Players** 分頁中接受或拒絕。
  - **Web page（網頁）：** 在你伺服器自己的位址或你已驗證的網域上（1.3.2，使用 ResinCraft Relay 時）。
  - **你自己的 Discord 機器人：** 玩家輸入 `/whitelist`。
  - **伺服器列表（1.4.0）：** 使用 ResinCraft 的玩家可以在「探索 → 伺服器」中申請。
  - **你的回覆：** 接受後會把玩家加入白名單，機器人會私訊通知對方。
  - **保護：** 被封鎖的玩家會被拒絕；**Reject and block**（拒絕並封鎖）可以讓對方無法再次申請，還有 **Blocked**（已封鎖）清單，每位玩家都有 **Unblock**（解除封鎖）按鈕（1.4.1）。

## 基岩版（Windows）

- **基岩版頁面（0.3.1）：** 安裝（1.0.0）、更新和修復（1.2.0）、啟動和解除安裝（1.2.3）Minecraft for Windows 與 Minecraft Preview（會先備份世界）。

## 帳戶

- **Microsoft 登入（0.1.0）**，權杖加密保存。用於單人和區域網路的**離線帳戶（0.1.0）**。為沒有 Java 版的 Microsoft 帳戶提供**基岩版帳戶（1.0.0）**。
- **外觀、披風和改名（0.1.0）。** 外觀庫、依玩家名稱取得外觀和線上搜尋（1.0.3）；3D 外觀預覽（1.1.0）。

## 從其他啟動器搬移

- **匯入（1.0.5）：** 從 Prism Launcher、MultiMC、Modrinth App、CurseForge 應用程式、ATLauncher、GDLauncher 和官方 Minecraft Launcher 匯入實例，連同模組、世界、資源包和設定一起。伺服器也可以匯入。
- **移到另一台電腦（1.1.1）：** 設定 → 移到另一台電腦會把所有內容儲存到一個 `.resincraft` 檔案；在新電腦上開啟它即可。

## 應用程式

- **Windows（0.1.0）、macOS**（Apple Silicon 和 Intel）**和 Linux**（x64 和 ARM64：AppImage、`.deb`，1.2.0；`.tar.gz`，1.2.4）。
- **Windows 安裝程式：** `.exe`（0.1.0）、適合集中管理部署的 `.msi`（1.2.10），以及 **ResinCraft Setup（1.3.0）**：一個小巧的安裝程式，永遠安裝最新版本，下載連結永遠不變。
- **更新（0.3.0）：** 自動檢查。
  - 標題列中的**更新**按鈕（1.2.7）。
  - 有遊戲或伺服器在執行時，可以**關閉並更新**（1.2.7）。
  - 在背景**靜默更新**（1.2.7）。
- **在系統匣中保持執行（1.2.7）：** 關閉視窗後，伺服器、Discord 機器人、遠端控制和下載會繼續執行。
- **重新安裝 ResinCraft（1.3.0）：** 在設定 → 更新中把應用程式覆蓋重新安裝一次，用來修復。實例、帳戶和設定都會保留。
- **主題：** 深色、淺色和跟隨系統（0.1.0）；黑曜石、深板岩、櫻花、地獄和終界（1.3.0）。
  - **建立主題（1.3.0）：** 你自己的主題，可以用**微調**改任何顏色（色彩選擇器），還能為應用程式的各個部分寫 CSS（1.3.2）。
  - **分享主題（1.3.2）：** **匯出**成 `.rctheme` 檔案，附上圖片和 CSS；用**匯入主題**匯入，或按兩下該檔案（1.4.0）。
  - **自訂 CSS（1.3.0）：** 在任何主題上疊加你自己的 CSS，從目前的顏色開始改，還內建了指南，介紹顏色、應用程式的各個部分和現成的範例。
  - 還有一個隱藏彩蛋（1.3.0）。試試 Konami 秘技。
- **16 種語言（0.1.0）：** English, Deutsch, Español, Français, Bahasa Indonesia, Italiano, 日本語, 한국어, Polski, Português (Brasil), Русский, ไทย, Türkçe, Tiếng Việt, 简体中文, 繁體中文.
- **儲存空間管理（1.1.0）：** 把實例放在另一個磁碟上。可以**移動實例**過去，或**不移動，直接使用**（1.4.1）。
- 設定中的**重設設定**和**解除安裝 ResinCraft（1.4.0）**。
