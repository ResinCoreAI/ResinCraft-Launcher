# ResinCraft Launcher: fitur

Launcher Minecraft yang modern dan ramah buatan **Puirkle**, untuk Windows, macOS, dan Linux. Tanpa telemetri dan tanpa akun ResinCraft.

> NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.

Versi dalam tanda kurung adalah versi saat fitur itu hadir. Yang terbaru adalah 1.4.0 dan 1.4.1.

## Bermain

- **Instalasi (0.1.0):** instalasi terpisah untuk setiap versi atau modpack, masing-masing dengan mod, dunia, Java, memori, dan argumen JVM sendiri.
- **Semua versi Minecraft (0.1.0):** setiap rilis dan snapshot, sampai ke versi alpha klasik.
- **Pemuat mod (0.1.0):** Fabric, Quilt, Forge, dan NeoForge, dengan pemilih versi loader. Forge klasik untuk 1.7.10 sampai 1.12.2 (1.1.2), Forge sampai Minecraft 1.2.5 dan LiteLoader (1.2.0). OptiFine (1.0.1) dan jar mod (1.2.0) juga bisa.
- **Ganti versi dan loader (1.2.7):** ganti versi Minecraft atau pemuat mod sebuah instalasi dari tab Pengaturan-nya, seperti di Prism. Label versi di halaman instalasi juga membukanya.
- **Main (0.1.0):** sekali klik. **Main juga sebagai** akun lain, atau jalankan instalasi yang sama dua kali dengan dua akun (1.0.5).
- **Gabung cepat (1.1.0):** server terakhir Anda, dan dunia pemain tunggal (1.2.3), sekali klik untuk langsung masuk.
- **Dunia (0.1.0):** ganti nama dunia, cadangkan, impor dunia dari file zip. Mainkan dunia secara langsung (1.2.0).
- **Cadangan dunia otomatis (1.4.0):** selama game atau server berjalan, dunianya dicadangkan setiap 30 menit, dan 3 cadangan terbaru per dunia disimpan (Pengaturan → Cadangan otomatis).
- **Pulihkan cadangan (1.4.0):** kembalikan dunia dari cadangan mana pun, buatan Anda sendiri atau otomatis, atau kembalikan sebagai salinan. Dunia yang digantikan dipindahkan ke Recycle Bin.
- **Perbaikan crash (1.2.7):** saat Minecraft crash, ResinCraft membaca laporan crash dan log. Ia menjelaskan masalahnya dengan bahasa sederhana dan menawarkan perbaikan sekali klik. Perbaikannya: memasang mod yang kurang, mematikan mod yang menyebabkan crash, memilih Java yang tepat, memberi game lebih banyak memori.
- **Instal ulang (1.3.0):** unduh lagi file game sebuah instalasi, atau kembalikan file modpack seperti aslinya di paket. Dari menu instalasi atau **Pengaturan → Perbaiki**. Dunia tetap aman.
- **Flag Java racikan (1.2.7):** game dimulai dengan flag G1GC racikan ResinCraft agar frame lebih mulus (Pengaturan → Java, atau per instalasi).
- **Java (0.1.0):** menemukan Java yang terpasang, memilih yang tepat untuk tiap versi Minecraft, dan mengunduh Eclipse Temurin jika tidak ada yang cocok.
- **Tampilan RAM (1.2.1):** berapa banyak memori yang dipakai launcher, tiap game, dan tiap server (bisa juga ditampilkan di Beranda).
- **Discord Rich Presence (1.2.3):** nama paket, versi, waktu bermain, pemain tunggal atau server. Tombol untuk teman (1.2.6): **View modpack** (lihat modpack) dan **Get ResinCraft** (dapatkan ResinCraft).

## Instalasi

- **Atur:** grup (0.2.0), urutan Anda sendiri (0.3.1, seret untuk menyusun), ikon dan banner (0.3.0), dan warna (0.1.0).
- **Tab (0.1.0):** Konten, Dunia, Server, Tangkapan layar, Catatan, File (pengelola dan editor file bawaan, 0.2.0), Log, dan Pengaturan.
- **Salin dari instance lain (1.2.5):** dunia, shader pack, resource pack, dan pengaturan game; mod beserta pengaturannya (folder config) sejak 1.2.6.
- **Duplikat (0.1.0), ekspor** (Modrinth `.mrpack` atau CurseForge `.zip`, 1.0.5) dan **jadikan modpack Anda sendiri (1.1.0)**.
- **Pilih beberapa (1.1.0):** pindahkan, hapus, duplikat, atau perbarui banyak instalasi sekaligus.
- **Perintah dan lingkungan (1.2.0):** perintah yang dijalankan sebelum game dimulai dan setelah game ditutup, serta variabel lingkungan.
- **Sakelar instan (1.2.7):** menyalakan atau mematikan mod langsung terjadi; penggantian nama file berjalan di latar belakang.
- **Hapus dan buat instan (1.3.0):** instalasi yang dihapus langsung hilang dan dipindahkan ke Recycle Bin di latar belakang. Modpack yang sedang dipasang langsung muncul di Pustaka, dengan progresnya di kartu.

## Konten dan Jelajahi

- **Situs (0.1.0):** mod, modpack, paket sumber daya, dan shader dari Modrinth, CurseForge, FTB, ATLauncher, Technic, dan rilis GitHub (0.3.1), disaring sesuai versi dan loader instalasi.
- **Halaman modpack (1.2.0)** dengan deskripsi, galeri, versi, catatan perubahan, dan **daftar mod di dalam paket (1.2.5)**.
- **Pemasangan pintar (0.3.0):** pilih versi mana saja, pasang beberapa sekaligus, dependensi wajib ditambahkan otomatis, dan mod yang sama dari dua situs akan terdeteksi.
- **Pembaruan (0.1.0):** periksa dan terapkan pembaruan (satu atau semua); pembaruan modpack dan ganti versi (1.1.0). **Perbarui semua** mengunduh hingga empat sekaligus (1.4.1).
- **Unduhan manual (1.0.1):** file CurseForge yang pembuatnya memblokir launcher diambil dari folder Unduhan Anda atau **Folder yang dipantau** lainnya (1.0.5, Pengaturan → Unduhan).
- **Daftar (0.4.0):** ekspor mod, paket sumber daya, atau shader sebagai daftar, lalu pasang daftar itu ke instalasi lain.
- **Cari server (1.4.0):** Jelajahi → **Server** menampilkan server yang di-host dengan ResinCraft dan server yang ditambahkan pemain. Cari dan saring menurut kategori, wilayah, bahasa, modpack, serta dukungan Bedrock atau profil offline; beri suka dan laporkan.
- **Halaman untuk setiap server (1.4.1):** deskripsi lengkap dan MOTD, semua detail, paket kliennya, tautan, dan kotak permintaan whitelist.
- **Gabung sekali klik (1.4.0):** **Gabung** memilih instalasi yang cocok, atau bertanya. **Pasang & gabung** membuat instalasi dengan mod yang persis sama dengan server lalu bergabung.
- **Minta masuk whitelist (1.4.0):** **Minta gabung** mengirim permintaan yang ditandatangani dengan akun Minecraft Anda. Tombolnya menampilkan **Waiting for the host** (menunggu host), **On the whitelist** (sudah di whitelist), atau **Ask again** (minta lagi), dan ResinCraft memberi tahu Anda (serta membuat taskbar berkedip) saat host menjawab (1.4.1).

## Menjalankan server

- **Jenis server (0.1.0):** Vanilla, Paper, Purpur, Folia, Spigot, Fabric, Quilt, Forge, dan NeoForge; Leaf, Arclight (mod dan plugin sekaligus), dan Bedrock Dedicated Server sejak 0.3.1.
- **Dari modpack atau instalasi (0.1.0):** buat server dari Modrinth, CurseForge (paket server resmi jika ada), atau FTB, atau dari salah satu instalasi Anda.
- **Tidak ada paket server resmi? (1.2.11):** ResinCraft membangun server dari daftar mod paket itu sendiri, memberi tahu Anda saat server dibuat, dan menampilkan lencana **Built by ResinCraft** (dibangun oleh ResinCraft).
- **File yang perlu diunduh sendiri (1.2.9):** file yang pembuatnya hanya mengizinkan unduhan dari situs web mereka dicantumkan di tab **Console** (konsol) server. Sebelum setiap mulai, ResinCraft mencarinya di folder Unduhan Anda dan di instalasi Anda dari paket yang sama, lalu menaruhnya di tempatnya.
- **Memori sesuai ukuran paket (1.2.9):** server modded baru mendapat 6 GB mulai dari 80 mod dan 8 GB mulai dari 150 mod (paling banyak setengah RAM PC Anda).
- **Mod khusus klien hanya dimatikan saat crash (1.2.8):** mod klien tetap ada di server selama server bisa mulai dengan baik. Jika server crash saat mulai karena sebuah mod mencoba memakai klien game, mod itu dimatikan (`.jar.disabled`) dan server mulai ulang sendiri. Mod yang dibutuhkan mod lain tetap menyala.
- **Kelola (0.1.0):** konsol, editor properti, pengelola plugin dan mod dengan pembaruan (0.3.0), whitelist, op dan ban, ikon server (1.2.5), cadangan.
- **Pembaruan lebih cepat (1.4.1):** **Perbarui semua** mengunduh hingga empat plugin atau mod sekaligus dan memasangnya bersamaan, atau mengantrekannya untuk mulai ulang berikutnya selama server berjalan.
- **Daftarkan server Anda (1.4.0):** Settings → **Daftar server** memasukkannya ke Jelajahi → Server dengan deskripsi, tag, wilayah, dan bahasa. Server yang Anda jalankan di tempat lain bisa ditambahkan dengan **Kirim server**.
- **Paket klien (1.4.0):** terbitkan apa yang dibutuhkan pemain untuk bergabung. Sejak 1.4.1: modpack server (dipasang dari situsnya sendiri), setiap mod lain dari Modrinth atau CurseForge, dan file Anda sendiri langsung dari PC Anda; paket sumber daya dan shader ikut serta; server plugin dan vanilla juga bisa.
- **Mulai ulang dan menu lainnya (1.2.7):** Mulai ulang di sebelah Stop; menu berisi salin alamat, buka folder, cadangkan, pengaturan, dan hapus.
- **Sedang online (1.2.7):** pemain di server Anda, diperiksa langsung setiap beberapa detik.
- **Flag Java (0.2.0):** flag racikan ResinCraft, atau milik modpack itu sendiri (`user_jvm_args.txt`, skrip mulai, 1.2.7).
- **Anti-xray (1.3.0):** server Paper, Purpur, Folia, dan Leaf bisa menyembunyikan bijih dari mod dan texture pack x-ray (Settings → Anti-xray).
- **Anti-cheat (1.4.0):** satu sakelar memasang anti-cheat Grim di server plugin.
- **Buat ulang dunia (1.4.0):** mulai ulang server dengan dunia baru; dunia lama dipindahkan ke Recycle Bin.
- **Instal ulang (1.3.0):** pasang ulang software server, atau kembalikan file modpack-nya. Dunia dan pengaturan tetap ada.
- **Hapus dan buat instan (1.3.0):** server yang dihapus langsung hilang; server yang sedang dibuat langsung muncul di daftar, dengan progresnya.
- **Kendali jarak jauh (1.3.0):** jalankan server Anda dari browser mana saja atau dari ponsel dengan konsol web di `console.rscraft.resincore.tech`, masuk dengan akun Minecraft yang sama, selama ResinCraft terbuka atau ada di system tray (Pengaturan → Kendali jarak jauh). Konsol ini bisa melakukan semua yang bisa dilakukan pengelola server. Pengelola file, pengaturan Java, dan plugin dari tautan mana pun memerlukan sakelar kedua, **Izinkan kendali penuh**. Tombol **Konsol web** di halaman Servers (1.3.1).
- **PC Anda yang lain (1.4.1):** menu PC di tab Servers membuka server di PC Anda yang lain yang kendali jarak jauhnya menyala: mulai, hentikan, kelola pemain, plugin, dan pengaturan, serta buat atau impor server di sana.
- **Biarkan teman membantu (1.4.1):** Pengaturan → Kendali jarak jauh → **People who can use your servers** (orang yang bisa memakai server Anda): beri akun Minecraft akses **Viewer** (penonton), **Operator**, atau **Manager** (pengelola), untuk semua server Anda atau yang Anda pilih. File, pengaturan Java, serta membuat atau menghapus server tetap urusan Anda.
- **Berbagi dengan teman:**
  - ResinCraft Relay (`<name>.rscraft.resincore.tech`, 0.3.0)
  - playit.gg (0.2.0)
  - bore (0.2.0)
  - router Anda (UPnP, 0.2.0)
  - domain Anda sendiri, dengan otomatisasi DNS Cloudflare (0.2.0), diverifikasi dengan record TXT (**Menunggu verifikasi**, **Terverifikasi**, 1.3.1)
  - **Automatic** (otomatis) untuk server baru (1.3.2): router Anda dulu, lalu ResinCraft Relay, lalu playit.gg
- **Bedrock players can join** (pemain Bedrock bisa bergabung, 0.3.1) ke server Java (Geyser + Floodgate).
- **Whitelist requests** (permintaan whitelist, 1.2.7): pemain meminta untuk bergabung, lalu Anda menerima atau menolaknya di tab Players.
  - **Halaman web:** di alamat server Anda sendiri atau domain Anda yang terverifikasi (1.3.2, dengan ResinCraft Relay).
  - **Bot Discord Anda sendiri:** pemain mengetik `/whitelist`.
  - **Daftar server (1.4.0):** pemain yang memakai ResinCraft meminta dari Jelajahi → Server.
  - **Jawaban Anda:** menerima memasukkan mereka ke whitelist; bot memberi tahu mereka lewat pesan langsung.
  - **Perlindungan:** pemain yang di-ban otomatis ditolak; **Reject and block** (tolak dan blokir) mencegah seseorang meminta lagi, dengan daftar **Blocked** (diblokir) dan **Unblock** (buka blokir) untuk setiap pemain (1.4.1).

## Bedrock Edition (Windows)

- **Halaman Bedrock (0.3.1):** pasang (1.0.0), perbarui dan perbaiki (1.2.0), jalankan dan copot (1.2.3) Minecraft for Windows dan Minecraft Preview (dunia dicadangkan lebih dulu).

## Akun

- **Masuk dengan Microsoft (0.1.0)**, dengan token yang disimpan terenkripsi. **Profil offline (0.1.0)** untuk pemain tunggal dan LAN. **Profil Bedrock (1.0.0)** untuk akun Microsoft tanpa Java Edition.
- **Skin, jubah, dan ganti nama (0.1.0).** Pustaka skin, skin dari nama pemain, dan pencarian online (1.0.3); penampil skin 3D (1.1.0).

## Pindah dari launcher lain

- **Impor (1.0.5):** instalasi dari Prism Launcher, MultiMC, aplikasi Modrinth, aplikasi CurseForge, ATLauncher, GDLauncher, dan Minecraft Launcher resmi, lengkap dengan mod, dunia, paket, dan pengaturannya. Server juga bisa diimpor.
- **Pindah ke PC lain (1.1.1):** Pengaturan → Pindah ke PC lain menyimpan semuanya ke satu file `.resincraft`; buka file itu di PC baru.

## Aplikasi

- **Windows (0.1.0), macOS** (Apple Silicon dan Intel) **dan Linux** (x64 dan ARM64: AppImage, `.deb`, 1.2.0; `.tar.gz`, 1.2.4).
- **Penginstal Windows:** `.exe` (0.1.0), `.msi` untuk instalasi terkelola (1.2.10), dan **ResinCraft Setup (1.3.0)**: penginstal kecil yang selalu memasang versi terbaru, di tautan yang tidak pernah berubah.
- **Pembaruan (0.3.0):** diperiksa otomatis.
  - Tombol **Perbarui** di bilah judul (1.2.7).
  - **Tutup dan perbarui**, saat ada game atau server yang berjalan (1.2.7).
  - **Perbarui diam-diam** di latar belakang (1.2.7).
- **Tetap berjalan di system tray (1.2.7):** menutup jendela tetap membuat server, bot Discord, kendali jarak jauh, dan unduhan berjalan.
- **Instal ulang ResinCraft (1.3.0):** Pengaturan → Pembaruan memasang ulang aplikasi di atas dirinya sendiri untuk memperbaikinya. Instalasi, akun, dan pengaturan tetap ada.
- **Tema:** Gelap, Terang, dan Sistem (0.1.0); Obsidian, Deepslate, Ceri, Nether, dan The End (1.3.0).
  - **Buat tema (1.3.0):** tema Anda sendiri, dengan **Atur detail** untuk warna apa pun (pemilih warna) dan CSS untuk bagian-bagian aplikasi (1.3.2).
  - **Bagikan tema (1.3.2):** **Ekspor** file `.rctheme`, lengkap dengan gambar dan CSS-nya; **Impor tema**, atau klik dua kali file-nya (1.4.0).
  - **CSS kustom (1.3.0):** CSS Anda sendiri di atas tema apa pun, dimulai dari warna saat ini, dengan panduan bawaan tentang warna, bagian-bagian aplikasi, dan contoh siap pakai.
  - Dan ada kejutan tersembunyi (1.3.0). Coba kode Konami.
- **16 bahasa (0.1.0):** English, Deutsch, Español, Français, Bahasa Indonesia, Italiano, 日本語, 한국어, Polski, Português (Brasil), Русский, ไทย, Türkçe, Tiếng Việt, 简体中文, 繁體中文.
- **Pengelola penyimpanan (1.1.0):** simpan instalasi di drive lain. **Pindahkan instalasi** ke sana, atau **Gunakan tanpa memindahkan** (1.4.1).
- **Atur ulang pengaturan** dan **Copot ResinCraft (1.4.0)** di Pengaturan.
