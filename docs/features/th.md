# ResinCraft Launcher: ฟีเจอร์

ลันเชอร์ Minecraft ที่ทันสมัยและใช้ง่าย โดย **Puirkle** ใช้ได้ทั้ง Windows, macOS และ Linux ไม่มีการเก็บข้อมูลการใช้งาน (telemetry) และไม่ต้องสมัครบัญชี ResinCraft

> NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.

ตัวเลขในวงเล็บคือเวอร์ชันที่ฟีเจอร์นั้นเริ่มมี เวอร์ชันล่าสุดคือ 1.4.0 และ 1.4.1

## การเล่น

- **อินสแตนซ์ (0.1.0):** แยกการติดตั้งตามเวอร์ชันหรือม็อดแพ็ก แต่ละอันมีม็อด โลก Java หน่วยความจำ และอาร์กิวเมนต์ JVM เป็นของตัวเอง
- **เล่นได้ทุกเวอร์ชันของ Minecraft (0.1.0):** ทุกรีลีสและสแนปช็อต ย้อนไปได้ถึงรุ่นอัลฟาคลาสสิก
- **ตัวโหลดม็อด (0.1.0):** Fabric, Quilt, Forge และ NeoForge เลือกเวอร์ชันของตัวโหลดได้ มี Forge แบบคลาสสิกสำหรับ 1.7.10 ถึง 1.12.2 (1.1.2) Forge ย้อนไปถึง Minecraft 1.2.5 และ LiteLoader (1.2.0) แถมรองรับ OptiFine (1.0.1) และ jar mod (1.2.0) ด้วย
- **เปลี่ยนเวอร์ชันและตัวโหลด (1.2.7):** สลับเวอร์ชัน Minecraft หรือตัวโหลดม็อดของอินสแตนซ์ได้จากแท็บการตั้งค่า แบบเดียวกับใน Prism หรือจะกดชิปเวอร์ชันบนหน้าอินสแตนซ์เพื่อเปิดหน้านี้ก็ได้
- **เล่น (0.1.0):** คลิกเดียวจบ ใช้ **เล่นครั้งนี้ในชื่อ** เพื่อเล่นด้วยบัญชีอื่น หรือจะเปิดอินสแตนซ์เดียวกันสองหน้าต่างด้วยสองบัญชีก็ได้ (1.0.5)
- **เข้าเกมด่วน (1.1.0):** เซิร์ฟเวอร์ที่เพิ่งเล่นไป และโลกเล่นคนเดียว (1.2.3) คลิกเดียวก็เข้าเกมได้ทันที
- **โลก (0.1.0):** เปลี่ยนชื่อ สำรองข้อมูล และนำเข้าโลกจากไฟล์ zip และเล่นโลกได้โดยตรง (1.2.0)
- **สำรองโลกอัตโนมัติ (1.4.0):** ระหว่างที่เกมหรือเซิร์ฟเวอร์ทำงานอยู่ โลกของมันจะถูกสำรองทุก 30 นาที โดยเก็บไว้ 3 ชุดล่าสุดต่อโลก (การตั้งค่า → สำรองข้อมูลอัตโนมัติ)
- **กู้คืนจากไฟล์สำรอง (1.4.0):** คืนโลกจากไฟล์สำรองไหนก็ได้ ทั้งที่คุณสำรองเองหรือที่สำรองอัตโนมัติ หรือจะกู้กลับมาเป็นสำเนาก็ได้ โลกที่ถูกแทนที่จะไปอยู่ในถังรีไซเคิล
- **ตัวช่วยแก้แครช (1.2.7):** เมื่อ Minecraft แครช ResinCraft จะอ่านรายงานแครชและล็อก แล้วบอกเป็นภาษาง่าย ๆ ว่าเกิดอะไรขึ้น พร้อมปุ่มแก้ในคลิกเดียว สิ่งที่แก้ให้ได้: ติดตั้งม็อดที่ขาดไป ปิดม็อดที่ทำให้แครช เลือก Java ที่ถูกต้อง และเพิ่มหน่วยความจำให้เกม
- **ติดตั้งใหม่ (1.3.0):** ดาวน์โหลดไฟล์เกมของอินสแตนซ์ใหม่ หรือคืนไฟล์ของม็อดแพ็กให้เหมือนที่มากับแพ็ก ทำได้จากเมนูของอินสแตนซ์ หรือจาก **การตั้งค่า → ซ่อมแซม** โลกของคุณยังอยู่ครบ
- **แฟล็ก Java ที่จูนมาแล้ว (1.2.7):** เกมจะเปิดด้วยแฟล็ก G1GC ของ ResinCraft เพื่อให้เฟรมลื่นขึ้น (การตั้งค่า → Java หรือตั้งแยกรายอินสแตนซ์)
- **Java (0.1.0):** หา Java ที่ติดตั้งไว้ในเครื่อง เลือกตัวที่เหมาะกับแต่ละเวอร์ชันของ Minecraft และดาวน์โหลด Eclipse Temurin ให้ถ้าไม่มีตัวไหนใช้ได้
- **ดูการใช้ RAM (1.2.1):** ลันเชอร์ แต่ละเกม และแต่ละเซิร์ฟเวอร์ใช้หน่วยความจำไปเท่าไร (เลือกให้แสดงที่หน้าแรกได้)
- **Discord Rich Presence (1.2.3):** แสดงชื่อแพ็ก เวอร์ชัน เวลาที่เล่น และบอกว่าเล่นคนเดียวหรืออยู่ในเซิร์ฟเวอร์ มีปุ่มให้เพื่อนกด (1.2.6): **View modpack** และ **Get ResinCraft** (ปุ่มบน Discord เป็นภาษาอังกฤษ)

## อินสแตนซ์

- **จัดระเบียบ:** แบ่งกลุ่ม (0.2.0) เรียงลำดับเองได้ (0.3.1 ลากเพื่อจัด) ใส่ไอคอนและแบนเนอร์ (0.3.0) และสี (0.1.0)
- **แท็บ (0.1.0):** เนื้อหา, โลก, เซิร์ฟเวอร์, ภาพหน้าจอ, บันทึกย่อ, ไฟล์ (ตัวจัดการไฟล์และตัวแก้ไขในตัว, 0.2.0), ล็อก และการตั้งค่า
- **คัดลอกจากอินสแตนซ์อื่น (1.2.5):** โลก เชดเดอร์แพ็ก รีซอร์สแพ็ก และการตั้งค่าเกม ส่วนม็อดและการตั้งค่าม็อด (โฟลเดอร์ config) คัดลอกได้ตั้งแต่ 1.2.6
- **ทำสำเนา (0.1.0), ส่งออก** (Modrinth `.mrpack` หรือ CurseForge `.zip`, 1.0.5) และ **ทำเป็นม็อดแพ็กของคุณเอง (1.1.0)**
- **เลือกหลายอัน (1.1.0):** ย้าย ลบ ทำสำเนา หรืออัปเดตหลายอินสแตนซ์ได้ในครั้งเดียว
- **คำสั่งและตัวแปรสภาพแวดล้อม (1.2.0):** คำสั่งที่จะรันก่อนเปิดเกมและหลังปิดเกม รวมถึงตัวแปรสภาพแวดล้อม (environment variables)
- **สลับได้ทันที (1.2.7):** เปิดหรือปิดม็อดได้ทันทีไม่ต้องรอ ส่วนการเปลี่ยนชื่อไฟล์จะทำอยู่เบื้องหลัง
- **ลบและสร้างได้ทันที (1.3.0):** อินสแตนซ์ที่ลบจะหายไปทันที แล้วค่อยถูกย้ายไปถังรีไซเคิลอยู่เบื้องหลัง ส่วนม็อดแพ็กที่กำลังติดตั้งจะขึ้นในคลังทันที พร้อมแสดงความคืบหน้าบนการ์ด

## เนื้อหาและหน้าสำรวจ

- **แหล่งดาวน์โหลด (0.1.0):** ม็อด ม็อดแพ็ก แพ็กทรัพยากร และเชดเดอร์จาก Modrinth, CurseForge, FTB, ATLauncher, Technic และรีลีสบน GitHub (0.3.1) คัดมาให้ตรงกับเวอร์ชันและตัวโหลดของอินสแตนซ์
- **หน้าม็อดแพ็ก (1.2.0)** มีคำอธิบาย แกลเลอรี เวอร์ชัน บันทึกการเปลี่ยนแปลง และ **ม็อดที่อยู่ในแพ็ก (1.2.5)**
- **ติดตั้งอย่างฉลาด (0.3.0):** เลือกเวอร์ชันไหนก็ได้ ติดตั้งทีเดียวหลายอัน ม็อดที่ต้องใช้ร่วม (dependency) ถูกเพิ่มให้เอง และรู้ทันถ้าม็อดตัวเดียวกันมาจากสองเว็บ
- **อัปเดต (0.1.0):** ตรวจหาและติดตั้งอัปเดต (ทีละอันหรือทั้งหมด) รวมถึงอัปเดตม็อดแพ็กและสลับเวอร์ชันแพ็ก (1.1.0) **อัปเดตทั้งหมด** ดาวน์โหลดได้พร้อมกันสูงสุดสี่อัน (1.4.1)
- **ดาวน์โหลดเอง (1.0.1):** ไฟล์ CurseForge ที่ผู้สร้างไม่ให้ลันเชอร์ดาวน์โหลด ResinCraft จะหยิบมาจากโฟลเดอร์ดาวน์โหลด หรือจาก **โฟลเดอร์ที่เฝ้าดู** อื่น ๆ (1.0.5, การตั้งค่า → การดาวน์โหลด)
- **รายการ (0.4.0):** ส่งออกม็อด แพ็กทรัพยากร หรือเชดเดอร์เป็นรายการ แล้วเอารายการนั้นไปติดตั้งในอินสแตนซ์อื่นได้
- **หาเซิร์ฟเวอร์ (1.4.0):** สำรวจ → **เซิร์ฟเวอร์** แสดงเซิร์ฟเวอร์ที่โฮสต์ด้วย ResinCraft และเซิร์ฟเวอร์ที่ผู้เล่นเพิ่มเข้ามา ค้นหาและกรองตามหมวดหมู่ ภูมิภาค ภาษา ม็อดแพ็ก หรือการรองรับ Bedrock และโปรไฟล์ออฟไลน์ได้ กดถูกใจและรายงานได้
- **หน้าของแต่ละเซิร์ฟเวอร์ (1.4.1):** คำอธิบายเต็มและ MOTD รายละเอียดทุกอย่าง แพ็กฝั่งไคลเอนต์ ลิงก์ และช่องส่งคำขอเข้าไวท์ลิสต์
- **เข้าร่วมในคลิกเดียว (1.4.0):** **เข้าร่วม** จะเลือกอินสแตนซ์ที่เข้ากันให้ หรือถามคุณ ส่วน **ติดตั้งและเข้าร่วม** จะสร้างอินสแตนซ์ที่มีม็อดตรงกับเซิร์ฟเวอร์ทุกตัวแล้วเข้าร่วมให้
- **ขอเข้าไวท์ลิสต์ (1.4.0):** **ขอเข้าร่วม** จะส่งคำขอที่ลงชื่อด้วยบัญชี Minecraft ของคุณ ปุ่มจะขึ้นว่า **Waiting for the host** (รอเจ้าของเซิร์ฟเวอร์), **On the whitelist** (อยู่ในไวท์ลิสต์แล้ว) หรือ **Ask again** (ขออีกครั้ง) และ ResinCraft จะแจ้งคุณ (พร้อมกะพริบแถบงาน) เมื่อเจ้าของตอบกลับ (1.4.1)

## โฮสต์เซิร์ฟเวอร์

- **ประเภทเซิร์ฟเวอร์ (0.1.0):** Vanilla, Paper, Purpur, Folia, Spigot, Fabric, Quilt, Forge และ NeoForge ส่วน Leaf, Arclight (ใช้ม็อดกับปลั๊กอินพร้อมกัน) และ Bedrock Dedicated Server มีตั้งแต่ 0.3.1
- **สร้างจากม็อดแพ็กหรืออินสแตนซ์ (0.1.0):** สร้างเซิร์ฟเวอร์จาก Modrinth, CurseForge (ใช้ server pack ทางการถ้ามี) หรือ FTB หรือจากอินสแตนซ์ของคุณเองก็ได้
- **ไม่มี server pack ทางการ? (1.2.11):** ResinCraft จะสร้างเซิร์ฟเวอร์จากรายการม็อดของแพ็กเอง บอกให้รู้ตอนสร้างเซิร์ฟเวอร์ และแสดงป้าย **Built by ResinCraft** (ResinCraft สร้างให้)
- **ไฟล์ที่ต้องดาวน์โหลดเอง (1.2.9):** ไฟล์ที่ผู้สร้างอนุญาตให้ดาวน์โหลดจากเว็บของเขาเท่านั้น จะแสดงไว้ในแท็บ **Console** (คอนโซล) ของเซิร์ฟเวอร์ ก่อนเปิดเซิร์ฟเวอร์ทุกครั้ง ResinCraft จะหาไฟล์พวกนี้ในโฟลเดอร์ดาวน์โหลดและในอินสแตนซ์ที่ใช้แพ็กเดียวกัน แล้ววางไว้ให้ถูกที่
- **หน่วยความจำตามขนาดแพ็ก (1.2.9):** เซิร์ฟเวอร์ม็อดที่สร้างใหม่จะได้ 6 GB เมื่อมีม็อดตั้งแต่ 80 ตัว และ 8 GB เมื่อมีตั้งแต่ 150 ตัว (ไม่เกินครึ่งหนึ่งของ RAM ในเครื่อง)
- **ปิดม็อดฝั่งไคลเอนต์เฉพาะตอนที่ทำให้แครช (1.2.8):** ม็อดที่ทำงานได้เฉพาะฝั่งตัวเกม (ไคลเอนต์) จะยังอยู่ในเซิร์ฟเวอร์ตราบใดที่เซิร์ฟเวอร์เปิดได้ปกติ ถ้าตอนเปิดแครชเพราะม็อดไปเรียกใช้ฝั่งตัวเกม ม็อดตัวนั้นจะถูกปิด (`.jar.disabled`) แล้วเซิร์ฟเวอร์จะเปิดใหม่เอง ม็อดที่ม็อดอื่นต้องใช้จะยังเปิดไว้
- **จัดการ (0.1.0):** คอนโซล ตัวแก้ไข properties ตัวจัดการปลั๊กอินและม็อดพร้อมอัปเดต (0.3.0) ไวท์ลิสต์ OP และการแบน ไอคอนเซิร์ฟเวอร์ (1.2.5) และการสำรองข้อมูล
- **อัปเดตเร็วขึ้น (1.4.1):** **อัปเดตทั้งหมด** ดาวน์โหลดปลั๊กอินหรือม็อดได้พร้อมกันสูงสุดสี่ตัวแล้วใส่เข้าไปพร้อมกัน หรือถ้าเซิร์ฟเวอร์ทำงานอยู่ ก็จะรอใส่ตอนรีสตาร์ตครั้งถัดไป
- **ลงรายชื่อเซิร์ฟเวอร์ของคุณ (1.4.0):** Settings → **รายชื่อเซิร์ฟเวอร์** จะนำเซิร์ฟเวอร์ไปแสดงใน สำรวจ → เซิร์ฟเวอร์ พร้อมคำอธิบาย แท็ก ภูมิภาค และภาษา เซิร์ฟเวอร์ที่คุณรันไว้ที่อื่นก็เพิ่มได้ด้วย **ส่งเซิร์ฟเวอร์**
- **แพ็กฝั่งไคลเอนต์ (1.4.0):** เผยแพร่สิ่งที่ผู้เล่นต้องใช้เพื่อเข้าเซิร์ฟเวอร์ ตั้งแต่ 1.4.1: ม็อดแพ็กของเซิร์ฟเวอร์ (ติดตั้งจากเว็บของแพ็กเอง) ม็อดอื่นแต่ละตัวจาก Modrinth หรือ CurseForge และไฟล์ของคุณเองที่ส่งตรงจากเครื่องคุณ ส่งแพ็กทรัพยากรและเชดเดอร์ไปด้วยได้ และใช้กับเซิร์ฟเวอร์ปลั๊กอินและ vanilla ได้ด้วย
- **ปุ่มรีสตาร์ตและเมนูเพิ่มเติม (1.2.7):** ปุ่มรีสตาร์ตอยู่ข้างปุ่มหยุด และมีเมนูสำหรับคัดลอกที่อยู่ เปิดโฟลเดอร์ สำรองข้อมูล การตั้งค่า และลบ
- **Online now (1.2.7)** (ออนไลน์ตอนนี้): ผู้เล่นที่อยู่ในเซิร์ฟเวอร์ของคุณ เช็กสดทุก ๆ ไม่กี่วินาที
- **Java flags (0.2.0)** (แฟล็ก Java): ใช้แฟล็กที่ ResinCraft ปรับจูนไว้ หรือของม็อดแพ็กเอง (`user_jvm_args.txt`, สคริปต์เริ่มเซิร์ฟเวอร์, 1.2.7)
- **Anti-xray (1.3.0)** (กันเอ็กซ์เรย์): เซิร์ฟเวอร์ Paper, Purpur, Folia และ Leaf ซ่อนแร่จากม็อดและเท็กซ์เจอร์แพ็กเอ็กซ์เรย์ได้ (Settings → Anti-xray ของเซิร์ฟเวอร์)
- **Anti-cheat (1.4.0)** (กันโกง): สวิตช์เดียวติดตั้งตัวกันโกง Grim บนเซิร์ฟเวอร์ปลั๊กอิน
- **สร้างโลกใหม่ (1.4.0):** เริ่มเซิร์ฟเวอร์ใหม่ด้วยโลกใหม่ โลกเก่าจะไปอยู่ในถังรีไซเคิล
- **ติดตั้งใหม่ (1.3.0):** ติดตั้งซอฟต์แวร์ของเซิร์ฟเวอร์ใหม่ หรือคืนไฟล์ม็อดแพ็กของเซิร์ฟเวอร์ให้เหมือนเดิม โลกและการตั้งค่ายังอยู่ครบ
- **ลบและสร้างได้ทันที (1.3.0):** เซิร์ฟเวอร์ที่ลบจะหายไปทันที ส่วนเซิร์ฟเวอร์ที่กำลังสร้างจะขึ้นในรายการทันทีพร้อมความคืบหน้า
- **ควบคุมระยะไกล (1.3.0):** ดูแลเซิร์ฟเวอร์ได้จากเบราว์เซอร์ไหนก็ได้หรือจากมือถือ ผ่านเว็บคอนโซลที่ `console.rscraft.resincore.tech` โดยลงชื่อเข้าใช้ด้วยบัญชี Minecraft บัญชีเดียวกัน ใช้ได้ตอนที่ ResinCraft เปิดอยู่หรือทำงานอยู่ใน system tray (การตั้งค่า → ควบคุมระยะไกล) เว็บคอนโซลทำได้ทุกอย่างที่ตัวจัดการเซิร์ฟเวอร์ทำได้ ส่วนตัวจัดการไฟล์ การตั้งค่า Java และปลั๊กอินจากลิงก์ไหนก็ได้ ต้องเปิดสวิตช์ที่สองอีกตัว คือ **อนุญาตให้ควบคุมได้เต็มที่** มีปุ่ม **เว็บคอนโซล** บนหน้า Servers ด้วย (1.3.1)
- **เครื่องอื่นของคุณ (1.4.1):** เมนูเครื่องในแท็บ Servers เปิดเซิร์ฟเวอร์บนเครื่องอื่นของคุณที่เปิดการควบคุมระยะไกลไว้ได้ ทั้งเปิด หยุด จัดการผู้เล่น ปลั๊กอิน และการตั้งค่า รวมถึงสร้างหรือนำเข้าเซิร์ฟเวอร์บนเครื่องนั้น
- **ให้เพื่อนช่วยดูแล (1.4.1):** การตั้งค่า → ควบคุมระยะไกล → **People who can use your servers** (คนที่ใช้เซิร์ฟเวอร์ของคุณได้): ให้สิทธิ์บัญชี Minecraft เป็น **Viewer** (ผู้ดู), **Operator** (ผู้ควบคุม) หรือ **Manager** (ผู้จัดการ) กับทุกเซิร์ฟเวอร์หรือเฉพาะเซิร์ฟเวอร์ที่คุณเลือก ไฟล์ การตั้งค่า Java และการสร้างหรือลบเซิร์ฟเวอร์ยังเป็นสิทธิ์ของคุณคนเดียว
- **ชวนเพื่อนมาเล่น:**
  - ResinCraft Relay (`<name>.rscraft.resincore.tech`, 0.3.0)
  - playit.gg (0.2.0)
  - bore (0.2.0)
  - เราเตอร์ของคุณ (UPnP, 0.2.0)
  - โดเมนของคุณเอง พร้อมตั้งค่า DNS บน Cloudflare ให้อัตโนมัติ (0.2.0) และยืนยันด้วยเรคคอร์ด TXT (**รอการยืนยัน**, **ยืนยันแล้ว**, 1.3.1)
  - **Automatic** (อัตโนมัติ) สำหรับเซิร์ฟเวอร์ใหม่ (1.3.2): ลองเราเตอร์ของคุณก่อน แล้วค่อย ResinCraft Relay แล้วค่อย playit.gg
- **Bedrock players can join (0.3.1)** (ผู้เล่น Bedrock เข้าได้): ผู้เล่น Bedrock เข้าเซิร์ฟเวอร์ Java ได้ด้วย (Geyser + Floodgate)
- **Whitelist requests (1.2.7)** (คำขอเข้าไวท์ลิสต์): ผู้เล่นส่งคำขอเข้าเซิร์ฟเวอร์ แล้วคุณกดรับหรือปฏิเสธได้ในแท็บ Players
  - **หน้าเว็บ:** ที่ที่อยู่ของเซิร์ฟเวอร์คุณเอง หรือโดเมนที่ยืนยันแล้ว (1.3.2 เมื่อใช้ ResinCraft Relay)
  - **บอท Discord ของคุณเอง:** ผู้เล่นพิมพ์ `/whitelist`
  - **รายชื่อเซิร์ฟเวอร์ (1.4.0):** ผู้เล่นที่ใช้ ResinCraft ส่งคำขอได้จาก สำรวจ → เซิร์ฟเวอร์
  - **คำตอบของคุณ:** กด Accept แล้วผู้เล่นจะได้เข้าไวท์ลิสต์ และบอทจะแจ้งเขาทาง DM
  - **การป้องกัน:** คำขอจากผู้เล่นที่โดนแบนจะถูกปฏิเสธ ส่วน **Reject and block** จะกันไม่ให้คนนั้นส่งคำขอมาอีก โดยมีรายการ **Blocked** (ที่บล็อกไว้) และปุ่ม **Unblock** (ปลดบล็อก) ของแต่ละคน (1.4.1)
