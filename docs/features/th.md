# ResinCraft Launcher: ฟีเจอร์

ลันเชอร์ Minecraft ที่ทันสมัยและใช้ง่าย โดย **Puirkle** ใช้ได้ทั้ง Windows, macOS และ Linux ไม่มีการเก็บข้อมูลการใช้งาน (telemetry) และไม่ต้องสมัครบัญชี ResinCraft

> NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.

รายการที่มีป้าย **(ใหม่)** คือของใหม่ในเวอร์ชันล่าสุด

## การเล่น

- **อินสแตนซ์:** แยกการติดตั้งตามเวอร์ชันหรือม็อดแพ็ก แต่ละอันมีม็อด โลก Java หน่วยความจำ และอาร์กิวเมนต์ JVM เป็นของตัวเอง
- **เล่นได้ทุกเวอร์ชันของ Minecraft:** ทุกรีลีสและสแนปช็อต ย้อนไปได้ถึงรุ่นอัลฟาคลาสสิก
- **ตัวโหลดม็อด:** Fabric, Quilt, Forge (ย้อนไปถึง Minecraft 1.2.5), NeoForge และ LiteLoader เลือกเวอร์ชันของตัวโหลดได้ แถมรองรับ OptiFine และ jar mod ด้วย
- **เปลี่ยนเวอร์ชันและตัวโหลด:** สลับเวอร์ชัน Minecraft หรือตัวโหลดม็อดของอินสแตนซ์ได้จากแท็บการตั้งค่า แบบเดียวกับใน Prism หรือจะกดชิปเวอร์ชันบนหน้าอินสแตนซ์เพื่อเปิดหน้านี้ก็ได้
- **เล่น:** คลิกเดียวจบ ใช้ **เล่นครั้งนี้ในชื่อ** เพื่อเล่นด้วยบัญชีอื่น หรือจะเปิดอินสแตนซ์เดียวกันสองหน้าต่างด้วยสองบัญชีก็ได้
- **เข้าเกมด่วน:** เซิร์ฟเวอร์และโลกเล่นคนเดียวที่เพิ่งเล่นไป คลิกเดียวก็เข้าเกมได้ทันที
- **โลก:** เล่นโลกได้โดยตรง เปลี่ยนชื่อ สำรองข้อมูล และนำเข้าโลกจากไฟล์ zip
- **ตัวช่วยแก้แครช:** เมื่อ Minecraft แครช ResinCraft จะอ่านรายงานแครชและล็อก แล้วบอกเป็นภาษาง่าย ๆ ว่าเกิดอะไรขึ้น พร้อมปุ่มแก้ในคลิกเดียว สิ่งที่แก้ให้ได้: ติดตั้งม็อดที่ขาดไป ปิดม็อดที่ทำให้แครช เลือก Java ที่ถูกต้อง และเพิ่มหน่วยความจำให้เกม
- **ติดตั้งใหม่ (ใหม่):** ดาวน์โหลดไฟล์เกมของอินสแตนซ์ใหม่ หรือคืนไฟล์ของม็อดแพ็กให้เหมือนที่มากับแพ็ก ทำได้จากเมนูของอินสแตนซ์ หรือจาก **การตั้งค่า → ซ่อมแซม** โลกของคุณยังอยู่ครบ
- **แฟล็ก Java ที่จูนมาแล้ว:** เกมจะเปิดด้วยแฟล็ก G1GC ของ ResinCraft เพื่อให้เฟรมลื่นขึ้น (การตั้งค่า → Java หรือตั้งแยกรายอินสแตนซ์)
- **Java:** หา Java ที่ติดตั้งไว้ในเครื่อง เลือกตัวที่เหมาะกับแต่ละเวอร์ชันของ Minecraft และดาวน์โหลด Eclipse Temurin ให้ถ้าไม่มีตัวไหนใช้ได้
- **ดูการใช้ RAM:** ลันเชอร์ แต่ละเกม และแต่ละเซิร์ฟเวอร์ใช้หน่วยความจำไปเท่าไร (เลือกให้แสดงที่หน้าแรกได้)
- **Discord Rich Presence:** แสดงชื่อแพ็ก เวอร์ชัน เวลาที่เล่น และบอกว่าเล่นคนเดียวหรืออยู่ในเซิร์ฟเวอร์ มีปุ่มให้เพื่อนกด: **View modpack** และ **Get ResinCraft** (ปุ่มบน Discord เป็นภาษาอังกฤษ)

## อินสแตนซ์

- **จัดระเบียบ:** แบ่งกลุ่ม เรียงลำดับเองได้ (ลากเพื่อจัด) ใส่ไอคอน แบนเนอร์ และสี
- **แท็บ:** เนื้อหา, โลก, เซิร์ฟเวอร์, ภาพหน้าจอ, บันทึกย่อ, ไฟล์ (ตัวจัดการไฟล์และตัวแก้ไขในตัว), ล็อก และการตั้งค่า
- **คัดลอกจากอินสแตนซ์อื่น:** โลก ม็อดและการตั้งค่าม็อด (โฟลเดอร์ config) เชดเดอร์แพ็ก รีซอร์สแพ็ก และการตั้งค่าเกม
- **ทำสำเนา, ส่งออก** (Modrinth `.mrpack` หรือ CurseForge `.zip`) และ **ทำเป็นม็อดแพ็กของคุณเอง**
- **คำสั่งและตัวแปรสภาพแวดล้อม:** คำสั่งที่จะรันก่อนเปิดเกมและหลังปิดเกม รวมถึงตัวแปรสภาพแวดล้อม (environment variables)
- **สลับได้ทันที:** เปิดหรือปิดม็อดได้ทันทีไม่ต้องรอ ส่วนการเปลี่ยนชื่อไฟล์จะทำอยู่เบื้องหลัง
- **ลบและสร้างได้ทันที (ใหม่):** อินสแตนซ์ที่ลบจะหายไปทันที แล้วค่อยถูกย้ายไปถังรีไซเคิลอยู่เบื้องหลัง ส่วนม็อดแพ็กที่กำลังติดตั้งจะขึ้นในคลังทันที พร้อมแสดงความคืบหน้าบนการ์ด

## เนื้อหาและหน้าสำรวจ

- **แหล่งดาวน์โหลด:** ม็อด ม็อดแพ็ก แพ็กทรัพยากร และเชดเดอร์จาก Modrinth, CurseForge, FTB, ATLauncher, Technic และรีลีสบน GitHub คัดมาให้ตรงกับเวอร์ชันและตัวโหลดของอินสแตนซ์
- **หน้าม็อดแพ็ก** มีคำอธิบาย แกลเลอรี เวอร์ชัน บันทึกการเปลี่ยนแปลง และ **ม็อดที่อยู่ในแพ็ก**
- **ติดตั้งอย่างฉลาด:** เลือกเวอร์ชันไหนก็ได้ ติดตั้งทีเดียวหลายอัน ม็อดที่ต้องใช้ร่วม (dependency) ถูกเพิ่มให้เอง และรู้ทันถ้าม็อดตัวเดียวกันมาจากสองเว็บ
- **อัปเดต:** ตรวจหาและติดตั้งอัปเดต (ทีละอันหรือทั้งหมด) รวมถึงอัปเดตม็อดแพ็กและสลับเวอร์ชันแพ็ก
- **ดาวน์โหลดเอง:** ไฟล์ CurseForge ที่ผู้สร้างไม่ให้ลันเชอร์ดาวน์โหลด ResinCraft จะหยิบมาจากโฟลเดอร์ดาวน์โหลด หรือจาก **โฟลเดอร์ที่เฝ้าดู** อื่น ๆ (การตั้งค่า → การดาวน์โหลด)
- **รายการ:** ส่งออกม็อด แพ็กทรัพยากร หรือเชดเดอร์เป็นรายการ แล้วเอารายการนั้นไปติดตั้งในอินสแตนซ์อื่นได้

## โฮสต์เซิร์ฟเวอร์

- **ประเภทเซิร์ฟเวอร์:** Vanilla, Paper, Purpur, Folia, Spigot, Leaf, Fabric, Quilt, Forge, NeoForge, Arclight (ใช้ม็อดกับปลั๊กอินพร้อมกัน) และ Bedrock Dedicated Server
- **สร้างจากม็อดแพ็กหรืออินสแตนซ์:** สร้างเซิร์ฟเวอร์จาก Modrinth, CurseForge (ใช้ server pack ทางการถ้ามี) หรือ FTB หรือจากอินสแตนซ์ของคุณเองก็ได้
- **ไม่มี server pack ทางการ? (ใหม่):** ResinCraft จะสร้างเซิร์ฟเวอร์จากรายการม็อดของแพ็กเอง บอกให้รู้ตอนสร้างเซิร์ฟเวอร์ และแสดงป้าย **Built by ResinCraft** (ResinCraft สร้างให้)
- **ไฟล์ที่ต้องดาวน์โหลดเอง (ใหม่):** ไฟล์ที่ผู้สร้างอนุญาตให้ดาวน์โหลดจากเว็บของเขาเท่านั้น จะแสดงไว้ในแท็บ **Console** (คอนโซล) ของเซิร์ฟเวอร์ ก่อนเปิดเซิร์ฟเวอร์ทุกครั้ง ResinCraft จะหาไฟล์พวกนี้ในโฟลเดอร์ดาวน์โหลดและในอินสแตนซ์ที่ใช้แพ็กเดียวกัน แล้ววางไว้ให้ถูกที่
- **หน่วยความจำตามขนาดแพ็ก (ใหม่):** เซิร์ฟเวอร์ม็อดที่สร้างใหม่จะได้ 6 GB เมื่อมีม็อดตั้งแต่ 80 ตัว และ 8 GB เมื่อมีตั้งแต่ 150 ตัว (ไม่เกินครึ่งหนึ่งของ RAM ในเครื่อง)
- **ปิดม็อดฝั่งไคลเอนต์เฉพาะตอนที่ทำให้แครช:** ม็อดที่ทำงานได้เฉพาะฝั่งตัวเกม (ไคลเอนต์) จะยังอยู่ในเซิร์ฟเวอร์ตราบใดที่เซิร์ฟเวอร์เปิดได้ปกติ ถ้าตอนเปิดแครชเพราะม็อดไปเรียกใช้ฝั่งตัวเกม ม็อดตัวนั้นจะถูกปิด (`.jar.disabled`) แล้วเซิร์ฟเวอร์จะเปิดใหม่เอง ม็อดที่ม็อดอื่นต้องใช้จะยังเปิดไว้
- **จัดการ:** คอนโซล ตัวแก้ไข properties ตัวจัดการปลั๊กอินและม็อดพร้อมอัปเดต ไวท์ลิสต์ OP และการแบน ไอคอนเซิร์ฟเวอร์ และการสำรองข้อมูล
- **ปุ่มรีสตาร์ตและเมนูเพิ่มเติม:** ปุ่มรีสตาร์ตอยู่ข้างปุ่มหยุด และมีเมนูสำหรับคัดลอกที่อยู่ เปิดโฟลเดอร์ สำรองข้อมูล การตั้งค่า และลบ
- **Online now** (ออนไลน์ตอนนี้): ผู้เล่นที่อยู่ในเซิร์ฟเวอร์ของคุณ เช็กสดทุก ๆ ไม่กี่วินาที
- **Java flags** (แฟล็ก Java): ใช้แฟล็กที่ ResinCraft ปรับจูนไว้ หรือของม็อดแพ็กเอง (`user_jvm_args.txt`, สคริปต์เริ่มเซิร์ฟเวอร์)
- **Anti-xray (ใหม่)** (กันเอ็กซ์เรย์): เซิร์ฟเวอร์ Paper, Purpur, Folia และ Leaf ซ่อนแร่จากม็อดและเท็กซ์เจอร์แพ็กเอ็กซ์เรย์ได้ (Settings → Anti-xray ของเซิร์ฟเวอร์)
- **ติดตั้งใหม่ (ใหม่):** ติดตั้งซอฟต์แวร์ของเซิร์ฟเวอร์ใหม่ หรือคืนไฟล์ม็อดแพ็กของเซิร์ฟเวอร์ให้เหมือนเดิม โลกและการตั้งค่ายังอยู่ครบ
- **ลบและสร้างได้ทันที (ใหม่):** เซิร์ฟเวอร์ที่ลบจะหายไปทันที ส่วนเซิร์ฟเวอร์ที่กำลังสร้างจะขึ้นในรายการทันทีพร้อมความคืบหน้า
- **ควบคุมระยะไกล (ใหม่):** ดูแลเซิร์ฟเวอร์ได้จากเบราว์เซอร์ไหนก็ได้หรือจากมือถือ ผ่านเว็บคอนโซลที่ `console.rscraft.resincore.tech` โดยลงชื่อเข้าใช้ด้วยบัญชี Minecraft บัญชีเดียวกัน ใช้ได้ตอนที่ ResinCraft เปิดอยู่หรือทำงานอยู่ใน system tray (การตั้งค่า → ควบคุมระยะไกล) เว็บคอนโซลเปิด หยุด ดู และสร้างเซิร์ฟเวอร์ได้ แต่เข้าถึงไฟล์หรือการตั้งค่าอื่น ๆ ของคุณไม่ได้เลย
- **ชวนเพื่อนมาเล่น:**
  - ResinCraft Relay (`<name>.rscraft.resincore.tech`)
  - playit.gg
  - bore
  - เราเตอร์ของคุณ (UPnP)
  - โดเมนของคุณเอง พร้อมตั้งค่า DNS บน Cloudflare ให้อัตโนมัติ
- **Bedrock players can join** (ผู้เล่น Bedrock เข้าได้): ผู้เล่น Bedrock เข้าเซิร์ฟเวอร์ Java ได้ด้วย (Geyser + Floodgate)
- **Whitelist requests** (คำขอเข้าไวท์ลิสต์): ผู้เล่นส่งคำขอเข้าเซิร์ฟเวอร์ แล้วคุณกดรับหรือปฏิเสธได้ในแท็บ Players
  - **หน้าเว็บ:** `https://rscraft.resincore.tech/join/<name>` (เมื่อใช้ ResinCraft Relay)
  - **บอท Discord ของคุณเอง:** ผู้เล่นพิมพ์ `/whitelist`
  - **คำตอบของคุณ:** กด Accept แล้วผู้เล่นจะได้เข้าไวท์ลิสต์ และบอทจะแจ้งเขาทาง DM
  - **การป้องกัน:** คำขอจากผู้เล่นที่โดนแบนจะถูกปฏิเสธ ส่วน **Reject and block** จะกันไม่ให้คนนั้นส่งคำขอมาอีก

## บัญชี

- **ลงชื่อเข้าใช้ด้วย Microsoft** โดยเก็บโทเค็นแบบเข้ารหัส และ **โปรไฟล์ออฟไลน์** สำหรับเล่นคนเดียวและเล่น LAN
- **สกิน ผ้าคลุม และเปลี่ยนชื่อ**

## ย้ายมาจากลันเชอร์อื่น

- นำเข้าอินสแตนซ์จาก Prism Launcher, MultiMC, Modrinth App, แอป CurseForge, ATLauncher, GDLauncher และ Minecraft Launcher ตัวทางการ พร้อมม็อด โลก แพ็ก และการตั้งค่า นำเข้าเซิร์ฟเวอร์ได้ด้วย

## ตัวแอป

- **Windows, macOS** (Apple Silicon และ Intel) **และ Linux** (x64 และ ARM64: AppImage, `.deb`, `.tar.gz`)
- **ตัวติดตั้งบน Windows:** ไฟล์ `.exe` ไฟล์ `.msi` สำหรับองค์กรที่จัดการการติดตั้งจากส่วนกลาง และ **ResinCraft Setup (ใหม่)**: ตัวติดตั้งขนาดเล็กที่ติดตั้งเวอร์ชันล่าสุดให้เสมอ จากลิงก์ที่ไม่มีวันเปลี่ยน
- **อัปเดต:** ตรวจหาให้อัตโนมัติ
  - ปุ่ม **อัปเดต** บนแถบชื่อหน้าต่าง
  - **ปิดแล้วอัปเดต** เมื่อมีเกมหรือเซิร์ฟเวอร์เปิดอยู่
  - **อัปเดตแบบเงียบ** อยู่เบื้องหลัง
- **ทำงานต่อใน system tray:** ปิดหน้าต่างไปแล้ว เซิร์ฟเวอร์ บอท Discord การควบคุมระยะไกล และการดาวน์โหลดก็ยังทำงานต่อ
- **ติดตั้ง ResinCraft ใหม่ (ใหม่):** การตั้งค่า → อัปเดต จะติดตั้งแอปทับตัวเองเพื่อซ่อมแซม อินสแตนซ์ บัญชี และการตั้งค่ายังอยู่ครบ
- **ธีม (ใหม่):** มืด, สว่าง, ออบซิเดียน, ดีปสเลต, เชอร์รี่, เนเธอร์, ดิเอนด์, ฮาโลวีน และคริสต์มาส หรือจะใช้ตามระบบก็ได้
