# ResinCraft Launcher：功能

由 **Puirkle** 打造的现代、易用的 Minecraft 启动器，支持 Windows、macOS 和 Linux。没有遥测，也不需要 ResinCraft 账户。

> NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.

括号里的版本号是每项功能首次推出的版本。最新的是 1.4.0 和 1.4.1。

## 游玩

- **实例（0.1.0）：** 每个版本或整合包单独安装，各自拥有自己的模组、世界、Java、内存和 JVM 参数。
- **任意 Minecraft 版本（0.1.0）：** 所有正式版和快照，一直到早期的经典版 Alpha。
- **模组加载器（0.1.0）：** Fabric、Quilt、Forge 和 NeoForge，可以选择加载器版本。适用于 1.7.10 到 1.12.2 的经典 Forge（1.1.2），最早到 Minecraft 1.2.5 的 Forge 和 LiteLoader（1.2.0）。也支持 OptiFine（1.0.1）和 jar 模组（1.2.0）。
- **更改版本和加载器（1.2.7）：** 像 Prism 一样，在实例的**设置**标签页里切换 Minecraft 版本或模组加载器。点击实例页面上的版本标签也能打开。
- **启动（0.1.0）：** 一键开玩。可以换用其他账户游玩，也可以用两个账户同时运行同一个实例（1.0.5）。
- **快速加入（1.1.0）：** 列出你最近玩过的服务器和单人世界（1.2.3），一键直接进入。
- **世界（0.1.0）：** 重命名、备份，或从 zip 导入世界。直接进入世界游玩（1.2.0）。
- **世界自动备份（1.4.0）：** 游戏或服务器运行时，它的世界每 30 分钟备份一次，每个世界保留最新的 3 份（设置 → 自动备份）。
- **恢复备份（1.4.0）：** 从任意备份恢复世界，你自己的备份或自动备份都可以，也可以恢复成一个副本。被替换的世界会移到回收站。
- **崩溃修复（1.2.7）：** Minecraft 崩溃时，ResinCraft 会读取崩溃报告和日志，用简单的话告诉你出了什么问题，并提供一键修复。可以修复：安装缺少的模组、关闭导致崩溃的模组、选择合适的 Java、给游戏更多内存。
- **重新安装（1.3.0）：** 重新下载实例的游戏文件，或把整合包自己的文件恢复成整合包原本的样子。可以在实例的菜单或**设置 → 修复**中操作。世界会保留。
- **调优的 Java 参数（1.2.7）：** 游戏使用 ResinCraft 的 G1GC 参数启动，帧率更平稳（设置 → Java，或按实例单独设置）。
- **Java（0.1.0）：** 自动找到已安装的 Java，按 Minecraft 版本选择合适的那个；都不合适时会下载 Eclipse Temurin。
- **内存显示（1.2.1）：** 显示启动器、每个游戏和每个服务器用了多少内存（可选在主页显示）。
- **Discord Rich Presence（1.2.3）：** 显示整合包名称、版本、游玩时长，以及在玩单人还是服务器。给好友的按钮（1.2.6）：**View modpack**（查看整合包）和 **Get ResinCraft**（获取 ResinCraft）。

## 实例

- **整理：** 分组（0.2.0）、自定义顺序（0.3.1，拖动排列）、图标和横幅（0.3.0），以及颜色（0.1.0）。
- **标签页（0.1.0）：** 内容、世界、服务器、截图、笔记、文件（内置文件管理器和编辑器，0.2.0）、日志和设置。
- **从其他实例复制（1.2.5）：** 世界、光影包、资源包和游戏设置；模组及其设置（config 文件夹）从 1.2.6 起支持。
- **创建副本（0.1.0）、导出**（Modrinth `.mrpack` 或 CurseForge `.zip`，1.0.5），以及**做成你自己的整合包（1.1.0）**。
- **多选（1.1.0）：** 一次移动、删除、复制或更新多个实例。
- **命令和环境变量（1.2.0）：** 设置启动前和游戏关闭后运行的命令，以及环境变量。
- **即时开关（1.2.7）：** 开启或关闭模组立即生效，重命名在后台完成。
- **即时删除和创建（1.3.0）：** 删除的实例会立刻消失，并在后台移到回收站。正在安装的整合包会马上出现在游戏库中，卡片上显示安装进度。

## 内容与发现

- **来源网站（0.1.0）：** 来自 Modrinth、CurseForge、FTB、ATLauncher、Technic 和 GitHub Releases（0.3.1）的模组、整合包、资源包和光影，按实例的版本和加载器筛选。
- **整合包页面（1.2.0）：** 包含简介、图库、版本、更新日志，以及**整合包里包含的模组（1.2.5）**。
- **智能安装（0.3.0）：** 任选版本，一次安装多个，自动添加必需的前置模组，还能发现从两个网站装了同一个模组的情况。
- **更新（0.1.0）：** 检查并应用更新（单个或全部），支持整合包更新和版本切换（1.1.0）。**全部更新**最多同时下载四个（1.4.1）。
- **手动下载（1.0.1）：** 作者禁止启动器下载的 CurseForge 文件，会从你的下载文件夹或其他**监视文件夹**（1.0.5，设置 → 下载）中自动获取。
- **列表（0.4.0）：** 把模组、资源包或光影导出为列表，再把列表安装到另一个实例。
- **查找服务器（1.4.0）：** 发现 → **服务器**列出用 ResinCraft 开设的服务器和玩家添加的服务器。可以搜索，并按分类、地区、语言、整合包、是否支持基岩版或离线账户筛选；还能点赞和举报。
- **每个服务器都有自己的页面（1.4.1）：** 完整简介和 MOTD、所有详情、客户端整合包、链接，以及白名单申请框。
- **一键加入（1.4.0）：** **加入**会挑选合适的实例，或者问你。**安装并加入**会创建一个恰好包含服务器模组的实例，然后加入。
- **申请加入白名单（1.4.0）：** **申请加入**会发送一个用你的 Minecraft 账户签名的申请。按钮会显示 **Waiting for the host**（等待服主）、**On the whitelist**（已在白名单中）或 **Ask again**（再次申请），服主回复时 ResinCraft 会通知你（并让任务栏闪烁）（1.4.1）。

## 开服

- **服务器类型（0.1.0）：** Vanilla、Paper、Purpur、Folia、Spigot、Fabric、Quilt、Forge 和 NeoForge；Leaf、Arclight（模组和插件同时使用）以及 Bedrock Dedicated Server 从 0.3.1 起支持。
- **从整合包或实例创建（0.1.0）：** 用 Modrinth、CurseForge（有官方服务端包时使用它）或 FTB 的整合包创建服务器，也可以从你的某个实例创建。
- **没有官方服务端包？（1.2.11）：** ResinCraft 会根据整合包自己的模组列表搭建服务器，创建时会告诉你，并显示 **Built by ResinCraft**（由 ResinCraft 搭建）标记。
- **需要自己下载的文件（1.2.9）：** 作者只允许从其网站下载的文件，会列在服务器的 **Console**（控制台）标签页中。每次启动前，ResinCraft 会在你的下载文件夹和同一整合包的实例中查找它们，并放到正确的位置。
- **按整合包大小分配内存（1.2.9）：** 新建的模组服务器在有 80 个模组时分配 6 GB，150 个时分配 8 GB（最多为电脑内存的一半）。
- **仅客户端模组只在导致崩溃时才关闭（1.2.8）：** 只要服务器能正常启动，客户端模组就会留在服务器上。如果某次启动因为某个模组调用了游戏客户端而崩溃，就会关闭那个模组（`.jar.disabled`）并自动重启服务器。其他模组依赖的模组会保持开启。
- **管理（0.1.0）：** 控制台、属性编辑器、支持更新的插件和模组管理（0.3.0）、白名单、管理员和封禁、服务器图标（1.2.5）、备份。
- **更快的更新（1.4.1）：** **全部更新**最多同时下载四个插件或模组，并一起装上；服务器运行时则排队等到下次重启。
- **把服务器加入列表（1.4.0）：** Settings → **服务器列表**会把它放进“发现 → 服务器”，附上简介、标签、地区和语言。在别处运行的服务器可以用**提交服务器**添加。
- **客户端整合包（1.4.0）：** 发布玩家加入时需要的内容。从 1.4.1 起：服务器的整合包（从它自己的网站安装）、来自 Modrinth 或 CurseForge 的其他每个模组，以及直接从你电脑发送的自己的文件；资源包和光影也能一起发送；插件服务器和原版服务器也支持。
- **重启和更多菜单（1.2.7）：** Stop（停止）旁边有“重新启动”；菜单里有复制地址、打开文件夹、备份、设置和删除。
- **当前在线（1.2.7）：** 每隔几秒实时查看服务器上的玩家。
- **Java 参数（0.2.0）：** 使用 ResinCraft 调好的参数，或整合包自带的参数（`user_jvm_args.txt`、启动脚本，1.2.7）。
- **Anti-xray（反矿透）（1.3.0）：** Paper、Purpur、Folia 和 Leaf 服务器可以对 X 光模组和材质包隐藏矿石（服务器的 Settings → Anti-xray）。
- **Anti-cheat（反作弊）（1.4.0）：** 一个开关就能在插件服务器上安装 Grim 反作弊。
- **重新生成世界（1.4.0）：** 用一个新世界让服务器重新开始；旧世界会移到回收站。
- **重新安装（1.3.0）：** 重新安装服务器软件，或恢复它的整合包文件。世界和设置会保留。
- **即时删除和创建（1.3.0）：** 删除的服务器会立刻消失；正在创建的服务器会马上出现在列表中，并显示进度。
- **远程控制（1.3.0）：** 只要 ResinCraft 开着或在系统托盘中运行，就能在任意浏览器或手机上通过 `console.rscraft.resincore.tech` 网页控制台管理服务器，用同一个 Minecraft 账户登录（设置 → 远程控制）。服务器管理能做的，它都能做。文件管理器、Java 设置和来自任意链接的插件需要再打开第二个开关：**允许完全控制**。Servers 页面上有一个**网页控制台**按钮（1.3.1）。
- **你的其他电脑（1.4.1）：** Servers 标签页的电脑菜单可以打开你其他已开启远程控制的电脑上的服务器：启动、停止，管理玩家、插件和设置，还能在那里创建或导入服务器。
- **让好友帮忙（1.4.1）：** 设置 → 远程控制 → **People who can use your servers**（可以使用你服务器的人）：给某个 Minecraft 账户 **Viewer**（查看者）、**Operator**（操作员）或 **Manager**（管理者）权限，适用于你的所有服务器或你选的那些。文件、Java 设置，以及创建或删除服务器，仍然只有你能做。
- **与好友共享：**
  - ResinCraft Relay（`<name>.rscraft.resincore.tech`，0.3.0）
  - playit.gg（0.2.0）
  - bore（0.2.0）
  - 你的路由器（UPnP，0.2.0）
  - 你自己的域名，支持 Cloudflare DNS 自动配置（0.2.0），用 TXT 记录验证（**等待验证**、**已验证**，1.3.1）
  - 新服务器默认 **Automatic**（自动，1.3.2）：先用你的路由器，然后是 ResinCraft Relay，再然后是 playit.gg
- **基岩版玩家也能加入（0.3.1）** Java 版服务器（Geyser + Floodgate）。
- **Whitelist requests（白名单申请）（1.2.7）：** 玩家申请加入，你在 **Players** 标签页中同意或拒绝。
  - **Web page（网页）：** 在你服务器自己的地址或你已验证的域名上（1.3.2，使用 ResinCraft Relay 时）。
  - **你自己的 Discord 机器人：** 玩家输入 `/whitelist`。
  - **服务器列表（1.4.0）：** 使用 ResinCraft 的玩家可以在“发现 → 服务器”中申请。
  - **你的答复：** 同意后会把玩家加入白名单，机器人会私信通知对方。
  - **保护：** 被封禁的玩家会被拒绝；**Reject and block**（拒绝并屏蔽）可以让对方无法再次申请，还有 **Blocked**（已屏蔽）列表，每位玩家都有 **Unblock**（解除屏蔽）按钮（1.4.1）。

## 基岩版（Windows）

- **基岩版页面（0.3.1）：** 安装（1.0.0）、更新和修复（1.2.0）、启动和卸载（1.2.3）Minecraft for Windows 与 Minecraft Preview（会先备份世界）。

## 账户

- **Microsoft 登录（0.1.0）**，令牌加密保存。用于单人和局域网的**离线账户（0.1.0）**。为没有 Java 版的 Microsoft 账户提供**基岩版账户（1.0.0）**。
- **皮肤、披风和改名（0.1.0）。** 皮肤库、按玩家名获取皮肤和在线搜索（1.0.3）；3D 皮肤预览（1.1.0）。

## 从其他启动器迁移

- **导入（1.0.5）：** 从 Prism Launcher、MultiMC、Modrinth App、CurseForge 应用、ATLauncher、GDLauncher 和官方 Minecraft Launcher 导入实例，连同模组、世界、资源包和设置一起。服务器也可以导入。
- **迁移到另一台电脑（1.1.1）：** 设置 → 迁移到另一台电脑会把所有内容保存到一个 `.resincraft` 文件；在新电脑上打开它即可。

## 应用

- **Windows（0.1.0）、macOS**（Apple Silicon 和 Intel）**和 Linux**（x64 和 ARM64：AppImage、`.deb`，1.2.0；`.tar.gz`，1.2.4）。
- **Windows 安装程序：** `.exe`（0.1.0）、用于集中管理部署的 `.msi`（1.2.10），以及 **ResinCraft Setup（1.3.0）**：一个小巧的安装程序，总是安装最新版本，下载链接永远不变。
- **更新（0.3.0）：** 自动检查。
  - 标题栏中的**更新**按钮（1.2.7）。
  - 有游戏或服务器在运行时，可以**关闭并更新**（1.2.7）。
  - 在后台**静默更新**（1.2.7）。
- **在系统托盘中保持运行（1.2.7）：** 关闭窗口后，服务器、Discord 机器人、远程控制和下载会继续运行。
- **重新安装 ResinCraft（1.3.0）：** 在设置 → 更新中把应用覆盖重新安装一遍，用来修复。实例、账户和设置都会保留。
- **主题：** 深色、浅色和跟随系统（0.1.0）；黑曜石、深板岩、樱花、下界和末地（1.3.0）。
  - **创建主题（1.3.0）：** 你自己的主题，可以用**微调**改任意颜色（取色器），还能为应用的各个部分写 CSS（1.3.2）。
  - **分享主题（1.3.2）：** **导出**为 `.rctheme` 文件，带上图片和 CSS；用**导入主题**导入，或双击该文件（1.4.0）。
  - **自定义 CSS（1.3.0）：** 在任意主题上叠加你自己的 CSS，从当前颜色开始改，还内置了指南，介绍颜色、应用的各个部分和现成的示例。
  - 还有一个隐藏彩蛋（1.3.0）。试试 Konami 秘技。
- **16 种语言（0.1.0）：** English, Deutsch, Español, Français, Bahasa Indonesia, Italiano, 日本語, 한국어, Polski, Português (Brasil), Русский, ไทย, Türkçe, Tiếng Việt, 简体中文, 繁體中文.
- **存储管理（1.1.0）：** 把实例放在另一块硬盘上。可以**移动实例**过去，或**不移动，直接使用**（1.4.1）。
- 设置中的**重置设置**和**卸载 ResinCraft（1.4.0）**。
