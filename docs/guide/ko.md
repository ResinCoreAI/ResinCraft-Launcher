## 1. 설치하고 로그인하기

1. [릴리스 페이지](https://github.com/ResinCoreAI/ResinCraft-Launcher/releases/latest)에서 내 시스템에 맞는 ResinCraft를 내려받아요.
   - **Windows:** [`ResinCraft-Setup.exe`](https://github.com/ResinCoreAI/ResinCraft-Launcher/releases/download/setup/ResinCraft-Setup.exe)(항상 최신 버전을 설치해요) 또는 `…_amd64_windows.exe` / `…_amd64_windows.msi`
   - **macOS:** `…_universal_macos.dmg`
   - **Linux:** `.AppImage`, `.deb` 또는 `.tar.gz`
2. 설치하고 실행해요. Windows에서는 게시자를 확인할 수 없다는 메시지가 나올 수 있어요. macOS에서는 처음 한 번만 앱을 오른쪽 클릭하고 **열기**를 고르세요.
3. **계정** → **Microsoft로 로그인**을 열고, Microsoft 공식 페이지에서 로그인해요. 비밀번호는 ResinCraft를 거치지 않아요.
   - Microsoft 계정이 없나요? 싱글플레이와 LAN용으로 **오프라인 프로필**을 추가하세요.

## 2. 첫 인스턴스 만들기

*인스턴스*는 모드, 월드, 설정을 따로 가진 독립된 Minecraft 설치예요.

1. **라이브러리** → **새 인스턴스**를 열어요.
2. **Minecraft 버전**과 **모드 로더**를 골라요.
   - **Vanilla:** 모드 없음.
   - **Fabric** 또는 **Quilt:** 가벼운 모드, 최적화 모드.
   - **Forge** 또는 **NeoForge:** 규모가 큰 콘텐츠 모드.
3. 이름을 정하고 **인스턴스 만들기**를 눌러요.
4. **플레이**를 눌러요. 처음 실행할 때는 게임과 알맞은 Java를 내려받고, 그다음부터는 금방 시작돼요.

팁: 왼쪽의 **빠른 참가**에 최근 서버와 월드가 모여 있어요. 클릭 한 번이면 바로 들어가요.

## 3. 모드, 리소스 팩, 셰이더 추가하기

1. 인스턴스를 열고 **콘텐츠** 탭 → **모드 추가**를 눌러요. 왼쪽 바에서 **둘러보기**를 열어도 돼요.
2. 검색하거나 Modrinth, CurseForge, FTB 같은 사이트를 둘러봐요. 인스턴스에 맞는 버전만 보여요.
3. **설치**를 눌러요. 필요한 모드(선행 모드)는 자동으로 추가돼요.
4. 다시 **콘텐츠**에서:
   - 모드 옆의 스위치로 켜고 끌 수 있어요.
   - **업데이트 확인**을 누르면 모드를 업데이트할 수 있어요(하나씩 또는 전부).

일부 CurseForge 제작자는 런처가 파일을 내려받지 못하게 막아 두었어요. 그럴 때 ResinCraft는 그 파일들을 **모두 다운로드** 아래에 보여 줘요. 브라우저에서 내려받으면 ResinCraft가 다운로드 폴더에서 알아서 찾아요. 브라우저가 다른 곳에 저장하나요? **설정 → 다운로드 → 감시 폴더**에 그 폴더를 추가하세요.

## 4. 모드팩 설치하기

1. **둘러보기** → **모드팩**을 열어요(또는 **라이브러리** → **새 인스턴스** → **모드팩 다운로드**).
2. 팩을 열면 설명, 버전, 팩에 들어 있는 **모드**를 볼 수 있어요.
3. **팩 설치**를 눌러요. 새 인스턴스가 **라이브러리**에 바로 나타나고, 카드에 설치 진행 상황이 표시돼요. 설치가 끝나면 **플레이**할 수 있어요.
4. 팩에 업데이트가 나오면 ResinCraft가 알려 줘요. 인스턴스 페이지에서 다른 팩 버전을 고를 수도 있어요.

## 5. Minecraft 버전이나 모드 로더 바꾸기

1. 인스턴스 페이지 위쪽의 버전 표시(예: **1.21.4 · Fabric 0.16.10**)를 클릭해요. **설정 → 버전**이 열려요.
2. **Minecraft** 버전, **모드 로더**, 로더 버전을 골라요.
3. **버전 변경**을 누르고 확인해요. 다음에 실행할 때 필요한 것을 내려받아요.
4. 예전 버전용 모드는 작동하지 않을 수 있어요. **콘텐츠**로 가서 **업데이트 확인**을 누르세요.

## 6. Minecraft가 충돌했을 때

게임이 충돌하면 **(인스턴스 이름) 이(가) 충돌했습니다** 창이 열려요. ResinCraft가 충돌 보고서와 로그를 읽고 무엇이 잘못됐는지 알려 줘요. 예를 들면 이렇게요(이 메시지는 영어로 표시돼요).

- *Sodium Extra needs Sodium, which isn't installed*(Sodium Extra에 필요한 Sodium이 설치되어 있지 않음) → **고치기**를 누르면 Sodium을 설치해요.
- *citresewn crashed the game*(citresewn 때문에 게임이 충돌함) → **고치기**를 누르면 그 모드를 꺼요(나중에 **콘텐츠**에서 다시 켤 수 있어요).
- *This needs Java 21 or newer*(Java 21 이상 필요) → **고치기**를 누르면 ResinCraft가 알맞은 Java를 골라요.
- *Minecraft ran out of memory*(Minecraft 메모리 부족) → **고치기**를 누르면 메모리를 더 줘요.

하나씩 **고치기**를 누르거나 **모두 고치고 플레이**를 누르세요. 버튼을 누르기 전에는 아무것도 바뀌지 않아요. ResinCraft가 원인을 모를 때는 **로그 열기**로 게임이 마지막에 남긴 내용을 볼 수 있어요.

## 7. 다른 인스턴스에서 복사하기

1. 복사해 *넣을* 인스턴스를 열고 → 위쪽의 **다른 인스턴스에서 복사** 버튼을 눌러요.
2. 내용을 *가져올* 인스턴스를 골라요.
3. 원하는 것에 체크해요.
   - **세계**
   - **모드**와 **모드 설정**(config 폴더)
   - **셰이더 팩**과 **리소스 팩**
   - **게임 설정**(비디오, 조작, 키 설정)
4. **복사**를 눌러요. 이미 같은 이름이 있는 월드는 새 이름이 붙어요. 이미 있는 모드와 팩은 그대로 둬요.

## 8. 서버 열기

서버 관련 화면은 아직 일부가 영어로 표시돼요.

1. **Servers**(서버) → **Create server**(서버 만들기)를 열어요.
2. 만드는 방법을 골라요.
   - **Server software**(서버 소프트웨어): Paper, Fabric, Forge, NeoForge, Vanilla, Bedrock…
   - **Modpack**(모드팩): 친구들이 하는 것과 같은 팩.
   - **From an instance**(인스턴스에서): 지금 쓰고 있는 모드 그대로.
   - **From a file**(파일에서).
3. **Create**(만들기)를 눌러요. 창이 닫히고 다운로드는 오른쪽 아래에서 계속돼요.
4. Minecraft EULA 동의를 물어보면 동의하고 **Start**(시작)를 눌러요.

서버 페이지에서는:

- **Console**(콘솔): 서버가 출력하는 내용이에요. 아래쪽에서 명령어를 입력할 수 있어요.
- **Players**(플레이어): 지금 접속 중인 사람, 그리고 화이트리스트, OP, 차단 목록.
- **Mods** 또는 **Plugins**(모드 / 플러그인): 추가, 업데이트, 끄기.
- **Properties**(속성): 서버 설정(난이도, 화이트리스트 켜기/끄기 등).
- **Settings**(설정):
  - 메모리, Java, **Java flags**(Java 플래그: ResinCraft 것 또는 모드팩 자체 것)
  - 친구가 접속하는 방법
  - 서버 아이콘
- **다시 시작**과 **⋯** 메뉴(주소 복사, 폴더 열기, 지금 백업, 삭제).

- **Settings → Anti-xray**(설정 → 엑스레이 방지, Paper, Purpur, Folia, Leaf): 엑스레이 모드와 텍스처 팩으로부터 광석을 숨겨요. **Hide ores**(광석 숨기기)는 서버 부담이 적고, **Fake ores**(가짜 광석)는 더 강력해요. 다음 시작부터 적용돼요.

게임 클라이언트에서만 돌아가는 모드(셰이더, 미니맵 등)는 서버가 문제없이 시작되는 한 서버에 그대로 둬요. 그런 모드 때문에 충돌하면 ResinCraft가 그 모드를 끄고 서버를 다시 시작해요. **Mods** 탭에서 다시 켤 수 있어요.

모드팩에 공식 서버 팩이 없으면 ResinCraft가 팩 자체의 모드 목록으로 서버를 만들어요. **Create**(만들기) 다음에 나오는 창에서 그렇게 알려 주고, 서버에는 **Built by ResinCraft**(ResinCraft가 만듦) 배지가 붙어요. 팩 파일 중에는 제작자 웹사이트에서만 내려받을 수 있는 것도 있어요. 그런 파일은 **Console** 탭 위쪽에 **Get file**(파일 받기)과 함께 나와요. 브라우저에서 내려받으면 다음에 시작하기 전에 ResinCraft가 제자리에 넣어요. 바로 찾게 하려면 **Look again**(다시 찾기)을 누르세요.

## 9. 친구를 서버에 초대하기

서버의 **Settings** → **How friends connect**(친구 접속 방법)에서 골라요.

- **Automatic**(자동, 추천): **ResinCraft Relay**를 먼저 시도하고, 그다음 playit.gg, 그다음 bore를 시도해요.
- **ResinCraft Relay:** 친구들은 `yourname.rscraft.resincore.tech`로 접속해요. Microsoft 계정으로 로그인되어 있어야 해요.
- **playit.gg:** 바뀌지 않는 무료 주소예요. 처음 시작할 때 playit.gg 계정을 연결하라고 해요(게스트 계정도 괜찮아요).
- **직접 포트 포워딩함:** 공유기를 직접 설정했다면 이걸 고르세요.

친구에게 알려 줄 주소는 **Console** 탭에 나와요. 베드락 친구도 Java 서버에 들어올 수 있어요. **Bedrock players can join**(베드락 플레이어 참가 허용)을 켜세요.

## 10. 화이트리스트 신청 (웹 페이지와 Discord 봇)

플레이어가 참가를 신청하게 하고, 수락이나 거절은 직접 정해요.

1. **Properties**에서 **white-list**를 **true**로 바꿔요(안 그러면 누구나 그냥 들어올 수 있어요).
2. 서버의 **Players** 탭을 열고 **Whitelist requests**(화이트리스트 신청)를 켜요.
3. 플레이어가 신청하는 방법을 골라요.
   - **Web page**(웹 페이지):
     - 서버를 ResinCraft Relay로 공유할 때 쓸 수 있어요.
     - **Copy link**(링크 복사)를 누르고 플레이어에게 링크를 보내요: `https://rscraft.resincore.tech/join/<name>`.
     - 페이지는 서버가 온라인일 때만 작동해요.
   - **Your Discord bot**(내 Discord 봇):
     1. [Discord Developer Portal](https://discord.com/developers/applications)을 열고 → **New Application** → **Bot** → **Reset Token**을 누른 다음 토큰을 복사해요.
     2. ResinCraft에 붙여 넣고 **Save**(저장)를 눌러요. 토큰은 내 PC에 안전하게 보관되고 다시 표시되지 않아요.
     3. **Online as …**가 보이면 **Add the bot to your Discord**(Discord에 봇 추가)를 누르고 내 Discord 서버를 골라요.
     4. 플레이어는 내 Discord에서 `/whitelist TheirName`을 입력해요.
4. 신청은 **Players** 탭에 나타나요.
   - **Accept**(수락): 플레이어를 화이트리스트에 추가해요(봇이 DM으로 알려 줘요).
   - **Reject**(거절): 신청을 거절해요.
   - **Reject and block**(거절하고 차단): 신청을 거절하고 그 사람이 다시 신청하지 못하게 해요. **Unblock all**(모두 차단 해제)로 Discord 차단을 풀 수 있어요.

차단(밴)된 플레이어의 신청은 자동으로 거절돼요. Discord 봇은 ResinCraft가 열려 있을 때만 작동해요. 창을 닫아도 계속 돌아가게 하려면 시스템 트레이를 켜세요(13장).

## 11. 베드락 에디션

Windows에서는 왼쪽의 **베드락**에서 Minecraft for Windows와 Minecraft Preview를 설치, 실행, 제거할 수 있어요. 제거할 때는 월드를 먼저 백업해요.

## 12. 다른 런처에서 옮기기

**라이브러리** → **다른 런처에서 옮기기**로 다음 런처의 인스턴스를 가져올 수 있어요.

- Prism Launcher와 MultiMC
- Modrinth App과 CurseForge 앱
- ATLauncher와 GDLauncher
- 공식 Minecraft Launcher

모드, 월드, 설정도 함께 옮겨져요. 원본은 그대로 남아 있어요.

## 13. 업데이트와 시스템 트레이

- **업데이트:**
  - 새 ResinCraft 버전이 준비되면 제목 표시줄에 **업데이트** 버튼이 나타나요.
  - 게임이나 서버가 실행 중이면 **닫고 업데이트**(서버는 먼저 월드를 저장해요)나 **멈추면 업데이트**를 고를 수 있어요.
- **조용히 업데이트**(설정 → 업데이트): 아무것도 실행 중이지 않을 때 묻지 않고 백그라운드에서 새 버전을 설치해요.
- **시스템 트레이에서 계속 실행**(설정 → 외관):
  - 창을 닫아도 ResinCraft가 계속 실행돼요. 서버, Discord 봇, 다운로드가 계속 돌아가요.
  - 트레이 아이콘을 클릭하면 다시 열려요. 완전히 끄려면 오른쪽 클릭 → **Quit ResinCraft**(ResinCraft 종료)를 누르세요.

## 14. 테마와 사용자 CSS

1. **설정 → 외관 → 테마**를 열고 카드를 골라요: **시스템**, 다크, 라이트, 흑요석, 심층암, 벚나무, 네더, 엔드.
2. **사용자 CSS:** **현재 색 넣기**를 누르고 원하는 색을 바꾼 다음 **적용**을 눌러요. 어떤 테마 위에도 적용되고, **지우기**로 없앨 수 있어요.
3. 입력란 아래의 **사용자 지정 방법**을 열어요. 바꿀 수 있는 색과 모양, 꾸밀 수 있는 앱의 각 부분, 예시(배경 사진, 더 둥근 모서리, 더 큰 글자…)가 나와 있어요. 하나를 클릭하면 내 CSS에 추가돼요.

쉿: 코나미 커맨드(↑ ↑ ↓ ↓ ← → ← → B A)를 입력하거나 ResinCraft 로고를 일곱 번 클릭해 보세요.

## 15. 원격 제어 (웹 콘솔)

어떤 브라우저에서든, 휴대폰에서든 서버를 다룰 수 있어요.

1. **계정**에서 Microsoft 계정으로 로그인해요.
2. **설정 → 원격 제어 → 원격 제어 허용**을 켜요. **…(으)로 연결됨**이 보이면 준비 끝이에요.
3. 창을 닫아도 계속 작동하도록 **시스템 트레이에서 계속 실행**을 켜요(13장).
4. `https://console.rscraft.resincore.tech`를 열고(또는 **웹 콘솔 열기**를 누르고) **같은 Minecraft 계정**으로 로그인해요.

콘솔에서는 서버 관리에서 할 수 있는 건 모두 할 수 있어요. 서버를 시작, 중지, 다시 시작하고, 콘솔을 보면서 명령어를 입력하고, 플레이어와 화이트리스트 신청을 관리하고, 플러그인과 모드를 추가하고 업데이트하고, 속성과 설정을 바꾸고, 모드팩 버전을 바꾸고, 다시 설치하고, 백업하고, 새 서버를 만들 수 있어요. 바뀐 내용은 하나하나 ResinCraft에 알림으로 표시돼요.

파일 관리자, Java 설정, 아무 다운로드 링크에서 받는 플러그인은 PC에서 프로그램을 실행할 수 있어서 두 번째 스위치인 **전체 제어 허용**이 필요해요. Minecraft(Microsoft) 계정에 2단계 인증을 켜 둔 경우에만 켜세요. 이 스위치가 꺼져 있으면 콘솔은 PC의 다른 것에 절대 접근할 수 없어요.

## 16. 다시 설치와 복구

- **파일이 없거나 손상돼서 인스턴스가 실행되지 않아요:**
  - **라이브러리**에서 인스턴스를 오른쪽 클릭 → **다시 설치** → **게임 파일**을 고르거나, 인스턴스의 **설정 → 복구**를 열어요.
  - Minecraft, 모드 로더, 라이브러리, 에셋을 다시 내려받아요. 월드, 모드, 설정은 그대로예요.
- **모드팩 파일이 바뀌었거나 지워졌어요:** **다시 설치** → **모드팩 파일**로 팩의 모드, 설정 파일, 스크립트를 되돌려요. 바꾼 파일은 먼저 백업하고, 월드와 직접 추가한 모드는 그대로예요.
- **서버:** 서버의 **⋯** 메뉴 → **다시 설치** → **서버 소프트웨어**(모드팩 서버라면 **모드팩 파일**). 월드, 설정, 플레이어 목록은 그대로예요.
- **ResinCraft 자체:** **설정 → 업데이트 → ResinCraft 다시 설치**로 앱을 그 위에 다시 설치해요.

## 17. 문제 해결

- **게임이 시작되지 않아요:** **(인스턴스 이름) 이(가) 충돌했습니다** 창(6장)이나 인스턴스의 **로그** 탭을 확인하세요. 파일이 없거나 손상됐나요? 다시 설치하세요(16장).
- **둘러보기에 모드가 안 보여요:** 내 Minecraft 버전이나 로더용이 없을 수 있어요. 다른 버전을 찾아보거나 인스턴스의 버전을 바꿔 보세요(5장).
- **친구가 들어오지 못해요:** 서버 **Console** 탭의 주소와 서버가 **Running**(실행 중) 상태인지 확인하세요. ResinCraft Relay를 쓴다면 Microsoft 계정으로 로그인되어 있는지 확인하세요.
- **서버가 시작하자마자 충돌해요:** ResinCraft가 클라이언트 전용 모드를 알아서 끄고 다시 시작해요. 어떤 모드를 껐는지는 **Console**에서 확인할 수 있어요. 파일이 없다고 나오면 **Console** 탭 위쪽의 목록에서 받으세요.
- **그래도 해결되지 않나요?** **로그** 탭의 로그를 첨부해서 [GitHub](https://github.com/ResinCoreAI/ResinCraft-Launcher/issues)에 문제를 알려 주세요.
