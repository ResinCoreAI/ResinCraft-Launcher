## 1. インストールとサインイン

*バージョン 0.1.0 から。*

1. [リリースページ](https://github.com/ResinCoreAI/ResinCraft-Launcher/releases/latest)から、お使いのシステム用の ResinCraft をダウンロードします。
   - **Windows:** [`ResinCraft-Setup.exe`](https://github.com/ResinCoreAI/ResinCraft-Launcher/releases/download/setup/ResinCraft-Setup.exe)（常に最新バージョンをインストールします）、または `…_amd64_windows.exe` / `…_amd64_windows.msi`
   - **macOS:** `…_universal_macos.dmg`
   - **Linux:** `.AppImage`、`.deb` または `.tar.gz`
2. インストールして起動します。Windows では「発行元を確認できません」と表示されることがあります。macOS では、初回だけアプリを右クリックして**開く**を選んでください。
3. **アカウント** → **Microsoftでサインイン** を開き、Microsoft 自身のページでサインインします。パスワードが ResinCraft を通ることはありません。
   - Microsoft アカウントがない場合は、シングルプレイと LAN 用に**オフラインプロフィール**を追加できます。

## 2. 最初のインスタンスを作る

*バージョン 0.1.0 から。*

*インスタンス*とは、Mod、ワールド、設定をそれぞれ別に持つ、独立した Minecraft のインストールのことです。

1. **ライブラリ** → **新規インスタンス** を開きます。
2. **Minecraftバージョン**と **Modローダー**を選びます。
   - **Vanilla:** Mod なし。
   - **Fabric** または **Quilt:** 軽めの Mod や軽量化 Mod 向け。
   - **Forge** または **NeoForge:** 大型のコンテンツ Mod 向け。
3. 名前を付けて **インスタンスを作成** を押します。
4. **プレイ** を押します。初回の起動ではゲーム本体と適切な Java をダウンロードします。2 回目からはすぐに起動します。

ヒント: 左側の**クイック参加**には、最近遊んだサーバーやワールドが並びます。ワンクリックですぐに入れます。

## 3. Mod、リソースパック、シェーダーを追加する

*バージョン 0.1.0 から。*

1. インスタンスを開き、**コンテンツ** タブ → **Modを追加** を押します。左のバーから**探す**を開いても構いません。
2. 検索するか、Modrinth、CurseForge、FTB などのサイトを見て回ります。インスタンスに合うバージョンだけが表示されます。
3. **インストール** を押します。必要な前提 Mod は自動で追加されます。
4. **コンテンツ** に戻ると:
   - Mod の横のスイッチでオン・オフを切り替えられます。
   - **アップデートを確認** を押すと Mod を更新できます（1 つずつ、またはすべて）。**すべて更新** は最大 4 つずつ同時にダウンロードします。

CurseForge の作者の中には、ランチャーからのダウンロードを許可していない人もいます。その場合 ResinCraft は該当ファイルを **すべてダウンロード** の下に表示します。ブラウザーでダウンロードすれば、ResinCraft がダウンロードフォルダーから自動で見つけます。ブラウザーの保存先が別の場所なら、**設定 → ダウンロード → 監視フォルダー** にそのフォルダーを追加してください。

## 4. Modパックをインストールする

*バージョン 0.1.0 から。*

1. **探す** → **Modパック** を開きます（または **ライブラリ** → **新規インスタンス** → **Modpack をダウンロード**）。
2. パックを開くと、説明、バージョン、パックに入っている **Mod** を確認できます。
3. **パックをインストール** を押します。新しいインスタンスがすぐに **ライブラリ** に表示され、カードにインストールの進捗が出ます。完了すると **プレイ** できるようになります。
4. パックにアップデートが来ると ResinCraft がお知らせします。インスタンスのページで別のパックバージョンを選ぶこともできます。

## 5. Minecraft のバージョンや Mod ローダーを変える

*バージョン 1.2.7 から。*

1. インスタンスのページで、上部のバージョン表示（例: **1.21.4 · Fabric 0.16.10**）をクリックします。**設定 → バージョン** が開きます。
2. **Minecraft** のバージョン、**Mod ローダー**、ローダーのバージョンを選びます。
3. **バージョンを変更** を押して確定します。次回の起動時に必要なものがダウンロードされます。
4. 古いバージョン向けの Mod は動かないことがあります。**コンテンツ** を開いて **アップデートを確認** を押してください。

## 6. Minecraft がクラッシュしたとき

*バージョン 1.2.7 から。*

ゲームがクラッシュすると、「**（インスタンス名） がクラッシュしました**」というウィンドウが開きます。ResinCraft がクラッシュレポートとログを読み取り、何が起きたかを教えてくれます。たとえば次のような内容です（このメッセージは英語で表示されます）。

- *Sodium Extra needs Sodium, which isn't installed*（Sodium Extra には Sodium が必要ですが、入っていません） → **直す** で Sodium をインストールします。
- *citresewn crashed the game*（citresewn がゲームをクラッシュさせました） → **直す** でその Mod をオフにします（あとで **コンテンツ** から再びオンにできます）。
- *This needs Java 21 or newer*（Java 21 以降が必要です） → **直す** で ResinCraft が適切な Java を選びます。
- *Minecraft ran out of memory*（Minecraft のメモリが足りなくなりました） → **直す** でメモリを増やします。

1 つずつ **直す** を押すか、**すべて直して遊ぶ** を押します。ボタンを押すまでは何も変わりません。原因がわからない場合は、**ログを開く** でゲームが最後に出力した内容を確認できます。

## 7. 別のインスタンスからコピーする

*バージョン 1.2.5 から。*

1. コピー*先*のインスタンスを開き、上部の **別のインスタンスからコピー** ボタンを押します。
2. コピー*元*のインスタンスを選びます。
3. コピーしたいものにチェックを入れます。
   - **ワールド**
   - **Mod** と **Modの設定**（config フォルダー）
   - **シェーダーパック** と **リソースパック**
   - **ゲーム設定**（映像、操作、キー割り当て）
4. **コピー** を押します。同じ名前のワールドがすでにある場合は、新しい名前が付きます。すでに入っている Mod やパックはそのまま残ります。

## 8. サーバーを立てる

*バージョン 0.1.0 から。*

サーバー関連の画面は、まだ一部が英語のままです。

1. **Servers**（サーバー） → **Create server**（サーバーを作成）を開きます。
2. 作り方を選びます。
   - **Server software**（サーバーソフトウェア）: Paper、Fabric、Forge、NeoForge、Vanilla、Bedrock…
   - **Modpack**（Modパック）: フレンドが遊んでいるのと同じパック。
   - **From an instance**（インスタンスから）: いま使っている Mod をそのまま。
   - **From a file**（ファイルから）。
3. **Create**（作成）を押します。ウィンドウが閉じ、ダウンロードは右下で続きます。
4. Minecraft の EULA への同意を求められたら同意し、**Start**（開始）を押します。

サーバーのページでは:

- **Console**（コンソール）: サーバーの出力が表示されます。下の欄でコマンドを入力できます。
- **Players**（プレイヤー）: いまオンラインの人、ホワイトリスト、OP、BAN。
- **Mods** または **Plugins**（Mod / プラグイン）: 追加、更新、オフ。**すべて更新** は最大 4 つずつ同時にダウンロードします。サーバーの実行中は、次の再起動時にアップデートが入ります。
- **Properties**（プロパティ）: サーバーの設定（難易度、ホワイトリストのオン・オフなど）。
- **Settings**（設定）:
  - メモリ、Java、**Java flags**（Java フラグ。ResinCraft のものか Modパック独自のもの）
  - フレンドの接続方法
  - サーバーアイコン
- **再起動** と **⋯** メニュー（アドレスをコピー、フォルダーを開く、今すぐバックアップ、削除）。

- **Settings → Anti-xray**（設定 → X-ray 対策。Paper、Purpur、Folia、Leaf）: X-ray Mod やテクスチャーパックから鉱石を隠します。**Hide ores**（鉱石を隠す）はサーバーへの負荷が軽く、**Fake ores**（偽の鉱石）はより強力です。次回の起動から有効になります。
- **Settings → Anti-cheat**（設定 → チート対策。プラグインサーバー）: スイッチ 1 つで Grim をインストールします。

ゲームクライアントでしか動かない Mod（シェーダー、ミニマップなど）は、サーバーが問題なく起動する限りそのまま残ります。その Mod のせいでクラッシュした場合は、ResinCraft がその Mod をオフにしてサーバーを再起動します。**Mods** タブからオンに戻せます。

Modパックに公式サーバーパックがない場合、ResinCraft はパック自身の Mod リストからサーバーを組み立てます。**Create**（作成）の後に出るウィンドウでその旨が表示され、サーバーには **Built by ResinCraft**（ResinCraft が作成）のバッジが付きます。パックのファイルの中には、作者の Web サイトからしかダウンロードできないものもあります。それらは **Console** タブの上部に **Get file**（ファイルを入手）とともに一覧表示されます。ブラウザーでダウンロードすれば、次回の起動前に ResinCraft が所定の場所に置きます。すぐに探させたいときは **Look again**（もう一度探す）を押してください。

## 9. フレンドをサーバーに招く

*バージョン 0.2.0 から。*

サーバーの **Settings** → **How friends connect**（フレンドの接続方法）で選びます。

- **Automatic**（自動、おすすめ。新しいサーバーではこれが既定です）: まずルーター、次に **ResinCraft Relay**、その次に playit.gg。
- **ResinCraft Relay:** フレンドは `yourname.rscraft.resincore.tech` に接続します。Microsoft アカウントでのサインインが必要です。
- **playit.gg:** 無料で、ずっと変わらないアドレスが使えます。初回の起動時に playit.gg アカウントとの連携を求められます（ゲストアカウントでも大丈夫です）。
- **自分でポート開放済み:** ルーターを自分で設定した場合。

フレンドに伝えるアドレスは **Console** タブに表示されます。統合版のフレンドも Java 版サーバーに参加できます。**Bedrock players can join**（統合版プレイヤーの参加を許可）をオンにしてください。

**独自ドメイン:** ResinCraft Relay を使う場合は、**自分のドメインを ResinCraft Relay につなぐ** をオンにしてドメインを入力します。表示される DNS レコード（ドメインが自分のものであることを証明する TXT レコードを含む）を追加して、**検証** を押します。バッジが **検証待ち** から **検証済み** に変わります。Cloudflare の自動 DNS をオンにしていれば、ResinCraft がレコードを追加してくれます。

## 10. ホワイトリスト申請（Web ページと Discord ボット）

*バージョン 1.2.7 から。*

プレイヤーに参加を申請してもらい、承認するか拒否するかを自分で決められます。

1. **Properties** で **white-list** を **true** にします（そうしないと、誰でも参加できてしまいます）。
2. サーバーの **Players** タブを開き、**Whitelist requests**（ホワイトリスト申請）をオンにします。
3. プレイヤーの申請方法を選びます。
   - **Web page**（Web ページ）:
     - サーバーを ResinCraft Relay で共有しているときに使えます。
     - **Copy link**（リンクをコピー）を押して、プレイヤーにリンクを送ります。リンクはサーバー自身のアドレスか、検証済みの自分のドメインです。
     - ページはサーバーがオンラインの間だけ使えます。
   - **Your Discord bot**（自分の Discord ボット）:
     1. [Discord Developer Portal](https://discord.com/developers/applications) を開き、**New Application** → **Bot** → **Reset Token** と進んで、トークンをコピーします。
     2. ResinCraft に貼り付けて **Save**（保存）を押します。トークンはお使いの PC に厳重に保管され、二度と表示されません。
     3. **Online as …** と表示されたら、**Add the bot to your Discord**（ボットを Discord に追加）を押して、自分の Discord サーバーを選びます。
     4. プレイヤーは、あなたの Discord で `/whitelist TheirName` と入力します。
4. 申請は **Players** タブに表示されます。
   - **Accept**（承認）: そのプレイヤーをホワイトリストに追加します（ボットがダイレクトメッセージで本人に知らせます）。
   - **Reject**（拒否）: 申請を断ります。
   - **Reject and block**（拒否してブロック）: 申請を断り、その人がもう申請できないようにします。ブロックしたプレイヤーは **Blocked**（ブロック中）の一覧に表示され、それぞれ **Unblock**（ブロック解除）できます。
   - **サーバーリストから:** ResinCraft を使っているプレイヤーは、探す → サーバー にあるあなたのサーバーのページから申請できます（17 章）。

BAN されたプレイヤーの申請は自動で断られます。Discord ボットは ResinCraft が開いている間だけ動きます。ウィンドウを閉じても動かし続けたい場合は、システムトレイをオンにしてください（13 章）。

## 12. 他のランチャーから移行する

*バージョン 1.0.5 から。*

## 13. アップデートとシステムトレイ

*バージョン 0.3.0 から（システムトレイは 1.2.7 から）。*

- **アップデート:**
  - ResinCraft の新しいバージョンの準備ができると、タイトルバーに **アップデート** ボタンが表示されます。
  - ゲームやサーバーが動いている場合は、**閉じてアップデート**（サーバーは先にワールドを保存します）か **停止したら更新** を選べます。
- **サイレントアップデート**（設定 → アップデート）: 何も動いていないときに、確認なしでバックグラウンドで新しいバージョンをインストールします。
- **システムトレイで動かし続ける**（設定 → 外観）:
  - ウィンドウを閉じても ResinCraft は動き続けます。サーバー、Discord ボット、ダウンロードはそのまま続きます。
  - トレイアイコンをクリックすると再び開きます。完全に終了するには、右クリック → **Quit ResinCraft**（ResinCraft を終了）を選びます。

## 14. テーマとカスタムCSS

*バージョン 1.3.0 から。*

1. **設定 → 外観 → テーマ** を開き、カードを選びます: **システム**、ダーク、ライト、黒曜石、深層岩、サクラ、ネザー、ジ・エンド。
2. **カスタムCSS:** **現在の色を挿入** を押して好きな色を変え、**適用** を押します。どのテーマにも上から適用されます。**クリア** で削除できます。
3. ボックスの下にある **カスタマイズの方法** を開きます。変更できる色や形、スタイルを変えられるアプリの各部分、例（背景画像、角を丸くする、文字を大きくする…）が並んでいます。クリックすると CSS に追加されます。

ちなみに: コナミコマンド（↑ ↑ ↓ ↓ ← → ← → B A）を試すか、ResinCraft のロゴを 7 回クリックしてみてください。

## 15. リモート操作（Web コンソール）

*バージョン 1.3.0 から。*

どのブラウザーからでも、スマホからでも、サーバーを操作できます。

1. **アカウント** で Microsoft アカウントにサインインします。
2. **設定 → リモート操作 → リモート操作を許可** をオンにします。「**… として接続中**」と表示されたら準備完了です。
3. ウィンドウを閉じても使えるように、**システムトレイで動かし続ける** をオンにします（13 章）。
4. `https://console.rscraft.resincore.tech` を開き（または **Web コンソールを開く** を押し）、**同じ Minecraft アカウント**でサインインします。

コンソールでは、サーバー管理でできることがすべてできます。サーバーの起動・停止・再起動、コンソールの確認とコマンドの入力、プレイヤーとホワイトリスト申請の管理、プラグインや Mod の追加と更新、プロパティと設定の変更、Modパックのバージョン切り替え、再インストール、バックアップ、新しいサーバーの作成などです。変更があるたびに、ResinCraft にお知らせが表示されます。

ファイルマネージャー、Java 設定、任意のダウンロードリンクからのプラグインは PC 上でプログラムを実行できるため、2 つ目のスイッチ **フル操作を許可** が必要です。Minecraft（Microsoft）アカウントで 2 段階認証を使っている場合にだけオンにしてください。オフのままなら、コンソールが PC 上のほかのものにアクセスすることは一切ありません。

## 16. 再インストールと修復

*バージョン 1.3.0 から。*

- **ファイルが足りない・壊れているせいでインスタンスが起動しない:**
  - **ライブラリ** でインスタンスを右クリック → **再インストール** → **ゲームファイル** を選ぶか、インスタンスの **設定 → 修復** を開きます。
  - Minecraft、Mod ローダー、ライブラリ、アセットがもう一度ダウンロードされます。ワールド、Mod、設定はそのままです。
- **Modパックのファイルが変更・削除された:** **再インストール** → **Modパックのファイル** で、パックの Mod、設定ファイル、スクリプトが元に戻ります。変更したファイルは先にバックアップされます。ワールドと自分で追加した Mod はそのままです。
- **サーバー:** **⋯** メニュー → **再インストール** → **サーバーソフト**（Modパックのサーバーなら **Modパックのファイル**）。ワールド、設定、プレイヤーリストはそのままです。
- **ResinCraft 本体:** **設定 → アップデート → ResinCraftを再インストール** で、アプリを上書きでもう一度インストールします。

## 17. サーバーを探して参加する

*バージョン 1.4.0 から。*

1. **探す** → **サーバー** を開きます。ResinCraft でホストされているサーバーと、プレイヤーが追加したサーバーが並びます。
2. 検索するか、カテゴリー（SMP、PvP、ミニゲーム、Skyblock…）、地域、言語、Modパック、統合版のプレイヤーやオフラインプロフィールで参加できるかどうかで絞り込みます。
3. サーバーのアイコンか名前をクリックすると、そのページが開きます。説明の全文、すべての詳細情報、クライアントパック、リンクが載っています。
4. **参加** を押します。ResinCraft がサーバーに合うインスタンスを選ぶか、どれを使うか尋ねます。独自の Mod を使うサーバーには **インストールして参加** があり、ちょうどその Mod を入れたインスタンスを作って参加します。
5. ホワイトリストのあるサーバーなら、**参加をリクエスト** を押します。ボタンの表示は **Waiting for the host**（ホストの返事待ち）になり、その後 **On the whitelist**（ホワイトリスト登録済み。**参加** を押します）か **Ask again**（もう一度申請）に変わります。ホストが返事をすると、ResinCraft が知らせてくれて、タスクバーも点滅します。

気に入ったサーバーにはいいねを。ルールを破っているサーバーは通報してください。

## 18. サーバーを掲載して Mod を共有する

*バージョン 1.4.0 から。*

1. ホストしているサーバーの **Settings** で、**サーバーリスト** をオンにします（最初はオフです）。
2. 説明、タグ、地域、言語を追加します。統合版やオフラインプロフィールへの対応と Modパックは自動で入ります。
3. **クライアントパック:** プレイヤーが **インストールして参加** できるよう、必要なものを公開します。
   - サーバーの Modパック（配信元のサイトからインストール）
   - ほかの Mod（1 つずつ Modrinth か CurseForge から）
   - 自分のファイル（ResinCraft の実行中に PC から直接送信）
   - いっしょに送ると決めたリソースパックやシェーダー
   プラグインサーバーやバニラサーバーにも作れます。サーバーと同じ Minecraft バージョンのインスタンスを選んでください。

ほかの場所で動かしているサーバーは、探す → サーバー の **サーバーを登録** から追加できます。

## 19. ほかの PC と、手伝ってくれるフレンド

*バージョン 1.4.1 から。*

**ほかの PC:** それぞれの PC でリモート操作をオンにし（15 章）、同じ Minecraft アカウントでサインインします。次に **Servers** で上部の PC メニューを開き、PC を選びます。ここからその PC のサーバーを起動、停止、管理できるほか、そちらで **Create server**（サーバーを作成）や **サーバーをインポート** もできます。その PC のフォルダーからインポートするには、フォルダーを入力します。それには、その PC で **フル操作を許可** がオンになっている必要があります。

**サーバーの運営を手伝ってくれるフレンド:**

1. **設定 → リモート操作 → People who can use your servers**（サーバーを使える人）を開きます。
2. 相手の Minecraft の名前を入力し、**Add**（追加）を押します。
3. できることを選びます。
   - **Viewer**（閲覧者）: コンソール、プレイヤー、設定を見られます。
   - **Operator**（オペレーター）: さらに、起動・停止・再起動、コマンドの送信、プレイヤーとホワイトリスト申請の対応ができます。
   - **Manager**（マネージャー）: さらに、設定、プラグインと Mod、Modパックを変更できます。
4. **All servers**（すべてのサーバー）のままにするか、**Which servers?**（どのサーバー？）でサーバーを選びます。

フレンドは、自分の ResinCraft（**Servers** の PC メニュー）か Web コンソールから、あなたのサーバーを開きます。使えるのは、リモート操作がオンで、あなたの PC で ResinCraft が動いている間です。ファイル、Java 設定、サーバーの作成と削除は、あなただけのものです。

## 20. ワールドのバックアップ

*バージョン 1.4.0 から。*

- **自動:** ゲームやサーバーが動いている間、そのワールドを 30 分ごとにバックアップし、ワールドごとに新しい 3 つを残します。変更やオフは **設定 → 自動バックアップ** で行えます。
- **復元:** インスタンスの **ワールド** タブか、ホストしているサーバーの **Settings → Backups**（設定 → バックアップ）で、自分で作ったものでも自動のものでも、バックアップの **復元** を押します。置き換えられたワールドはごみ箱に移されるので、復元は取り消せます。シングルプレイのワールドは、コピーとして戻すこともできます。

## 21. ストレージと別の PC への移行

*バージョン 1.1.0 から（別の PC へ移行は 1.1.1 から）。*

- **別のドライブ:** **設定 → ストレージ → 変更…** を開いてドライブかフォルダーを選び、次のどちらかを選びます。
  - **インスタンスを移動:** インスタンス、サーバー、Minecraft の共有ファイルをそこへ移します。
  - **移動せずに使う:** 新しいものはそこに置かれます。今のインスタンスはそのまま残り、元に切り替えると戻ってきます。
- **新しい PC:** **設定 → 別の PC へ移行** で、すべてを 1 つの `.resincraft` ファイルに保存します。新しい PC の ResinCraft でそのファイルを開いてください。

## 22. 困ったときは

- **ゲームが起動しない:** 「**（インスタンス名） がクラッシュしました**」ウィンドウ（6 章）か、インスタンスの **ログ** タブを確認してください。ファイルが足りない・壊れている場合は、再インストールしてください（16 章）。
- **探したい Mod が「探す」に出てこない:** お使いの Minecraft バージョンやローダー向けのものがないのかもしれません。別のバージョンを試すか、インスタンスのバージョンを変更してください（5 章）。
- **フレンドが参加できない:** サーバーの **Console** タブに表示されたアドレスと、サーバーが **Running**（実行中）になっていることを確認してください。ResinCraft Relay を使う場合は、Microsoft アカウントでサインインしているか確認してください。
- **サーバーが起動時にクラッシュする:** ResinCraft がクライアント専用 Mod を自動でオフにして、もう一度起動します。どの Mod をオフにしたかは **Console** に表示されます。ファイルが足りないと表示された場合は、**Console** タブ上部の一覧から入手してください。
- **それでも解決しない場合:** **ログ** タブのログを添えて、[GitHub](https://github.com/ResinCoreAI/ResinCraft-Launcher/issues) で問題を報告してください。
