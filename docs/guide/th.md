## 1. ติดตั้งและลงชื่อเข้าใช้

1. ดาวน์โหลด ResinCraft ให้ตรงกับระบบของคุณจาก [หน้า Releases](https://github.com/ResinCoreAI/ResinCraft-Launcher/releases/latest):
   - **Windows:** [`ResinCraft-Setup.exe`](https://github.com/ResinCoreAI/ResinCraft-Launcher/releases/download/setup/ResinCraft-Setup.exe) (ติดตั้งเวอร์ชันล่าสุดให้เสมอ) หรือ `…_amd64_windows.exe` / `…_amd64_windows.msi`
   - **macOS:** `…_universal_macos.dmg`
   - **Linux:** `.AppImage`, `.deb` หรือ `.tar.gz`
2. ติดตั้งแล้วเปิดแอปขึ้นมา Windows อาจเตือนว่าไม่รู้จักผู้เผยแพร่ ส่วนบน macOS ครั้งแรกให้คลิกขวาที่แอปแล้วเลือก **เปิด**
3. ไปที่ **บัญชี** → **ลงชื่อเข้าใช้ด้วย Microsoft** แล้วลงชื่อเข้าใช้บนหน้าเว็บของ Microsoft เอง รหัสผ่านของคุณจะไม่ผ่าน ResinCraft เลย
   - ไม่มีบัญชี Microsoft? เพิ่ม **โปรไฟล์ออฟไลน์** ไว้เล่นคนเดียวหรือเล่น LAN ได้

## 2. สร้างอินสแตนซ์แรก

*อินสแตนซ์* คือ Minecraft ที่ติดตั้งแยกไว้หนึ่งชุด มีม็อด โลก และการตั้งค่าเป็นของตัวเอง

1. ไปที่ **คลัง** → **อินสแตนซ์ใหม่**
2. เลือก **เวอร์ชัน Minecraft** และ **ตัวโหลดม็อด**:
   - **Vanilla:** ไม่มีม็อด
   - **Fabric** หรือ **Quilt:** ม็อดเบา ๆ และม็อดเพิ่มเฟรมเรต
   - **Forge** หรือ **NeoForge:** ม็อดเนื้อหาใหญ่ ๆ
3. ตั้งชื่อ แล้วกด **สร้างอินสแตนซ์**
4. กด **เล่น** ครั้งแรกจะดาวน์โหลดตัวเกมกับ Java ที่เหมาะให้ ครั้งต่อ ๆ ไปจะเปิดได้เร็วขึ้น

เคล็ดลับ: **เข้าเกมด่วน** ทางซ้ายจะแสดงเซิร์ฟเวอร์และโลกที่เพิ่งเล่นไป คลิกเดียวก็เข้าเกมได้ทันที

## 3. เพิ่มม็อด แพ็กทรัพยากร และเชดเดอร์

1. เปิดอินสแตนซ์ → แท็บ **เนื้อหา** → **เพิ่มม็อด** หรือจะเปิด **สำรวจ** จากแถบด้านซ้ายก็ได้
2. ค้นหา หรือเลือกดูจาก Modrinth, CurseForge, FTB และเว็บอื่น ๆ ระบบจะแสดงเฉพาะเวอร์ชันที่ใช้กับอินสแตนซ์ของคุณได้
3. กด **ติดตั้ง** ม็อดที่ต้องใช้ร่วม (dependency) จะถูกเพิ่มให้เอง
4. กลับมาที่ **เนื้อหา**:
   - กดสวิตช์ข้างม็อดเพื่อเปิดหรือปิดม็อดนั้น
   - กด **ตรวจหาอัปเดต** เพื่ออัปเดตม็อด (ทีละตัวหรือทั้งหมด)

ผู้สร้างบางคนบน CurseForge ไม่อนุญาตให้ลันเชอร์ดาวน์โหลดไฟล์ของเขา ResinCraft จะแสดงไฟล์พวกนี้ไว้ใต้ **ดาวน์โหลดทั้งหมด** ให้คุณดาวน์โหลดผ่านเบราว์เซอร์ แล้ว ResinCraft จะไปหาไฟล์ในโฟลเดอร์ดาวน์โหลดเอง ถ้าเบราว์เซอร์ของคุณเซฟไฟล์ไว้ที่อื่น ก็เพิ่มโฟลเดอร์นั้นใน **การตั้งค่า → การดาวน์โหลด → โฟลเดอร์ที่เฝ้าดู**

## 4. ติดตั้งม็อดแพ็ก

1. ไปที่ **สำรวจ** → **ม็อดแพ็ก** (หรือ **คลัง** → **อินสแตนซ์ใหม่** → **ดาวน์โหลดม็อดแพ็ก**)
2. เปิดแพ็กที่สนใจเพื่อดูคำอธิบาย เวอร์ชัน และ **ม็อด** ที่อยู่ในแพ็ก
3. กด **ติดตั้งแพ็ก** อินสแตนซ์ใหม่จะขึ้นใน **คลัง** ทันที พร้อมแสดงความคืบหน้าการติดตั้งบนการ์ด แล้วกด **เล่น** ได้เมื่อติดตั้งเสร็จ
4. เมื่อแพ็กมีอัปเดต ResinCraft จะบอกคุณ และคุณยังเลือกเวอร์ชันอื่นของแพ็กได้จากหน้าอินสแตนซ์ด้วย

## 5. เปลี่ยนเวอร์ชัน Minecraft หรือตัวโหลดม็อด

1. ที่หน้าอินสแตนซ์ คลิกชิปเวอร์ชันด้านบน (เช่น **1.21.4 · Fabric 0.16.10**) ระบบจะเปิด **การตั้งค่า → เวอร์ชัน**
2. เลือกเวอร์ชัน **Minecraft**, **ตัวโหลดม็อด** และเวอร์ชันของตัวโหลด
3. กด **เปลี่ยนเวอร์ชัน** แล้วยืนยัน ตอนเปิดเกมครั้งถัดไปจะดาวน์โหลดสิ่งที่ต้องใช้ให้
4. ม็อดที่ทำมาสำหรับเวอร์ชันเก่าอาจใช้ไม่ได้ ให้ไปที่ **เนื้อหา** แล้วกด **ตรวจหาอัปเดต**

## 6. เมื่อ Minecraft แครช

เมื่อเกมแครช หน้าต่าง **Minecraft แครช** จะเด้งขึ้นมา (ตรงคำว่า Minecraft จะเป็นชื่ออินสแตนซ์ของคุณ) ResinCraft จะอ่านรายงานแครชกับล็อก แล้วบอกว่าเกิดอะไรขึ้น เช่น

- *Sodium Extra ต้องใช้ Sodium แต่ยังไม่ได้ติดตั้ง* → **แก้** จะติดตั้ง Sodium ให้
- *citresewn ทำให้เกมแครช* → **แก้** จะปิดม็อดนั้น (เปิดกลับได้ทีหลังใน **เนื้อหา**)
- *ต้องใช้ Java 21 ขึ้นไป* → **แก้** จะให้ ResinCraft เลือก Java ที่ถูกต้องให้
- *Minecraft หน่วยความจำไม่พอ* → **แก้** จะเพิ่มหน่วยความจำให้

กด **แก้** ทีละข้อ หรือกด **แก้ทั้งหมดแล้วเล่น** ทีเดียวก็ได้ ไม่มีอะไรเปลี่ยนจนกว่าคุณจะกดปุ่ม ถ้า ResinCraft บอกสาเหตุไม่ได้ กด **เปิดบันทึก** เพื่อดูว่าเกมพิมพ์อะไรออกมาเป็นอย่างสุดท้าย

## 7. คัดลอกของจากอินสแตนซ์อื่น

1. เปิดอินสแตนซ์ *ปลายทาง* ที่จะคัดลอกของเข้าไป → กดปุ่ม **คัดลอกจากอินสแตนซ์อื่น** ด้านบน
2. เลือกอินสแตนซ์ *ต้นทาง* ที่จะคัดลอกมา
3. ติ๊กสิ่งที่ต้องการ:
   - **โลก**
   - **ม็อด** และ **การตั้งค่าม็อด** (โฟลเดอร์ config)
   - **เชดเดอร์แพ็ก** และ **รีซอร์สแพ็ก**
   - **การตั้งค่าเกม** (ภาพ การควบคุม และปุ่มคีย์ลัด)
4. กด **คัดลอก** โลกที่ชื่อซ้ำกับที่มีอยู่จะได้ชื่อใหม่ ส่วนม็อดและแพ็กที่มีอยู่แล้วจะคงไว้เหมือนเดิม

## 8. โฮสต์เซิร์ฟเวอร์

1. ไปที่ **Servers** (เซิร์ฟเวอร์) → **Create server** (สร้างเซิร์ฟเวอร์)
2. เลือกวิธีสร้าง:
   - **Server software** (ซอฟต์แวร์เซิร์ฟเวอร์): Paper, Fabric, Forge, NeoForge, Vanilla, Bedrock…
   - **Modpack** (ม็อดแพ็ก): แพ็กเดียวกับที่เพื่อน ๆ เล่น
   - **From an instance** (จากอินสแตนซ์): ใช้ม็อดชุดที่คุณเล่นอยู่แล้ว
   - **From a file** (จากไฟล์)
3. กด **Create** (สร้าง) หน้าต่างจะปิดไป แล้วการดาวน์โหลดจะทำต่อที่มุมขวาล่าง
4. กดยอมรับ EULA ของ Minecraft เมื่อระบบถาม แล้วกด **Start** (เริ่ม)

ในหน้าของเซิร์ฟเวอร์:

- **Console** (คอนโซล): ดูข้อความจากเซิร์ฟเวอร์ และพิมพ์คำสั่งได้ที่ช่องด้านล่าง
- **Players** (ผู้เล่น): ใครออนไลน์อยู่ตอนนี้ รวมถึงไวท์ลิสต์ OP และรายชื่อที่โดนแบน
- **Mods** หรือ **Plugins** (ม็อดหรือปลั๊กอิน): เพิ่ม อัปเดต หรือปิด
- **Properties** (ค่าของเซิร์ฟเวอร์): การตั้งค่าเซิร์ฟเวอร์ (ความยาก เปิด/ปิดไวท์ลิสต์ และอื่น ๆ)
- **Settings** (การตั้งค่า):
  - หน่วยความจำ Java และ **Java flags** (แฟล็ก Java ของ ResinCraft หรือของม็อดแพ็กเอง)
  - วิธีที่เพื่อนเชื่อมต่อ
  - ไอคอนเซิร์ฟเวอร์
- **รีสตาร์ต** และเมนู **⋯** (คัดลอกที่อยู่ เปิดโฟลเดอร์ สำรองข้อมูลตอนนี้ ลบ)

- **Settings → Anti-xray** (การตั้งค่า → กันเอ็กซ์เรย์ ใช้กับ Paper, Purpur, Folia, Leaf): ซ่อนแร่จากม็อดและเท็กซ์เจอร์แพ็กเอ็กซ์เรย์ **Hide ores** (ซ่อนแร่) กินแรงเซิร์ฟเวอร์น้อย ส่วน **Fake ores** (แร่ปลอม) กันได้แน่นกว่า จะมีผลตอนเปิดเซิร์ฟเวอร์ครั้งถัดไป

ม็อดที่ทำงานเฉพาะฝั่งตัวเกม (เชดเดอร์ มินิแมป…) จะยังอยู่บนเซิร์ฟเวอร์ตราบใดที่เซิร์ฟเวอร์เปิดได้ปกติ ถ้าม็อดตัวไหนทำให้แครช ResinCraft จะปิดม็อดนั้นแล้วเปิดเซิร์ฟเวอร์ใหม่ให้ และคุณเปิดม็อดกลับได้ในแท็บ **Mods**

ถ้าม็อดแพ็กไม่มี server pack ทางการ ResinCraft จะสร้างเซิร์ฟเวอร์จากรายการม็อดของแพ็กเอง หน้าต่างที่ขึ้นมาหลังกด **Create** จะบอกเรื่องนี้ และเซิร์ฟเวอร์จะมีป้าย **Built by ResinCraft** (ResinCraft สร้างให้) ไฟล์บางไฟล์ในแพ็กดาวน์โหลดได้จากเว็บของผู้สร้างเท่านั้น ไฟล์พวกนี้จะแสดงอยู่ด้านบนของแท็บ **Console** พร้อมปุ่ม **Get file** (รับไฟล์) ให้ดาวน์โหลดผ่านเบราว์เซอร์ แล้ว ResinCraft จะวางไฟล์ไว้ให้ก่อนเปิดเซิร์ฟเวอร์ครั้งถัดไป หรือจะกด **Look again** (หาอีกครั้ง) ก็ได้

## 9. ให้เพื่อนเข้าเซิร์ฟเวอร์ของคุณ

ไปที่ **Settings** ของเซิร์ฟเวอร์ → **How friends connect** (วิธีที่เพื่อนเชื่อมต่อ):

- **Automatic** (อัตโนมัติ แนะนำให้ใช้): ลอง **ResinCraft Relay** ก่อน ถ้าไม่ได้ค่อยใช้ playit.gg แล้วค่อย bore
- **ResinCraft Relay:** เพื่อนเข้าผ่าน `yourname.rscraft.resincore.tech` ต้องลงชื่อเข้าใช้บัญชี Microsoft ไว้
- **playit.gg:** ที่อยู่ฟรีที่ไม่เปลี่ยน ตอนเปิดเซิร์ฟเวอร์ครั้งแรกจะให้เชื่อมบัญชี playit.gg (ใช้บัญชีผู้เยี่ยมชมก็ได้)
- **ฟอร์เวิร์ดพอร์ตเอง:** ถ้าคุณตั้งค่าเราเตอร์เองไว้แล้ว

แท็บ **Console** จะแสดงที่อยู่ที่ต้องส่งให้เพื่อน เพื่อนที่เล่น Bedrock ก็เข้าเซิร์ฟเวอร์ Java ได้ แค่เปิด **Bedrock players can join** (ผู้เล่น Bedrock เข้าได้)

## 10. คำขอเข้าไวท์ลิสต์ (หน้าเว็บและบอท Discord)

ให้ผู้เล่นส่งคำขอเข้าเซิร์ฟเวอร์ แล้วคุณเป็นคนเลือกเองว่าจะรับหรือไม่รับ

1. ใน **Properties** ตั้ง **white-list** เป็น **true** (ไม่อย่างนั้นใครก็เข้าได้อยู่ดี)
2. เปิดแท็บ **Players** ของเซิร์ฟเวอร์ แล้วเปิด **Whitelist requests** (คำขอเข้าไวท์ลิสต์)
3. เลือกช่องทางที่ผู้เล่นจะใช้ส่งคำขอ:
   - **Web page** (หน้าเว็บ):
     - ใช้ได้เมื่อเซิร์ฟเวอร์แชร์ผ่าน ResinCraft Relay
     - กด **Copy link** (คัดลอกลิงก์) แล้วส่งลิงก์นี้ให้ผู้เล่น: `https://rscraft.resincore.tech/join/<name>`
     - หน้าเว็บใช้ได้ตอนที่เซิร์ฟเวอร์ออนไลน์อยู่
   - **Your Discord bot** (บอท Discord ของคุณ):
     1. เปิด [Discord Developer Portal](https://discord.com/developers/applications) → **New Application** → **Bot** → **Reset Token** แล้วคัดลอกโทเค็นไว้
     2. วางโทเค็นใน ResinCraft แล้วกด **Save** (บันทึก) โทเค็นจะถูกเก็บแบบปิดผนึกไว้ในเครื่องคุณ และจะไม่แสดงให้เห็นอีก
     3. เมื่อขึ้นว่า **Online as …** ให้กด **Add the bot to your Discord** (เพิ่มบอทเข้า Discord ของคุณ) แล้วเลือกเซิร์ฟเวอร์ Discord ของคุณ
     4. ผู้เล่นพิมพ์ `/whitelist TheirName` ใน Discord ของคุณ
4. คำขอจะขึ้นในแท็บ **Players**:
   - **Accept** (รับ): เพิ่มผู้เล่นเข้าไวท์ลิสต์ (บอทจะแจ้งเขาทาง DM)
   - **Reject** (ปฏิเสธ): ปฏิเสธคำขอ
   - **Reject and block** (ปฏิเสธและบล็อก): ปฏิเสธ แล้วกันไม่ให้คนนั้นส่งคำขอมาอีก ส่วน **Unblock all** (ปลดบล็อกทั้งหมด) จะยกเลิกการบล็อกบน Discord

คำขอจากผู้เล่นที่โดนแบนจะถูกปฏิเสธให้อัตโนมัติ บอท Discord ทำงานเฉพาะตอนที่ ResinCraft เปิดอยู่ ถ้าอยากให้บอททำงานต่อแม้ปิดหน้าต่างไปแล้ว ให้เปิดการทำงานใน system tray (หัวข้อ 13)

## 13. อัปเดตและ system tray

- **อัปเดต:**
  - เมื่อ ResinCraft เวอร์ชันใหม่พร้อมแล้ว ปุ่ม **อัปเดต** จะขึ้นบนแถบชื่อหน้าต่าง
  - ถ้ามีเกมหรือเซิร์ฟเวอร์เปิดอยู่ คุณเลือกได้ว่าจะ **ปิดแล้วอัปเดต** (เซิร์ฟเวอร์จะเซฟโลกก่อน) หรือ **อัปเดตเมื่อหยุดทำงาน**
- **อัปเดตแบบเงียบ** (การตั้งค่า → อัปเดต): ติดตั้งเวอร์ชันใหม่อยู่เบื้องหลังโดยไม่ต้องถาม เมื่อไม่มีอะไรเปิดอยู่
- **ทำงานต่อใน system tray** (การตั้งค่า → รูปลักษณ์):
  - ปิดหน้าต่างแล้ว ResinCraft ก็ยังทำงานต่อ: เซิร์ฟเวอร์ บอท Discord และการดาวน์โหลดไม่หยุด
  - คลิกไอคอนใน tray เพื่อเปิดกลับมา หรือคลิกขวา → **Quit ResinCraft** (ออกจาก ResinCraft) เพื่อปิดโปรแกรมจริง ๆ

## 14. ธีมและ CSS ของคุณเอง

1. เปิด **การตั้งค่า → รูปลักษณ์ → ธีม** แล้วเลือกการ์ด: **ระบบ**, มืด, สว่าง, ออบซิเดียน, ดีปสเลต, เชอร์รี่, เนเธอร์, ดิเอนด์, ฮาโลวีน หรือคริสต์มาส
2. **ธีมเทศกาล:**
   - ฮาโลวีนจะเปิดเองตั้งแต่ 16 ถึง 31 ตุลาคม และคริสต์มาสตั้งแต่ 10 ถึง 25 ธันวาคม พอถึงวันถัดไป ธีมของคุณจะกลับมาเอง
   - อยากใช้ธีมของตัวเองต่อ? กด **ใช้ธีมของฉัน** บนแบนเนอร์ หรือเลือกการ์ดอื่น แล้วธีมนั้นจะอยู่กับคุณไปตลอดเทศกาลนั้น
   - ปิด **ธีมเทศกาล** ถ้าไม่อยากให้เปลี่ยนเองอีกเลย
3. **CSS ของคุณเอง:** กด **ใส่สีปัจจุบัน** แก้สีไหนก็ได้ แล้วกด **ใช้** ใช้ได้กับทุกธีม ส่วน **ล้าง** จะลบ CSS ออก

ชู่ว์: ลองกดสูตรโคนามิ (↑ ↑ ↓ ↓ ← → ← → B A) หรือคลิกโลโก้ ResinCraft เจ็ดครั้งดูสิ

## 15. ควบคุมระยะไกล (เว็บคอนโซล)

ดูแลเซิร์ฟเวอร์ของคุณได้จากเบราว์เซอร์ไหนก็ได้ หรือจากมือถือ

1. ลงชื่อเข้าใช้บัญชี Microsoft ใน **บัญชี**
2. เปิด **การตั้งค่า → ควบคุมระยะไกล → อนุญาตการควบคุมระยะไกล** เมื่อขึ้นว่า **เชื่อมต่อแล้วในชื่อ …** ก็พร้อมใช้งานแล้ว
3. เปิด **ทำงานต่อใน system tray** (หัวข้อ 13) เพื่อให้ยังใช้ได้แม้ปิดหน้าต่างไปแล้ว
4. เปิด `https://console.rscraft.resincore.tech` (หรือกด **เปิดเว็บคอนโซล**) แล้วลงชื่อเข้าใช้ด้วย **บัญชี Minecraft บัญชีเดียวกัน**

จากเว็บคอนโซล คุณเปิด หยุด และรีสตาร์ตเซิร์ฟเวอร์ ดูคอนโซลและพิมพ์คำสั่ง จัดการผู้เล่น สำรองข้อมูล และสร้างเซิร์ฟเวอร์ใหม่ได้ แต่เว็บคอนโซลเข้าถึงไฟล์ การตั้งค่า Java หรืออะไรอื่นในเครื่องคุณไม่ได้ ทุกการเปลี่ยนแปลงจะขึ้นเป็นการแจ้งเตือนใน ResinCraft

## 16. ติดตั้งใหม่และซ่อมแซม

- **อินสแตนซ์เปิดไม่ได้เพราะไฟล์หายหรือเสีย:**
  - คลิกขวาที่อินสแตนซ์ใน **คลัง** → **ติดตั้งใหม่** → **ไฟล์เกม** หรือเปิด **การตั้งค่า → ซ่อมแซม** ของอินสแตนซ์นั้น
  - Minecraft ตัวโหลดม็อด ไลบรารี และแอสเซ็ตจะถูกดาวน์โหลดใหม่ โลก ม็อด และการตั้งค่ายังอยู่ครบ
- **ไฟล์ของม็อดแพ็กถูกแก้หรือถูกลบ:** **ติดตั้งใหม่** → **ไฟล์ม็อดแพ็ก** จะคืนม็อด คอนฟิก และสคริปต์ของแพ็กกลับมา ไฟล์ที่คุณแก้จะถูกสำรองไว้ก่อน ส่วนโลกและม็อดที่คุณเพิ่มเองยังอยู่ครบ
- **เซิร์ฟเวอร์:** เมนู **⋯** ของเซิร์ฟเวอร์ → **ติดตั้งใหม่** → **ซอฟต์แวร์เซิร์ฟเวอร์** (หรือ **ไฟล์ม็อดแพ็ก** สำหรับเซิร์ฟเวอร์ที่สร้างจากม็อดแพ็ก) โลก การตั้งค่า และรายชื่อผู้เล่นยังอยู่ครบ
- **ตัว ResinCraft เอง:** **การตั้งค่า → อัปเดต → ติดตั้ง ResinCraft ใหม่** จะติดตั้งแอปทับตัวเอง

## 17. แก้ปัญหา

- **เกมไม่ยอมเปิด:** ดูหน้าต่าง **Minecraft แครช** (หัวข้อ 6) หรือแท็บ **ล็อก** ของอินสแตนซ์ ถ้าไฟล์หายหรือเสีย ก็ติดตั้งใหม่ได้ (หัวข้อ 16)
- **หาม็อดในหน้าสำรวจไม่เจอ:** ม็อดนั้นอาจไม่มีสำหรับเวอร์ชัน Minecraft หรือตัวโหลดของคุณ ลองเวอร์ชันอื่น หรือเปลี่ยนเวอร์ชันของอินสแตนซ์ (หัวข้อ 5)
- **เพื่อนเข้าไม่ได้:** เช็กที่อยู่ในแท็บ **Console** ของเซิร์ฟเวอร์ และดูว่าเซิร์ฟเวอร์ขึ้นสถานะ **Running** (กำลังทำงาน) อยู่ ถ้าใช้ ResinCraft Relay ให้แน่ใจว่าลงชื่อเข้าใช้บัญชี Microsoft แล้ว
- **เซิร์ฟเวอร์แครชตอนเปิด:** ResinCraft จะปิดม็อดฝั่งไคลเอนต์ให้เองแล้วเปิดเซิร์ฟเวอร์ใหม่ ดูใน **Console** จะมีบรรทัดที่บอกว่าปิดม็อดตัวไหนไป ถ้าขึ้นว่าไฟล์หาย ให้ไปเอาไฟล์จากรายการด้านบนของแท็บ **Console**
